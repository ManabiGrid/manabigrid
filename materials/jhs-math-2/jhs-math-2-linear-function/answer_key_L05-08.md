## L05 条件から式を決める——手がかり2つで直線は1本に決まる

<!-- 検算の型（L01で導入した代入検算のL05での運用）: 求めた式に、与えられた手がかりの点を代入して成り立つか確かめる（2点問題は両方の点で）。 -->

### 練習

1. <!-- 旧ID: ex_L5_check_02 -->
   傾きが分かっているので y＝−x＋b の形。点 (4, 1) を代入:
   1＝−4＋b
   b＝5
   **y＝−x＋5**（検算: x＝4 で y＝−4＋5＝1——点 (4, 1) を通る ✓）
2. <!-- 旧ID: ex_L5_check_01 -->
   x座標は 2 と 5 で異なる（確認）。
   a＝(16−7)÷(5−2)＝9÷3＝3
   7＝3×2＋b → b＝1
   **y＝3x＋1**（検算: x＝2 で y＝7 ✓、x＝5 で y＝16 ✓——両方の点を通る）
3. 変化の割合は式の a と同じ数なので、a＝3。x＝1, y＝2 を代入:
   2＝3×1＋b → b＝−1
   **y＝3x−1**（検算: x＝1 で y＝3−1＝2 ✓）
4. x座標は −2 と 1 で異なる（確認）。
   a＝(3−9)÷(1−(−2))＝(−6)÷3＝−2
   3＝−2×1＋b → b＝5
   **y＝−2x＋5**（検算: x＝−2 で y＝4＋5＝9 ✓、x＝1 で y＝−2＋5＝3 ✓）
5. **まちがい: 2点のx座標がちがうことを確認せずに、傾きの計算を始めたこと（最初の一手のとばし）。**
   この2点はx座標がどちらも3で同じ。分母が 3−3＝0 になり、0で割る計算はできない。そして、x座標が同じでyの値がちがう2点（「x＝3 のとき y＝5」と「x＝3 のとき y＝9」）を両方満たす y＝ax＋b は、どんな a・b でも作れない。
   **正しい直し方: 「この2点を通る一次関数の式は求められない」と答える。**（確認: xの値1つにyの値が2つ対応する関係は、関数の式では表せない ✓）

**S1**
x＝7 のとき y＝2×7＋3＝17 なので、(7, 17) はたしかに直線上の点。
x座標は 1 と 7 で異なる（確認）。
a＝(17−5)÷(7−1)＝12÷6＝2
5＝2×1＋b → b＝3
**y＝2x＋3——例2とまったく同じ式になる。**
続く一言（例）: 同じ直線の上なら、どの2点を選んで計算しても、**同じ傾き・同じ式が得られる**。直線上では変化の割合がどこで測っても一定（L02）だから、傾きはどの2点から計算しても同じ値になり、そこに1点を代入して決まる b も同じになる。（検算: x＝4 で y＝2×4＋3＝11——例2の点 (4, 11) も通る ✓）

## L06 二元一次方程式とグラフ——交わる点は2つの式を同時に満たす組

<!-- 検算の型（本レッスン・L06で導入）: 交点は、もとの2つの方程式の両方に代入して確かめる（「交点は両方の式で確かめる」）。yについて解いた式は、xに1つ値を入れて出た組がもとの方程式を成り立たせるか確かめる。 -->

### 練習

1. <!-- 旧ID: ex_L6_check_02 -->
   y＝−3x＋9
   **傾き −3、切片 9**（検算: x＝1 のとき y＝6——組 (1, 6) をもとの式へ: 3×1＋6＝9 ✓）
2. (1) 4y＝−2x＋12
   **y＝−(1/2)x＋3**（検算: x＝2 のとき y＝2——組 (2, 2) をもとの式へ: 2×2＋4×2＝12 ✓）
   (2) −2y＝−x＋4
   **y＝(1/2)x−2**（検算: x＝4 のとき y＝0——組 (4, 0) をもとの式へ: 4−2×0＝4 ✓）
3. <!-- 旧ID: ex_L6_check_01 -->
   x＋y＝5 より y＝5−x。もう一方の式でも同じ y になる x を探す:
   5−x＝2x−1
   6＝3x
   x＝2、y＝2×2−1＝3
   **交点は (2, 3)**（検算: x＋y＝2＋3＝5 ✓、y＝2×2−1＝3 ✓——両方の式を満たす。x＝2 だけでは交点の答えにならないことに注意）
4. x＋y＝7 より y＝−x＋7。x−y＝1 より y＝x−1。同じ y になる x を探す:
   −x＋7＝x−1
   8＝2x
   x＝4、y＝4−1＝3
   **交点は (4, 3)**（検算: 4＋3＝7 ✓、4−3＝1 ✓——両方の式を満たす）
5. (1) **×**。まちがい: 両辺を2で割るときに、右辺の −x を2で割っていない。2y＝−x＋8 の両辺を2で割るなら、右辺は**すべての項**を2で割って y＝−(1/2)x＋4。（検算: 正しい式で x＝2 のとき y＝3——2＋2×3＝8 ✓。まちがいの式 y＝−x＋4 で x＝2 のとき y＝2——2＋2×2＝6 で 8 にならない ✗）
   (2) **○**。交点は2つの直線の両方に乗っている点なので、2つの方程式のどちらも成り立たせる——「同時に満たす組」である。（本文・主概念2のとおり）

### stretch

**S1**
2x＋y＝10 をyについて解くと y＝−2x＋10。
- 傾き: どちらも **−2**（同じ）。切片: 6 と 10（ちがう）。
- 同じ x での2つの y の差: (−2x＋10)−(−2x＋6)＝4。−2x どうしが消えるので、差は x がいくつでも 4 のまま。
- 差が 0 になる x はない＝同じ y になる x がない——2つの直線は**交わらない**（傾きが同じで切片がちがう2直線は平行）。

**したがって、2つの式を同時に満たす x, y の組は1つもない。**（検算: x＝0, 1, 2, 3 での y の差はすべて 4 ✓）
L01のstretchで調べた「ペースが同じ2本の式」（差がいつまでも変わらない）は、座標平面で見ると、決して交わらない平行な2直線だった——ということ。

## L07 一次関数の利用——式が使える範囲まで考える

<!-- 検算の型（L07・利用題）: ①数の点検＝出てきた値を式に戻す ②場面の点検＝値が変域の中にあるか・場面に合うか（L01「スタートとペースの点検」の拡張・L07で導入）。 -->

### 練習

1. <!-- 旧ID: ex_L7_check_02 -->
   x＝5 のとき y＝3×5＋4＝19
   **5分後の深さは19cm。x＝15 のとき、この式はこの場面を正しく表さない。**
   理由: x＝15 を入れれば y＝49 と計算はできるが、x＝15 は変域 0 ≤ x ≤ 12 の外。12分で満水になり、それ以降は「水面が毎分3cmずつ上がる」という前提がくずれるので、計算はできても y＝3x＋4 は15分後のこの場面を正しく表さない。
   （検算: 数の点検 3×5＋4＝19 ✓／場面の点検 0 ≤ 5 ≤ 12 で変域内 ✓・15は変域外 ✓）
2. (1) 2x が増えた分、＋6 がはじめの高さ。**y＝2x＋6**（検算: x＝0 で y＝6＝はじめの高さ ✓、x＝1 で y＝8＝毎分2cm増 ✓）
   (2) 30＝2x＋6 → 24＝2x → x＝12　**12分後**（検算: 数の点検 2×12＋6＝30＝満水 ✓）
   (3) **x の変域 0 ≤ x ≤ 12、y の変域 6 ≤ y ≤ 30**（検算: 両はしの代入 x＝0 → y＝6・x＝12 → y＝30 ✓／場面の点検: はじめの6cmから満水の30cmまで ✓）
3. (1) 0＝−4x＋20 → 4x＝20 → x＝5　**5分後**（検算: 数の点検 −4×5＋20＝0 ✓）
   (2) **x の変域 0 ≤ x ≤ 5、y の変域 0 ≤ y ≤ 20**。a＝−4 が負なので x が大きいほど y は小さい——x＝0 で y＝20（大きい方）、x＝5 で y＝0（小さい方）と、両はしの大小が入れかわる。（検算: 両はしの代入 ✓／場面の点検: 20Lから空の0Lまで ✓）
   (3) y＝−4×7＋20＝**−8**。水の量が負になることはないので、**場面では意味がない**。x＝7 は変域 0 ≤ x ≤ 5 の外——5分で空になったあとは「毎分4Lずつぬける」という前提がくずれている。（検算: 場面の点検で変域外 ✓）
4. <!-- 旧ID: ex_L7_check_01 -->
   はじめの差20mが、1分ごとに 80−60＝20m ずつ縮まるので 20÷20＝1
   **1分後**。式で見ると A: y＝60x＋20、B: y＝80x。追いつくとき2つの y が等しいから 60x＋20＝80x → 20＝20x → x＝1。
   （検算: 数の点検 x＝1 で A＝60×1＋20＝80m・B＝80×1＝80m——同じ地点にいる ✓／場面の点検 x＝1 は出発後（x ≥ 0）で変域内 ✓）
5. 答えの例（式を使う場合）: 「**2人の進み方を表す2つの式**を使って、**y が等しくなるときの方程式 60x＋20＝80x を解いて**、**追いつく時刻 x を求める**。」
   答えの例（グラフを使う場合）: 「**2つの式のグラフ**を使って、**2直線の交点の x 座標を読み取って**、**追いつく時刻を求める**。」
   どちらの道でも、「何を使って・どうやって・何を求める」の3つが入っていれば正解。「交点を見れば分かる」だけでは、どうやって何を求めるのかが伝わらないので、説明として不十分。
   （検算: どちらの方法も問4と同じ x＝1 に行き着く ✓——式は問4で解済み、グラフの交点は2式に x＝1 を代入して同じ点 (1, 80) になることで確認）

### stretch

**S1**
(1) 50x＝60x＋20 → −10x＝20 → **x＝−2**
(2) この場面で式が使えるのは出発してから、つまり x ≥ 0 の範囲。**x＝−2 はこの変域の外なので、BさんはAさんに追いつけない**。場面のようすから見ても、Bさん（毎分50m）はAさん（毎分60m）より遅いので、差は縮まらずに開いていく。実際、2人の差は (60x＋20)−50x＝10x＋20 で、x＝0, 1, 2, 3 のとき 20, 30, 40, 50m と増え続ける。「方程式の解が出ても、変域の外なら場面では起こらない」——式の答えを場面に戻して読む、この章の点検そのものだ。
（検算: 数の点検 x＝−2 を両式に代入すると 50×(−2)＝−100・60×(−2)＋20＝−100 で式の上では確かに一致 ✓／場面の点検 時間が負なので場面では意味がない＝「追いつく時刻はない」✓／差 10x＋20 は x ≥ 0 でつねに20以上 ✓）

## L08 章末まとめ——表・式・グラフ・場面を行き来する

<!-- 検算の型: 式を求める問題は x＝0（はじめの量）と与えられた点の代入、交点は両式への代入、変域は端の値の確認。 -->

### 3部屋の自己チェック（答えの例）

- 部屋1: a は「x が1増えるときの y の変わり方（ペース）」、b は「x＝0 のときの y（はじめの量）」／「＋2」は時間がたっても変わらないはじめの量で、増えるペースは 3x の3だけが表すから／割るのは**増加量どうし**（yの増加量 ÷ xの増加量。y÷x ではない）／変化の割合は増え方であり、b はスタート量を決めるだけで増え方に関係しないから（どちらも a＝3）。

- 部屋2: a は傾き、b は切片として見える／最初に打つ点は y 軸上の (0, b)／右下がりの傾きは**負**——数を読む前に「右へ進むと上がるか下がるか」を言葉にする／手がかりは**2つ**必要（決めるものが a と b の2つだから）／2点の **x 座標がちがうこと**の確認が先。

- 部屋3: y について解いて y＝ax＋b の形にする／交点は座標平面上の点なので **(x, y) の組**で答える／交点は2つの直線の両方に乗っている点＝2つの方程式のどちらにも当てはまる組だから、それが連立方程式の解といえる／y＝3x＋4 に x＝100 を入れれば計算はできるが、水そうは12分で満水になるので場面では使えない——式が場面を表すのは変域の中だけ／変域は **y にもある**（x の変域に対応して y の変域が決まる）。

**S1**

| x | 0 | 1 | 2 | 3 |
|---|---:|---:|---:|---:|
| y＝2x＋3 | 3 | 5 | 7 | 9 |
| y＝2x−1 | −1 | 1 | 3 | 5 |
| 差 | 4 | 4 | 4 | 4 |

y＝2x＋3 と y＝2x−1: 差はいつも 4 のまま変わらない（式の差 (2x＋3)−(2x−1)＝4——増えた分 2x どうしが消える）。同じ y になる x がないので、**この2本は交わらない**。
