# レッスンマップ — 中1英語「be動詞で人・ものの状態を伝える」（全4レッスン）

## 設計判断（レッスン数の根拠）

- **4レッスン**とする（調べの記録の執筆契約1のレンジ「子単元1本あたり3〜5」内）。根拠: 教科書2社実測で開隆堂はbe動詞（肯定・否定・疑問）に5時間、東京書籍はUnit 1の3 Part＋対比まとめ2時間（調べの記録の教科書の単元配置の節・令和7年度用2社の範囲）。本子単元は**疑問文を含まない**（疑問文の裁定: 産出なし・受容素材も--contrast限定）ため、5時間からの縮小が整合的。親単元合計9〜13の枠には 4＋4＋4＝12 で収まる（各5だと15で超過するため親側で上限管理）。
- 4レッスンを超えたら未習先取り（疑問文・三単現・SVC拡張・過去形）の混入を疑う（調べの記録の執筆契約1）。

## 本子単元の中核（調べの記録の子単元配分の節の--be行）

「**be動詞は1文に1つ・主語の直後**」の型の確立。

1. **主語を立てる**——日本語では省略される傾向にある主語を明示的に立てる活動（令和元年度報告書の指導提言由来・主語省略）。本親単元での初出はここ。
2. **動詞脱落の予防**——主語の直後にbeを必ず置く（設計根拠: 動詞脱落型。詳細はteacher_notes）。
3. **is多重挿入の予防**——「beは1文に1つ」の自己チェックの型（設計根拠: is多重挿入型。詳細はteacher_notes）。

## スコープ（疑問文の裁定の反映・do_not_cover）

- 扱う: **be動詞の肯定文・否定文**（am / are / is、主語は I / you / this / that / he / she / it / 単数の人名・もの）。短縮形 I'm / isn't / aren't。
- 扱わない: **疑問文**（産出・受容とも本子単元ではゼロ。受容判定素材は--contrast限定〔疑問文の裁定の第2項〕）／一般動詞（次子単元）／三単現-s・does／be動詞以外のSVC（look/become等）／未来・過去表現／冠詞の規則説明（a student / a soccer fan はかたまり提示のみ）／カタカナ発音表記（ゼロ）。
- 複数主語（we / they＋are）は本子単元では中心に置かない（負荷1点/レッスンの管理。単数系＋youで型を確立し、拡張は後続の運用に委ねる）。

## 例文・語彙の方針

- 全例文は**新規自作・架空**。人物は架空名（Aoki Ren・Mori Aiko——既刊 introducing-yourself-and-others の「姓＋名ローマ字・架空人物」方針に整合）。実在人物ゼロ・教科書転載ゼロ。
- 語彙は小学校話題圏＋カタカナ資産語を中心に最小限: student / fan / soccer / tennis / music / game / happy / hungry / busy / fine / new / kind / late / big / bag / ball / desk / school / friend / brother / sister / from 〜。カタカナ語（サッカー・テニス・ファン等）はズレを明示して踏み台にする（カタカナ語・干渉チェック表の検査項目②）。
- 冠詞つきの語と、my bag のように持ち主を表す語つきの語は**かたまり**で提示する（a student / a soccer fan / my bag）。冠詞の規則説明は置かない。
