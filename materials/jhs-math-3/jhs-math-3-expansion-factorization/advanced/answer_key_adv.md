## 第1節 x²の係数が1でない2次式

1. (1) ac＝3 → (a, c)＝(1, 3)。bd＝8 → (1, 8)(8, 1)(2, 4)(4, 2)。表で ad＋bc＝10 を探すと (b, d)＝(2, 4): 1×4＋2×3＝10 ✓
   3x²＋10x＋8＝**(x＋2)(3x＋4)**
   検算（展開で戻す）: (x＋2)(3x＋4)＝3x²＋4x＋6x＋8＝3x²＋10x＋8 ✓
   ※(x＋4)(3x＋2) とする誤りに注意——定数項の積8は合うが、真ん中は 1×2＋4×3＝14 で外れる。(b, d) の順序を入れ替えたものは**別の候補**として1行ずつ照合する。
   (2) ac＝4 → (1, 4)(2, 2)。bd＝−15 → 異符号の組 (1, −15)(−1, 15)(3, −5)(−3, 5)(5, −3)(−5, 3)(15, −1)(−15, 1)。(a, c)＝(2, 2)、(b, d)＝(−5, 3) で ad＋bc＝2×3＋(−5)×2＝−4 ✓
   4x²−4x−15＝**(2x−5)(2x＋3)**
   検算（展開で戻す）: (2x−5)(2x＋3)＝4x²＋6x−10x−15＝4x²−4x−15 ✓
   ※検算で真ん中が ＋4x になったら、符号の配置ミス——(2x＋5)(2x−3) は 4x²＋4x−15。b, d の符号を両方入れ替えると真ん中の符号だけ反転する、という本文の性質そのものなので、かっこの中の符号を総入れ替えすれば直る。
   (3) ac＝6 → (1, 6)(2, 3)。bd＝−6。もとの式に共通因数がないので、(3x−3)・(2x＋2) のような中に共通因数が残る候補は除外して調べると、(a, c)＝(2, 3)、(b, d)＝(3, −2) で ad＋bc＝2×(−2)＋3×3＝5 ✓
   6x²＋5x−6＝**(2x＋3)(3x−2)**
   検算（展開で戻す）: (2x＋3)(3x−2)＝6x²−4x＋9x−6＝6x²＋5x−6 ✓
   ※(2x−3)(3x＋2) は真ん中が 2×2＋(−3)×3＝−5 で符号が逆。真ん中の符号だけ合わないときは、b, d の符号の総入れ替えを疑う。
2. 地図(1)——共通因数3が先: 6x²＋21x＋9＝3(2x²＋7x＋3)。かっこの中は例題1と同じ式で、
   6x²＋21x＋9＝3(2x²＋7x＋3)＝**3(x＋3)(2x＋1)**
   検算（展開で戻す）: 3(x＋3)(2x＋1)＝3(2x²＋7x＋3)＝6x²＋21x＋9 ✓
   ※(3x＋9)(2x＋1) も展開すると 6x²＋21x＋9 に戻ってしまうが、因数 3x＋9 の中に共通因数3が残っており**不完全**（L05の完了チェック）。「展開で戻る」だけでは不完全さは検出できない——完了判定と検算は役割の違う2つの検査である（L08）。

## 第2節 3項の平方

3. a＝3x、b＝y、c＝−2 として公式へ。平方3つ: 9x²・y²・4。2倍の積3つ: 2×3x×y＝6xy、2×y×(−2)＝−4y、2×(−2)×3x＝−12x。
   (3x＋y−2)²＝**9x²＋6xy＋y²−12x−4y＋4**
   検算（数値代入）: x＝1, y＝1 のとき、左辺＝(3＋1−2)²＝2²＝4、右辺＝9＋6＋1−12−4＋4＝4 ✓
   ※落ちやすいのは 2ca に当たる −12x——ab・bc の2本だけ点検して安心しない。また −4y を −2y と書く誤り（「2倍」の忘れ）は、数値代入の検算が拾ってくれる。
4. 項が6つ→3項の平方の逆向きを疑う。平方の候補: 4x²＝(2x)²、y²＝yの平方、1＝1²。「2倍の積」3本の点検: 2×2x×y＝4xy ✓、2×y×1＝2y ✓、2×1×2x＝4x ✓。2x の符号を＋に固定すると、決めるのは y と 1 の符号——2x を含む 4xy・4x の2本が＋なので b＝＋y・c＝＋1 と確定、残る 2y で照合 ✓。
   4x²＋4xy＋y²＋4x＋2y＋1＝**(2x＋y＋1)²**
   検算（展開で戻す）: (2x＋y＋1)² は a＝2x、b＝y、c＝1 の公式で 4x²＋y²＋1＋4xy＋2y＋4x＝4x²＋4xy＋y²＋4x＋2y＋1 ✓
   ※定数項の「1」を平方候補と見ずに素通りして、(2x＋y)²＋… の形でこねて止まるのが典型のつまずき。1＝1² も立派な平方である（L05の「くくり出した1を消さない」と同じく、1は忘れられやすい）。

## 第3節 公式の組合せ——多段

5. (1) 地図(1): 共通因数2 → 2(4x²−9y²)。地図(2): (2x)²−(3y)² の平方−平方（L07 S2の型）。
   8x²−18y²＝2(4x²−9y²)＝**2(2x＋3y)(2x−3y)**
   検算（展開で戻す）: (2x＋3y)(2x−3y)＝4x²−9y²、2倍して 8x²−18y² ✓
   ※共通因数2を見落とすと、8x² が平方に見えず（8は平方数でない）手が止まる。「地図の(1)を飛ばさない」（L08）が係数付きでも効く。
   (2) x⁴−81＝(x²)²−9²＝(x²＋9)(x²−9)。x²−9 に地図を再適用して、
   x⁴−81＝**(x²＋9)(x＋3)(x−3)**
   検算（展開で戻す）: (x＋3)(x−3)＝x²−9、(x²＋9)(x²−9)＝x⁴−81 ✓
   ※(x²＋9)(x²−9) で止めるのが典型の不完全。また x²＋9 を (x＋3)² と誤らない——展開すれば x²＋6x＋9 で別の式。x²＋9 は、積9・和0になる整数の組がないので、これ以上分解できない（完了の根拠）。
6. 地図(1): 共通因数3 → 3(a⁴−16b⁴)。地図(2)を2段: a⁴−16b⁴＝(a²＋4b²)(a²−4b²)、さらに a²−4b²＝(a＋2b)(a−2b)。
   3a⁴−48b⁴＝3(a⁴−16b⁴)＝3(a²＋4b²)(a²−4b²)＝**3(a²＋4b²)(a＋2b)(a−2b)**
   検算（展開で戻す）: (a＋2b)(a−2b)＝a²−4b²、(a²＋4b²)(a²−4b²)＝a⁴−16b⁴、3倍して 3a⁴−48b⁴ ✓
   ※a²＋4b² を (a＋2b)² と誤らない——展開すれば a²＋4ab＋4b²。「平方＋平方」の**2次式**（x²＋9・a²＋4b² など）は、積が正で和が0になる整数の組がないので分解できない。4次の「平方＋平方」x⁴＋4 は別で、演習8で開く。

## 第4節 複2次式

7. (1) x²＝M と置くと M²−10M＋9。積9・和−10 → (−1, −9)。(M−1)(M−9)、Mを戻して (x²−1)(x²−9)——両方とも平方−平方で再適用。
   x⁴−10x²＋9＝(x²−1)(x²−9)＝**(x＋1)(x−1)(x＋3)(x−3)**
   検算（展開で戻す）: (x＋1)(x−1)＝x²−1、(x＋3)(x−3)＝x²−9、(x²−1)(x²−9)＝x⁴−10x²＋9 ✓
   ※(x²−1)(x²−9) で止めるのが典型の不完全。4次では「戻したら地図を再適用」を2つの因数**両方**に行う。
   (2) x²＝M と置くと M²−3M−4。積−4・和−3 → (−4, 1)。(M−4)(M＋1)、Mを戻して (x²−4)(x²＋1)。x²−4 は平方−平方で開き、x²＋1 は積1・和0の整数の組がなく、これ以上分解できない。
   x⁴−3x²−4＝(x²−4)(x²＋1)＝**(x＋2)(x−2)(x²＋1)**
   検算（展開で戻す）: (x＋2)(x−2)＝x²−4、(x²−4)(x²＋1)＝x⁴＋x²−4x²−4＝x⁴−3x²−4 ✓
   ※x²＋1 を無理に開こうとして止まる、または「1次まで割れないから途中でまちがえた」と思い込むのが典型のつまずき。**分解できない2次の因数が残るのは正常**で、「割れない根拠」まで書けて完了である。
8. x⁴＋4＝(x⁴＋4x²＋4)−4x²＝(x²＋2)²−(2x)²——平方−平方の形が現れた。和と差の積で、
   ＝(x²＋2＋2x)(x²＋2−2x)＝**(x²＋2x＋2)(x²−2x＋2)**
   検算（展開で戻す）: ((x²＋2)＋2x)((x²＋2)−2x)＝(x²＋2)²−(2x)²＝x⁴＋4x²＋4−4x²＝x⁴＋4 ✓
   ※たした 4x² を**引き忘れる**と式そのものが変わってしまう——「たして引く」は必ずセット。また、答えの各因数は降べきの順（x²、x、定数）に整理して書く。2つの因数はどちらも、積2・和±2になる整数の組がないので、これ以上分解できない（完了の根拠）。
