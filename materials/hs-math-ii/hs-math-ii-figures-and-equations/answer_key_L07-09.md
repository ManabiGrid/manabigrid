## L07 円の方程式——中心と半径・標準形と一般形

**問1**
(1) **(x−3)²＋(y＋2)²=16**
　検算: 中心から右へ 4 の点 (7, −2) → 16＋0=16 ✓
(2) **x²＋y²=7**
　検算: (√7, 0) → 7＋0=7 ✓
(3) 半径の2乗は中心 (−1, 4) と点 (2, 0) の距離の2乗で (2＋1)²＋(0−4)²=9＋16=25。**(x＋1)²＋(y−4)²=25**
　検算: (2, 0) → 9＋16=25 ✓
(4) 中心は中点 ((−3＋5)/2, (1＋7)/2)=(1, 4)。半径の2乗は (1＋3)²＋(4−1)²=16＋9=25。**(x−1)²＋(y−4)²=25**
　検算: もう一方の端 (5, 7) → 16＋9=25 ✓
　※(4) で半径を「2点間の距離」としてしまう誤りに注意。直径の両端の距離は直径で、半径はその半分（ここでは 10 の半分の 5）。

**問2**
(1) (x−4)²−16＋(y＋3)²−9=0 より (x−4)²＋(y＋3)²=25。**中心 (4, −3)、半径 5 の円**
　検算: 中心から右へ 5 の点 (9, −3) をもとの式に → 81＋9−72−18=0 ✓
(2) (x＋2)²−4＋(y−1)²−1＋1=0 より (x＋2)²＋(y−1)²=4。**中心 (−2, 1)、半径 2 の円**
　検算: (0, 1) → 0＋1＋0−2＋1=0 ✓
(3) x²＋(y−3)²−9＋9=0 より x²＋(y−3)²=0。これを満たすのは x=0 かつ y=3 だけ。**点 (0, 3) の1つだけ**（円ではない）
(4) (x＋1)²−1＋(y＋2)²−4＋6=0 より (x＋1)²＋(y＋2)²=−1。左辺は 0 以上なので、**この方程式を満たす点はない**（図形を表さない）
　※(3)(4) を「半径 0 の円」「半径が虚数の円」などと書かない。円を表すのは右辺が正のときだけである。

**問3**
(1) **中心 (−2, 1)、半径 3**
(2) y=0 を代入して (x＋2)²＋1=9、(x＋2)²=8、x＋2=±2√2。交点は **(−2＋2√2, 0)、(−2−2√2, 0)**
　検算: 中心の y 座標 1 は半径 3 より小さいので、円は x 軸と2点で交わるはずである ✓。(−2＋2√2)＋2=2√2、その2乗は 8、8＋1=9 ✓
(3) 点 (1, 1) と中心の距離は √((1＋2)²＋(1−1)²)=√9=3 で半径に等しいから、**周上**。点 (0, 3) と中心の距離は √((0＋2)²＋(3−1)²)=√8=2√2 で、2√2<3 だから半径より小さく、**内部**。
　※周上・内部・外部は、中心からの距離と半径の大小で決まる。方程式の左辺に代入した値が 9 と等しい・小さい・大きい、で判定してもよい（(0, 3) では 4＋4=8<9）。

**問4** 一般形 x²＋y²＋lx＋my＋n=0 に3点を代入する。
A(1, 0): 1＋l＋n=0 ……①　B(4, 3): 25＋4l＋3m＋n=0 ……②　C(0, 3): 9＋3m＋n=0 ……③
①から n=−1−l。③に入れて 9＋3m−1−l=0、すなわち 3m−l=−8。②に入れて 25＋4l＋3m−1−l=0、すなわち 3l＋3m=−24、l＋m=−8。2式から m=−8−l を 3m−l=−8 に入れて −24−3l−l=−8、l=−4、m=−4、n=3。
**x²＋y²−4x−4y＋3=0**、平方完成して (x−2)²＋(y−2)²=5。**中心 (2, 2)、半径 √5**
検算: A → 1＋0−4−0＋3=0 ✓、B → 16＋9−16−12＋3=0 ✓、C → 0＋9−0−12＋3=0 ✓

**問5**
(1) 平方完成すると (x＋2)²＋(y−1)²=5−k。円を表すのは右辺が正のときだから、5−k>0、すなわち **k<5**
(2) k=5 のとき (x＋2)²＋(y−1)²=0 で、**点 (−2, 1) の1つだけを表す**
　検算: k=4（k<5 の例）なら右辺 1 で半径 1 の円、k=6 なら右辺 −1 で図形なし ✓

**問6** 解答例:「円は、中心 (a, b) からの距離が r である点の集合である。点 (x, y) と (a, b) の距離は距離の公式で √((x−a)²＋(y−b)²) と表せるから、円上の点は √((x−a)²＋(y−b)²)=r を満たす。両辺は 0 以上なので2乗しても同じ条件で、(x−a)²＋(y−b)²=r² が円の方程式になる。」（「距離が r」を距離の公式で書いて2乗する、という筋が入っていればよい。）

**S1**
(1) 一般形に代入して、A(−2, 0): 4−2l＋n=0、B(4, 0): 16＋4l＋n=0、C(0, 4): 16＋4m＋n=0。第2式から第1式を引いて 12＋6l=0、l=−2。第1式から n=−8。第3式から 16＋4m−8=0、m=−2。**x²＋y²−2x−2y−8=0**、すなわち (x−1)²＋(y−1)²=10。**M(1, 1)**
　検算: A → 4＋4−8=0 ✓、B → 16−8−8=0 ✓、C → 16−8−8=0 ✓
(2) A(−2, 0)、B(4, 0) は x 軸上にあり、中点は (1, 0)。AB の垂直二等分線は、中点を通り x 軸に垂直な直線 x=1 である。M の x 座標は 1 だから、**M はこの直線上にある** ✓
(3) AC の中点は (−1, 2)、AC の傾きは (4−0)/(0−(−2))=2 だから、垂直二等分線の傾きは −1/2。y−2=−(1/2)(x＋1)、すなわち **x＋2y−3=0**。M(1, 1) を代入すると 1＋2−3=0 で、**M はこの直線上にもある** ✓
　説明の例:「円の中心 M は A、B、C から等しい距離にある。A、B から等距離の点の集合が AB の垂直二等分線、A、C から等距離の点の集合が AC の垂直二等分線だから、M はその両方の上にあり、2直線の交点になる。」
（指導メモ: (3) の説明は、L10 の「条件を満たす点の集合」の見方の予告になっている。中1の作図（外接円の中心）と結びつけて確認させるとよい。）

## L08 円と直線の位置関係——共有点の個数を2つの方法で

**問1**
(1) y=x−2 を代入して x²＋(x−2)²=10、2x²−4x−6=0、x²−2x−3=0、(x−3)(x＋1)=0。x=3 のとき y=1、x=−1 のとき y=−3。**(3, 1)、(−1, −3)**
　検算: (3, 1) → 9＋1=10、1=3−2 ✓。(−1, −3) → 1＋9=10、−3=−1−2 ✓
(2) y=x＋2√2 を代入して x²＋(x＋2√2)²=4、2x²＋4√2 x＋8=4、x²＋2√2 x＋2=0、(x＋√2)²=0。x=−√2（重解）、y=−√2＋2√2=√2。共有点は **(−√2, √2) の1個**（直線は円に接している）
　検算: 2＋2=4 ✓。原点と直線 x−y＋2√2=0 の距離は 2√2/√2=2 で半径に等しい ✓
　※重解のときは共有点が1個。「解が1つだから共有点なし」と読み違えない。

**問2** y=−x＋k を代入して x²＋(−x＋k)²=9、2x²−2kx＋k²−9=0。判別式は D=(−2k)²−4×2×(k²−9)=4k²−8k²＋72=72−4k²=4(18−k²)。
D>0 は k²<18、すなわち −3√2<k<3√2。よって
**−3√2<k<3√2 のとき2個、k=±3√2 のとき1個、k<−3√2 または 3√2<k のとき0個**
検算（方法②）: 原点と直線 x＋y−k=0 の距離は |k|/√2。これが半径 3 より小さい条件は |k|<3√2 で一致 ✓

**問3** 中心 (2, 1)、半径 2。
(1) d=|3×2＋4×1|/√(9＋16)=10/5=2。d=r だから **1個**（接する）
(2) d=|2−1＋1|/√(1＋1)=2/√2=√2。√2<2 だから **2個**
(3) d=|4×2−3×1−20|/√(16＋9)=|−15|/5=3。3>2 だから **0個**
　※(1) は計算の結果 d=r になる例。図を描くと、直線 3x＋4y=0 は原点を通り、中心 (2, 1) からちょうど 2 離れている。

**問4** 原点と直線の距離は d=|15|/√(9＋16)=15/5=3。半径 5 だから、弦の半分は √(25−9)=√16=4。弦の長さは **8**
検算: d<r（3<5）で2点で交わる ✓。3²＋4²=5² ✓

**問5** 原点と直線 4x＋3y−10=0 の距離は d=|−10|/√(16＋9)=10/5=2。
(1) 接するのは d=r のときだから **r=2**
(2) 共有点をもつのは d≦r のときだから **r≧2**
　検算: r=2 で接し、r=3 なら d<r で2個、r=1 なら d>r で0個 ✓

**問6** 解答例:「判別式による方法は、連立して得た二次方程式をそのまま解けば共有点の座標まで求められる点が長所である。中心と直線の距離による方法は、点と直線の距離の公式1回で個数が分かり、図の上で d と r を見比べられるので結果の見当がつきやすい点が長所である。」（座標が求まる／計算が軽く図と対応する、の2点が挙がっていればよい。）

**S1** 弦の長さが 2√6 だから、弦の半分は √6。半径は √10 だから、中心と直線の距離 d は d²=10−6=4、d=2。原点と直線 x−y＋k=0 の距離は |k|/√2 だから、|k|/√2=2、|k|=2√2。**k=±2√2**
検算: k=2√2 のとき、x²＋(x＋2√2)²=10 より x²＋2√2 x−1=0、x=−√2±√3。2つの共有点の x 座標の差は 2√3、y 座標の差も 2√3（傾き 1）だから、弦の長さは √((2√3)²＋(2√3)²)=√24=2√6 ✓
（指導メモ: 「弦の長さ→d→k」の向きは、L08 §4 の「d→弦の長さ」の逆向き。公式を逆向きに使う型の1つとして位置づける。）

## L09 円の接線——半径に垂直・円外の点から

**問1** 円 x²＋y²=r² 上の点 (x₁, y₁) における接線は x₁x＋y₁y=r²。
(1) **2x−3y=13**
　検算: (2, −3) は円上（4＋9=13）✓。原点との距離は 13/√13=√13 で半径に等しい ✓
(2) 0×x＋(−4)y=16 より **y=−4**（x 軸に平行な直線）
　検算: (0, −4) は円上（0＋16=16）で、この直線上にある ✓
(3) (−3)x＋0×y=9 より **x=−3**（y 軸に平行な直線）
　検算: (−3, 0) は円上（9＋0=9）で、この直線上にある ✓
　※(2)(3) は、傾きを使う導き方では扱えない場合だが、公式はそのまま使える。x=−3 は関数のグラフではないが直線である（L04）。

**問2** 接点を (x₁, y₁) とすると接線は x₁x＋y₁y=5。これが x−2y=5 と同じ直線で、右辺がどちらも 5 なので係数がそのまま一致するから x₁=1、y₁=−2。接点は **(1, −2)**
検算: (1, −2) は円上（1＋4=5）✓。原点と直線 x−2y−5=0 の距離は |−5|/√(1＋4)=5/√5=√5 で半径 √5 に等しく、**確かに接線である** ✓

**問3** 接点を (x₁, y₁) とすると、接線は x₁x＋y₁y=10 で、これが点 (2, 4) を通るから 2x₁＋4y₁=10、すなわち x₁=5−2y₁。接点は円上にあるから x₁²＋y₁²=10。代入して (5−2y₁)²＋y₁²=10、5y₁²−20y₁＋15=0、y₁²−4y₁＋3=0、(y₁−1)(y₁−3)=0。y₁=1 のとき x₁=3、y₁=3 のとき x₁=−1。
接点 **(3, 1)** における接線 **3x＋y=10**、接点 **(−1, 3)** における接線 **−x＋3y=10**
検算: 点 (2, 4) を代入して 6＋4=10 ✓、−2＋12=10 ✓。接点はどちらも円上（9＋1=10、1＋9=10）✓

**問4** 点 (3, 1) を通り傾き m の直線は y−1=m(x−3)、すなわち mx−y−3m＋1=0。原点との距離が半径 3 に等しいから |1−3m|/√(m²＋1)=3。両辺を2乗して (1−3m)²=9(m²＋1)、1−6m＋9m²=9m²＋9、−6m=8、m=−4/3。この方法で求まるのは **4x＋3y−15=0** の1本だけである。
理由: y−1=m(x−3) の形は、点 (3, 1) を通る直線のうち **y 軸に平行な直線 x=3 を表せない**。直線 x=3 と原点の距離は 3 で半径に等しいから、x=3 も接線である。接線は **x=3、4x＋3y−15=0** の2本。
検算: 4x＋3y−15=0 と原点の距離は 15/5=3 ✓。点 (3, 1) を代入すると 12＋3−15=0 ✓。接点は、x=3 では (3, 0)、もう1本では垂直条件から求めると (12/5, 9/5) で、(12/5)²＋(9/5)²=(144＋81)/25=9 ✓
（指導メモ: 接点をおく方法（問3）ではこの見落としが起こらないことを対比させる。「接線は2本」を図で先に確かめる習慣がここで効く。）

**問5** 誤りは、**C₂ の中心と l の距離を、C₁ の半径と比べている**点である。「距離＝半径」の判定は、同じ円の中心と半径を組にして行う。
C₁ について: 中心 O(0, 0)、半径 3。O と l の距離は |−15|/√(9＋16)=15/5=3 で半径に等しいから、**l は C₁ に接する**。
C₂ について: 中心 (6, 8)、半径 2。この中心と l の距離は |18＋32−15|/5=35/5=7 で半径 2 と等しくないから、**l は C₂ に接しない**（7>2 なので、l は C₂ と共有点をもたない）。
検算: l と C₁ の接点は、O から l に下ろした垂線の足 (9/5, 12/5) で、(9/5)²＋(12/5)²=(81＋144)/25=9 ✓

**問6** 解答例:「接点 (x₁, y₁) と中心 O を結ぶ半径の傾きは y₁/x₁ で、接線はこの半径に垂直だから、接線の傾きは −x₁/y₁ である。接点を通るので y−y₁=−(x₁/y₁)(x−x₁) で、両辺に y₁ を掛けて整理すると x₁x＋y₁y=x₁²＋y₁² となる。接点は円上にあるので x₁²＋y₁²=r² であり、x₁x＋y₁y=r² が得られる。」（垂直条件で傾きを出す・接点を通る直線を書く・x₁²＋y₁²=r² で置き換える、の3段が入っていればよい。）

**S1** C₁ の半径 3、C₂ の半径 2 で、和は 5、差は 1。中心の間の距離は a。
- a=6: 6>5 だから **共有点 0個**。2つの円は離れている。
- a=5: 5=5 だから **共有点 1個**。2つの円は外側で接している。
- a=3: 1<3<5 だから **共有点 2個**。2つの円は2点で交わる。
- a=1: 1=1 だから **共有点 1個**。C₂ が C₁ の内側で接している。
- a=1/2: 1/2<1 だから **共有点 0個**。C₂ は C₁ の内部にあり、接していない。
検算: a=5 のとき、接点は x 軸上の (3, 0) で、C₁ 上（9=9）かつ C₂ 上（(3−5)²=4）✓。a=1 のとき、接点は (3, 0) で、C₂ 上（(3−1)²=4）✓
（指導メモ: 5つの場合を「d と r₁＋r₂・r₁−r₂ の大小」で分けるのは、L08 の「d と r の大小」と同じ発想であることを確認させる。この内容は学習指導要領解説にない発展扱い（L09 本文の guide）。）

**S2**
(1) C₂ は x²＋y²−12x−6y＋35=0、C₁ は x²＋y²−25=0。辺々引くと 12x＋6y−60=0、すなわち **2x＋y−10=0**
(2) 解答例:「共有点は C₁ の方程式と C₂ の方程式の両方を満たす。両方を満たす x、y は、2つの式を辺々引いた式も満たすから、共有点は (1) の直線の上にある。」
(3) **正しくない**。たとえば点 (0, 10) は 2x＋y−10=0 を満たすが、C₁ に代入すると 0＋100=100≠25 で C₁ 上にない。
(4) y=10−2x を C₁ に代入して x²＋(10−2x)²=25、5x²−40x＋75=0、x²−8x＋15=0、(x−3)(x−5)=0。x=3 のとき y=4、x=5 のとき y=0。共有点は **(3, 4)、(5, 0)**
　検算: (3, 4) → C₁: 9＋16=25 ✓、C₂: 9＋16−36−24＋35=0 ✓。(5, 0) → C₁: 25 ✓、C₂: 25−60＋35=0 ✓
（指導メモ: (2) と (3) は「A 上の点は B 上にある」と「B 上の点は A 上にある」の向きの違いを扱う。(2) の向きは言えるが (3) の逆向きは言えない。L10 の「逆の確認」と同じ論理の型である。）
