## L13 単元のまとめ——図形を点の集合として見る

**問1**
(1) 2x−y＋3=0 を y について解くと y=2x＋3。**傾き 2、y 軸との交点 (0, 3)**
(2) l に垂直な直線の傾きは −1/2（2×(−1/2)=−1）。点 (3, −1) を通るので y＋1=−(1/2)(x−3)、両辺を 2 倍して 2y＋2=−x＋3、すなわち **x＋2y−1=0**
　検算: (3, −1) → 3−2−1=0 ✓
(3) |2×3−(−1)＋3|/√(2²＋(−1)²)=|6＋1＋3|/√5=10/√5=**2√5**
　検算: (2) の直線と l の交点（垂線の足）は、x＋2y=1 と 2x−y=−3 を解いて (−1, 1)。点 (3, −1) との距離は √(16＋4)=√20=2√5 ✓

**問2**
(1) y 軸に平行な直線上の点は x 座標がすべて等しい。**x=−2**
(2) x=4 かつ y=−1 を満たす点だから **(4, −1)**
(3) 直線 x=−2 は y 軸に平行なので、それに垂直な直線は x 軸に平行で、点 (1, 3) を通るから **y=3**
(4) **いえない**。x=2 という1つの x の値に対して y の値が1つに決まらない（y はどんな値でもよい）ので、x の関数にならない。ただし、方程式 x=2 を満たす点 (x, y) の集合としては、確かに y 軸に平行な1本の直線である。
※(3) で「傾きの積が −1」を使おうとすると行き詰まる。x=−2 には傾きがないので、垂直は図で判断する（L05）。

**問3**
(1) 平方完成して (x＋1)²＋(y−2)²=9。**中心 (−1, 2)、半径 3**
　検算: 中心から右へ 3 の点 (2, 2) をもとの式に → 4＋4＋4−8−4=0 ✓
(2) 中心 (−1, 2) と直線 3x＋4y＋5=0 の距離は |−3＋8＋5|/√(9＋16)=10/5=2。2<3（半径）だから、**2点で交わる**
(3) 直線 y=x＋k を x−y＋k=0 と書く。中心 (−1, 2) との距離が半径 3 に等しいから |−1−2＋k|/√2=3、|k−3|=3√2、k−3=±3√2。**k=3＋3√2、3−3√2**
　検算: k=3＋3√2 のとき |3√2|/√2=3 ✓。k=3−3√2 のとき |−3√2|/√2=3 ✓
（指導メモ: (2) は判別式でも確かめられる。y=(−3x−5)/4 を代入する計算は重いので「個数だけなら距離」の使い分けを確認する場面にする。）

**問4** 「距離＝半径」の判定は、同じ円の中心と半径を組にして行う。
C₁ について: 中心 (2, 0)、半径 √5。中心と l の距離は |2−0＋3|/√(1＋4)=5/√5=√5 で、**C₁ の半径 √5 に等しいから、l は C₁ に接する**。
C₂ について: 中心 (0, 3)、半径 1。中心と l の距離は |0−6＋3|/√5=3/√5。(3/√5)²=9/5>1 だから 3/√5>1 で、**C₂ の半径 1 より大きいから、l は C₂ と共有点をもたない**。
検算: l と C₁ の接点は、中心 (2, 0) から l に下ろした垂線の足で、l 上の点 (1, 2) は (1−2)²＋(2−0)²=1＋4=5 で C₁ 上にあり、l 上にもある（1−4＋3=0）✓
※C₁ の中心と C₂ の半径、C₂ の中心と C₁ の半径のような組合せで比べても、何も判定したことにならない。

**問5**
(1) (2, 1): (2−1)²＋1=2≦4 ✓、2＋1=3≧1 ✓。**含まれる**
　(0, 0): 1＋0=1≦4 ✓ だが、0≧1 は成り立たない。**含まれない**
　(1, −2): 0＋4=4≦4 ✓（円の境界線上）だが、1−2=−1≧1 は成り立たない。**含まれない**
(2) (x−1)²＋y²≦4 は円 (x−1)²＋y²=4（中心 (1, 0)、半径 2・実線）の内部と周。x＋y≧1 は直線 x＋y=1（実線）について、原点で 0≧1 が成り立たないので原点を含まない側。共通部分は、**円 (x−1)²＋y²=4 の内部と周のうち、直線 x＋y=1 について原点と反対の側（点 (2, 1) を含む側）にある部分**（境界線をどちらも含む）
　検算: (1) の3点の結果と一致する ✓

**問6** P(x, y)、Q(s, t) とおく。P は AQ の中点だから x=(8＋s)/2、y=t/2、すなわち s=2x−8、t=2y。Q は円上にあるから s²＋t²=16、代入して (2x−8)²＋(2y)²=16、両辺を 4 で割って (x−4)²＋y²=4。逆に、この円上の点 P(x, y) に対して Q(2x−8, 2y) をとると、Q は円 x²＋y²=16 上にあり、P は AQ の中点になる。求める軌跡は**中心 (4, 0)、半径 2 の円**
検算: Q=(4, 0) のとき中点は (6, 0) で (6−4)²＋0=4 ✓。Q=(0, 4) のとき中点は (4, 2) で 0＋4=4 ✓

**S1**
(1) y=x＋1 を代入して x²＋(x＋1)²=25、2x²＋2x−24=0、x²＋x−12=0、(x＋4)(x−3)=0。**(3, 4)、(−4, −3)**
　検算: 9＋16=25、4=3＋1 ✓。16＋9=25、−3=−4＋1 ✓
(2) 円 x²＋y²=25 上の点 (x₁, y₁) における接線は x₁x＋y₁y=25。(3, 4) では **3x＋4y=25**、(−4, −3) では −4x−3y=25、すなわち **4x＋3y＋25=0**
　検算: 原点との距離はそれぞれ 25/5=5、25/5=5 で半径に等しい ✓
(3) (−2, 3): 4＋9=13≦25 ✓、3≧−2＋1=−1 ✓。**含まれる**
(4) y−x=k とおくと、これは傾き 1 の直線で、l と平行である。領域は円の内部と周のうち l の上側（y−x≧1 の側）なので、k≧1 の範囲で直線を上へ動かす。k が最大になるのは直線が円に接するときで、原点との距離 |k|/√2=5 から k=5√2（接点は原点から直線 −x＋y=5√2 に下ろした垂線の足 (−5√2/2, 5√2/2)。この点は y−x=5√2≧1 を満たすので領域に含まれる）。k が最小になるのは直線が l に重なるときで、k=1。**最大値 5√2**（点 (−5√2/2, 5√2/2)）、**最小値 1**（直線 y=x＋1 上の、(−4, −3) から (3, 4) までの線分上のすべての点）
　検算: (−5√2/2)²＋(5√2/2)²=25/2＋25/2=25 で円上 ✓。5√2/2−(−5√2/2)=5√2 ✓。最小値を与える点の例 (0, 1) → 1−0=1、0＋1≦25 ✓
（指導メモ: (4) は境界に円が混ざる領域での最大・最小。多角形なら頂点だけ調べればよいが、円が境界のときは「直線が円に接する点」が答えになることを L12 の guide と結びつける。最小値は辺（線分）全体で達成される型でもある。）
