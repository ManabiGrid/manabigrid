## L10 軌跡——条件を満たす点の集合と「逆の確認」

**問1** P(x, y) とおく。AP=BP は両辺が 0 以上だから AP²=BP² と同じ条件で、(x＋2)²＋(y−1)²=(x−4)²＋(y−3)²。展開して 4x＋4−2y＋1=−8x＋16−6y＋9、12x＋4y−20=0、すなわち 3x＋y−5=0。逆に、この直線上の点は式変形を逆にたどれるので AP=BP を満たす。求める軌跡は**直線 3x＋y−5=0**
垂直二等分線であることの確認: AB の中点 (1, 2) はこの直線上にある（3＋2−5=0）✓。AB の傾きは (3−1)/(4−(−2))=1/3、直線の傾きは −3 で、積は −1 ✓。よって AB の垂直二等分線である。
検算: 直線上の点 (0, 5) について、AP²=4＋16=20、BP²=16＋4=20 ✓

**問2** P(x, y) とおく。AP:BP=1:2 は 2AP=BP と同じで、両辺が 0 以上だから 4AP²=BP² と同じ条件。4(x²＋y²)=(x−6)²＋y²、4x²＋4y²=x²−12x＋36＋y²、3x²＋12x＋3y²−36=0、x²＋4x＋y²−12=0、(x＋2)²＋y²=16。逆に、この円上の点は式変形を逆にたどれるので AP:BP=1:2 を満たす。求める軌跡は**中心 (−2, 0)、半径 4 の円**
検算: 円上の点 (2, 0) → AP=2、BP=4 で 1:2 ✓。点 (−6, 0) → AP=6、BP=12 で 1:2 ✓
比を 1:1 に変えると: AP=BP となり、軌跡は **線分 AB の垂直二等分線、すなわち直線 x=3** になる（円ではなく直線）。
（指導メモ: 例題2の A、B と比の向きを変えた問題。比を変えると円の位置と大きさが変わり、1:1 で直線になることを、図で予想させてから式で確かめさせる。）

**問3** P(x, y) とおく。P は A、B と異なり、三角形 PAB ができる点とする。∠APB=90° は PA²＋PB²=AB² と同じ条件で、x²＋(y−2)²＋x²＋(y＋2)²=16、2x²＋2y²＋8=16、x²＋y²=4。これは線分 AB を直径とする円である。逆に、この円上の点は PA²＋PB²=AB² を満たすが、**A(0, 2) と B(0, −2) では三角形ができない**。求める軌跡は**円 x²＋y²=4 から2点 (0, 2)、(0, −2) を除いたもの**
検算: 円上の点 (2, 0) → PA²=4＋4=8、PB²=8、和 16=AB² ✓
※除く点を書き忘れて「円 x²＋y²=4」と答えるのは、逆の確認を省いたことになる。

**問4** P(x, y)、Q(s, t) とおく。P は AQ の中点だから x=(4＋s)/2、y=(2＋t)/2、すなわち s=2x−4、t=2y−2。Q は円上にあるから s²＋t²=9、代入して (2x−4)²＋(2y−2)²=9、両辺を 4 で割って (x−2)²＋(y−1)²=9/4。逆に、この円上の点 P に対して Q(2x−4, 2y−2) は円 x²＋y²=9 上にあり、P は AQ の中点になる。求める軌跡は**中心 (2, 1)、半径 3/2 の円**
検算: Q=(3, 0) のとき中点は (7/2, 1) で、(7/2−2)²＋0=9/4 ✓。Q=(0, 3) のとき中点は (2, 5/2) で、0＋(3/2)²=9/4 ✓
※半径を 9/4 と答えない。9/4 は半径の2乗で、半径は 3/2。

**問5** ここまでの議論だけから言えるのは**ア**である。「条件を満たす→式が成り立つ」を示しただけなので、条件を満たす点は円の上にあるとは言えるが、円の上の点が全部条件を満たすかはまだ分からない。軌跡が円全体であると結論するには、**逆に、円 x²＋y²=4 の上のどの点も条件を満たすこと（イ）を確かめる**必要がある。満たさない点があれば、その点を除いたものが軌跡になる。

**問6** 解答例:「例題3で (1)〜(3) から得た円の方程式だけでは、円の上の点がすべて元の条件を満たすとはまだ言えない。例題3では、条件から円 x²＋y²=9 が出てくるが、円上の2点 (−3, 0)、(3, 0) では三角形ができず条件を満たさないので、この2点を除かなければならない。逆の確認を書いてこそ、この除く点に気づける。」（「逆は別に確かめる必要がある」と「例題3の除く点」の2点が入っていればよい。）

**S1** P(x, y) とおく。円が2直線に接するとき、中心 P から2直線までの距離は等しく、その値が半径である。P と直線 y=0 の距離は |y|、P と直線 3x−4y=0 の距離は |3x−4y|/5 だから、|y|=|3x−4y|/5、すなわち 5|y|=|3x−4y|。|A|=|B| は「A=B または A=−B」と同じだから、5y=3x−4y または 5y=−(3x−4y)、すなわち x−3y=0 または 3x＋y=0。ただし半径は正なので距離は 0 でなく、2直線の交点である原点は除く。逆に、これら2直線上の原点以外の点は、2直線から等しい正の距離にあるので、その距離を半径とする円が2直線に接する。求める軌跡は**2直線 x−3y=0、3x＋y=0 から原点を除いたもの**
検算: 直線 x−3y=0 上の点 (3, 1) → y=0 との距離 1、3x−4y=0 との距離 |9−4|/5=1 ✓。直線 3x＋y=0 上の点 (1, −3) → 距離 3、|3＋12|/5=3 ✓
（指導メモ: 2直線のなす角を二等分する2本の直線が答えになる。「点と直線の距離」（L06）の公式を軌跡の条件に使う例。除く点（原点）を落とさないことが逆の確認の役目。）

## L11 不等式の表す領域——境界を描いて点で確かめる

**問1** 左辺 2x−3y＋6 に代入する。
(1) (0, 0): 6>0 が成り立つ。**含まれる**
(2) (3, 4): 6−12＋6=0。**境界線上**（不等号が > なので領域には含まれない）
(3) (−3, 2): −6−6＋6=−6 で、−6>0 は成り立たない。**含まれない**
(4) (1, −1): 2＋3＋6=11>0 が成り立つ。**含まれる**

**問2**
(1) 境界線は直線 y=−2x＋3 で、≧ なので**実線**。原点を代入すると 0≧3 は成り立たないので、**原点を含まない側（直線の上側）。境界線を含む**
(2) 境界線は直線 3x−2y=6 で、< なので**破線**。原点を代入すると 0<6 が成り立つので、**原点を含む側（直線の上側）。境界線を含まない**
(3) 境界線は直線 x=2（y 軸に平行）で、≦ なので**実線**。原点を代入すると 0≦2 が成り立つので、**原点を含む側（直線の左側）。境界線を含む**
(4) 境界線は直線 y=−1（x 軸に平行）で、> なので**破線**。原点を代入すると 0>−1 が成り立つので、**原点を含む側（直線の上側）。境界線を含まない**
検算: (2) で領域内の点 (0, 3) → 0−6<6 ✓、領域外の点 (4, 0) → 12<6 は成り立たない ✓

**問3**
(1) 境界線は円 (x＋1)²＋(y−2)²=4（中心 (−1, 2)、半径 2）で、≦ なので**実線**。中心を代入すると 0≦4 が成り立つので、**円の内部。境界線を含む**
(2) 境界線は円 x²＋y²=9（中心 (0, 0)、半径 3）で、> なので**破線**。中心を代入すると 0>9 は成り立たないので、**円の外部。境界線を含まない**
(3) 平方完成して (x−2)²＋(y＋1)²<5。境界線は円 (x−2)²＋(y＋1)²=5（中心 (2, −1)、半径 √5）で、< なので**破線**。中心を代入すると 0<5 が成り立つので、**円の内部。境界線を含まない**
(4) (1, 1) をもとの式の左辺に代入すると 1＋1−4＋2=0。**境界線上にあり、不等号が < なので領域には含まれない**
　検算: (3) の領域内の点として中心 (2, −1) をもとの式に → 4＋1−8−2=−5<0 ✓

**問4**
(1) 境界線 x−y＋2=0。点 (2, 1) を左辺に代入すると 2−1＋2=3>0。境界線を含むので **x−y＋2≧0**
(2) 円の外部は中心からの距離が半径より大きい点の集合。境界線を含まないので **(x−3)²＋(y＋1)²>16**
(3) 境界線 y=3 の上側で含まないので **y>3**
(4) 中心 (0, 0)、半径 2 の円の内部と周だから **x²＋y²≦4**
検算: (1) で反対側の点 (−3, 0) → −3−0＋2=−1 で ≧0 は成り立たない ✓。(2) で外部の点 (10, 0) → 49＋1=50>16 ✓

**問5** 原点 (0, 0) を代入すると 0−0>1、すなわち 0>1 で、**成り立たない**。だから領域は原点を含まない側である。直線 x−y=1 は y=x−1 と書け、原点 (0, 0) はこの直線の上側にある（y 座標 0 が x−1=−1 より大きい）。原点を含まない側は下側だから、**上側という答えは誤り**で、正しくは**直線 x−y=1 の下側**（境界線を含まない）である。
※「不等号が > だから上側」は、不等式を y について解いた形（この場合 y<x−1）でしか通用しない考え方で、もとの形のまま使うと逆を答えてしまう。点を1つ代入して確かめる。

**問6** 解答例:「境界線を含む領域は不等号に等号がつき（≦・≧）、図では境界線を実線で描き、答えには『境界線を含む』と書く。含まない領域は不等号が < や > で、境界線を破線で描き、答えには『境界線を含まない』と書く。この3か所が食い違わないように書く。」（不等号・線種・答えの文の3点が対応づけて書かれていればよい。）

**S1** (x−y)(x＋y)>0 が成り立つのは、x−y>0 かつ x＋y>0 のとき、または x−y<0 かつ x＋y<0 のときである。
- x−y>0 かつ x＋y>0: 直線 y=x について点 (1, 0) を含む側（1−0>0）と、直線 y=−x について点 (1, 0) を含む側（1＋0>0）の共通部分。x 軸の正の部分を含む右側の部分。
- x−y<0 かつ x＋y<0: 同様に、点 (−1, 0) を含む側どうしの共通部分。x 軸の負の部分を含む左側の部分。
求める領域は、**2直線 y=x、y=−x で平面を4つに分けたうち、x 軸を含む左右の2つの部分を合わせたもの。境界線を含まない**
検算: (2, 0) → (2)(2)=4>0 ✓、(−2, 0) → (−2)(−2)=4>0 ✓、(0, 2) → (−2)(2)=−4 で成り立たない ✓
（指導メモ: 「積が正」を符号の組合せに分けて場合ごとの領域を求め、最後に合わせる。数学Ⅰ「数と式」の連立不等式の「共通部分」と、場合分けの結果を「合わせる」の両方が出てくる。L12 S1 の絶対値の場合分けの準備になる。）

## L12 連立不等式の領域と最大・最小——線形計画法

**問1**
(1) x−y＋1≧0 は直線 x−y＋1=0（実線）について原点を含む側（1≧0）。x＋2y−4≦0 は直線 x＋2y−4=0（実線）について原点を含む側（−4≦0）。共通部分は、**2直線 x−y＋1=0、x＋2y−4=0 について、どちらも原点を含む側にある部分**（両方の境界線を含む）。2直線の交点は (2/3, 5/3)。
　検算: 原点 → 1≧0、−4≦0 ✓。点 (3, 3) → 1≧0 は成り立つが 5≦0 は成り立たない → 含まれない ✓
(2) x²＋y²<9 は円 x²＋y²=9（破線）の内部。x−y−1<0 は直線 x−y−1=0（破線）について原点を含む側（−1<0）で、直線の上側。共通部分は、**円 x²＋y²=9 の内部のうち、直線 x−y−1=0 の上側にある部分**（境界線をどちらも含まない）
　検算: (0, 1) → 1<9、−2<0 ✓。(2, 0) → 4<9 は成り立つが 1<0 は成り立たない → 含まれない ✓
(3) y≧0 は x 軸の上側、y≦2x は直線 y=2x について点 (1, 0) を含む側（0≦2）、x＋y≦6 は直線 x＋y=6 について原点を含む側。共通部分は、**3点 (0, 0)、(6, 0)、(2, 4) を頂点とする三角形の内部と周**（境界線を含む）。(2, 4) は y=2x と x＋y=6 の交点。
　検算: 内部の点 (2, 1) → 1≧0、1≦4、3≦6 ✓

**問2** x²＋y²≦16 と y≧x−2 の両方に代入する。
(1) (3, 2): 9＋4=13≦16 ✓、2≧1 ✓。**含まれる**
(2) (−1, −3): 1＋9=10≦16 ✓、−3≧−3 ✓（境界線上だが ≧ なので含む）。**含まれる**
(3) (4, 1): 16＋1=17≦16 は成り立たない。**含まれない**
(4) (2, −1): 4＋1=5≦16 ✓ だが、−1≧0 は成り立たない。**含まれない**
※連立不等式の領域に含まれるのは、すべての不等式が成り立つ点だけ。1つでも成り立たなければ含まれない。

**問3**
(1) 頂点は、x=0 と y=0 の交点 **(0, 0)**、y=0 と 2x＋y=8 の交点 **(4, 0)**、2x＋y=8 と x＋2y=7 の交点 **(3, 2)**（2x＋y=8 から y=8−2x を代入して x＋16−4x=7、x=3、y=2）、x=0 と x＋2y=7 の交点 **(0, 7/2)**
(2) x＋y=k は傾き −1 の直線。辺 2x＋y=8 の傾き −2 と辺 x＋2y=7 の傾き −1/2 の間にあるので、k が最大になるのは頂点 (3, 2) を通るとき。**最大値 5**（x=3、y=2）、**最小値 0**（x=0、y=0）
　検算: 頂点での値は (0, 0) で 0、(4, 0) で 4、(3, 2) で 5、(0, 7/2) で 7/2 ✓
(3) 3x＋y=k は傾き −3 の直線で、辺 2x＋y=8 の傾き −2 より急なので、k が最大になるのは頂点 (4, 0) を通るとき。**最大値 12**（x=4、y=0）
　検算: 頂点での値は 0、12、11、7/2 ✓

**問4** 2x＋y=k は傾き −2 の直線で、辺 2x＋y=8 と平行である。直線を上へ動かすと、頂点 (4, 0) と (3, 2) に同時に触れ、この辺全体で k=8 になる。**最大値 8**。最大値を与える点は**線分 2x＋y=8（0≦y≦2 の部分、すなわち (4, 0) から (3, 2) まで）上のすべての点**
検算: 頂点での値は (0, 0) で 0、(4, 0) で 8、(3, 2) で 8、(0, 7/2) で 7/2。辺の中点 (7/2, 1) でも 7＋1=8 ✓

**問5**
(1) 個数は 0 以上だから x≧0、y≧0。小麦粉は 200x＋100y≦1200、すなわち **2x＋y≦12**。バターは 100x＋100y≦800、すなわち **x＋y≦8**
(2) 領域の頂点は (0, 0)、(6, 0)、(4, 4)、(0, 8)（(4, 4) は 2x＋y=12 と x＋y=8 の交点）。利益 300x＋200y=k は傾き −3/2 の直線で、辺 2x＋y=12 の傾き −2 と辺 x＋y=8 の傾き −1 の間にあるので、k が最大になるのは頂点 (4, 4) を通るとき。**クッキー 4 箱、ケーキ 4 個のとき、利益は最大で 2000 円**
　検算: 頂点での利益は (0, 0) で 0、(6, 0) で 1800、(4, 4) で 2000、(0, 8) で 1600 ✓
(3) 小麦粉は 200×4＋100×4=1200 g で **余りは 0 g**。バターは 100×4＋100×4=800 g で **余りは 0 g**。どちらも使い切っている。
（指導メモ: 例題4と同じ型の自作問題。答えを元の場面に戻して「材料が余るか」まで読ませる。）

**問6** 解答例:「ax＋by=k の k は直線の位置を決める値で、k を変えると直線は平行に動く。直線が領域と共有点をもつ間は、その k の値をとる点が領域の中にあるので、領域の上での ax＋by の最大値は、直線が領域と共有点をもつ k の最大と同じである。だから、直線を動かして領域から離れる直前に通る点で、最大になる。」（「k＝直線の位置」「共有点をもつ k の最大」の言い換えが入っていればよい。）

**S1** 4つの場合に分けて絶対値を外す。
- x≧0、y≧0 のとき x＋y≦2: 直線 x＋y=2 について原点を含む側（x≧0、y≧0 の部分）。
- x≧0、y<0 のとき x−y≦2: 直線 x−y=2 について原点を含む側。
- x<0、y≧0 のとき −x＋y≦2: 直線 −x＋y=2 について原点を含む側。
- x<0、y<0 のとき −x−y≦2: 直線 x＋y=−2 について原点を含む側。
4つを合わせると、**4点 (2, 0)、(0, 2)、(−2, 0)、(0, −2) を頂点とする正方形の内部と周**（境界線を含む）
検算: (1, 1) → 1＋1=2≦2 ✓（境界線上・含む）。(−1, 0) → 1＋0≦2 ✓。(2, 1) → 2＋1=3 で成り立たない ✓
（指導メモ: 場合分け→各領域→合わせる、の順を守らせる。4つの場合の境界線が正方形の4辺になる。）

**S2**
(1) x、y は 0 以上の整数だから x≧0、y≧0。工程1: 2x＋2y≦7。工程2: 3x＋5y≦14。整数の条件を外して x、y を実数と見たとき、この不等式の表す領域は、4点 (0, 0)、(7/2, 0)、(7/4, 7/4)、(0, 14/5) を頂点とする四角形の内部と周（境界線を含む）で、元の条件を満たすのはその中の整数の点である。(7/4, 7/4) は 2x＋2y=7 と 3x＋5y=14 の交点（x＋y=7/2 から y=7/2−x を代入して 3x＋35/2−5x=14、x=7/4、y=7/4）。
(2) 4x＋5y=k は傾き −4/5 の直線。辺 2x＋2y=7 の傾き −1 と辺 3x＋5y=14 の傾き −3/5 の間にあるので、最大になるのは頂点 (7/4, 7/4) を通るとき。**最大値 63/4（＝15.75 千円）、点 (7/4, 7/4)**。この点は x、y が整数でないので、**個数としては意味をもたない**。
