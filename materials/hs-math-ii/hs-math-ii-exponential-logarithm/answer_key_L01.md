## L01 指数を 0 と負の整数へ広げる——法則が成り立つように決める

**問1**
(1) 5^(−2)=1/5^2=**1/25**
　検算: 5^(−2)×5^2=(1/25)×25=1 ✓
(2) (−3)^(−3)=1/(−3)^3=1/(−27)=**−1/27**
　検算: (−3)^(−3)×(−3)^3=(−1/27)×(−27)=1 ✓
(3) 7^0=**1**
　検算: 7^0×7^1=1×7=7=7^(0＋1) ✓
(4) (−3)^(−2)=1/(−3)^2=**1/9**
　検算: (−3)^(−2)×(−3)^2=(1/9)×9=1 ✓
(5) −3^(−2)=−(1/3^2)=**−1/9**
　※(4) と (5) は符号だけが違う。(4) は底が −3 全体、(5) は底が 3 で、負の符号は累乗の外にある。指数は、すぐ左にある物だけに働く。
　※(1) を −25 や −10 とするのは、負の指数を「負の数」や「かけ算」と読んだ誤り。負の指数は 5 で割る回数を表すので、答えは正の分数になる。

**問2** a≠0。
(1) 3^4×3^(−6)=3^(4−6)=3^(−2)=**1/9**
　検算: 直接計算で 81×(1/729)=81/729=1/9 ✓
(2) 5^2÷5^5=5^(2−5)=5^(−3)=**1/125**
　検算: 25÷3125=1/125 ✓
(3) (3^(−2))^2=3^((−2)×2)=3^(−4)=**1/81**
　検算: 3^(−2)=1/9 だから (1/9)^2=1/81 ✓
(4) a^3÷a^(−2)=a^(3−(−2))=**a^5**
　検算: a=3 のとき 27÷(1/9)=243=3^5 ✓
(5) a^5×a^(−5)=a^(5−5)=a^0=**1**
　検算: a^(−5)=1/a^5 だから a^5×(1/a^5)=1 ✓
　※(4) で 3−(−2) を 3−2=1 と計算すると a^1 になる。指数の引き算でも、負の数を引くときは符号に注意する。

**問3**
(1) 10^(−3)=1/10^3=1/1000=**0.001**
(2) 0.01=1/100=1/10^2=**10^(−2)**
　検算: 10^(−3)×10^3=0.001×1000=1 ✓。10^(−2)×10^2=0.01×100=1 ✓

**問4** 説明の例:「指数法則 a^0×a^n=a^(0＋n)=a^n が指数 0 でも成り立つようにするには、a^0 は a^n にかけても値を変えない数、すなわち 1 でなければならない。だから a^0=1 と決める（a≠0）。」
　※「0 乗は 0」とすると 0×a^n=0 となり、a^n に戻らないので法則が壊れる。「a を 0 個かけるから」という説明は、0 個かける操作が無いので説明になっていない。説明の中に「指数法則が成り立つように決めた」という筋があれば正解とする。

**問5** a^(−n)×a^n=1 の両辺を a^n で割る。a≠0 だから a^n≠0 で、割ることができる。よって a^(−n)=**1/a^n**。
　検算: a=3、n=2 で 3^(−2)=1/9=1/3^2 ✓
　（指導メモ: 「両辺を a^n で割る」の 1 手に a≠0 の条件が効いている。条件を書かずに割った答案には、a=0 のとき何が起きるかを問い返す。）

**S1**
(1) 0.00035=35/100000=3.5/10000=3.5×(1/10^4)=**3.5×10^(−4)**
　検算: 3.5×10^(−4)=3.5×0.0001=0.00035 ✓
(2) (3.5×10^(−4))×(2×10^6)=(3.5×2)×10^(−4＋6)=7×10^2=**700**
　検算: 0.00035×2000000=700 ✓
　※(1) で 35×10^(−5) や 0.35×10^(−3) と書いても値は同じだが、a×10^n の形では 1≦a<10 にそろえる。
