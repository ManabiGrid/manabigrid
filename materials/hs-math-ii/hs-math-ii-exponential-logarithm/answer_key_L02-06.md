## L02 累乗根と有理数の指数——1 回分の倍率を表す

**問1**
(1) 2^4=16<20<81=3^4 だから **2<⁴√20<3**
　検算: ⁴√20≒2.1147 で、2 と 3 の間にある ✓
(2) 3^3=27<30<64=4^3 だから **3<³√30<4**
　検算: ³√30≒3.1072 で、3 と 4 の間にある ✓
　※挟むときは、底になる整数の 4 乗（3 乗）を並べて、20（30）がどの 2 つの間に入るかを見る。⁴√20 を「20÷4=5」と読むのは、累乗根を割り算と読んだ誤り。

**問2**
(1) ³√125=**5**
　検算: 5^3=125 ✓
(2) ⁵√32=**2**
　検算: 2^5=32 ✓
(3) 8^(1/3)=³√8=**2**
　検算: 2^3=8 ✓
(4) 9^(−1/2)=1/9^(1/2)=1/√9=**1/3**
　検算: (1/3)^2=1/9=9^(−1) ✓
(5) 32^(2/5)=(⁵√32)^2=2^2=**4**
　検算: 4 を 5/2 乗すると 32 に戻る。4^(5/2)=(√4)^5=2^5=32 ✓
　※(4) を −3 や −1/3 とするのは、負の指数を負の符号と読んだ誤り（L01 の再掲）。負の指数は分母へ回す。

**問3** a>0。
(1) 3^(1/2)×3^(3/2)=3^(1/2＋3/2)=3^2=**9**
　検算: 小数で 3^(1/2)≒1.7321、3^(3/2)≒5.1962 で、積はおよそ 9.0 ✓
(2) 5^(2/3)÷5^(−1/3)=5^(2/3−(−1/3))=5^1=**5**
　検算: 指数 2/3＋1/3=1 ✓
(3) (2^(3/4))^(8/3)=2^((3/4)×(8/3))=2^2=**4**
　検算: (3/4)×(8/3)=24/12=2 ✓
(4) ³√4×³√16=³√(4×16)=³√64=**4**
　検算: 4^3=64 ✓（分数の指数で書くと 4^(1/3)×16^(1/3)=(4×16)^(1/3)=64^(1/3)）
(5) a^(1/2)×a^(1/3)÷a^(5/6)=a^(1/2＋1/3−5/6)=a^0=**1**
　検算: 3/6＋2/6−5/6=0 ✓
　※(2) で 2/3−1/3=1/3 とするのは、負の指数を引くときの符号の誤り。a^p÷a^q=a^(p−q) の q が −1/3 なので、2/3−(−1/3)=1 になる。

**問4**
(1) 1 回分の倍率を r とすると r^3=27 だから r=27^(1/3)=³√27=**3 倍**
　検算: 3^3=27 ✓
(2) r^5=32 だから r=32^(1/5)=⁵√32=**2 倍**
　検算: 2^5=32 ✓
(3) r^2=1/9 だから r=(1/9)^(1/2)=√(1/9)=**1/3 倍**
　検算: (1/3)^2=1/9 ✓
　※(1) を「27÷3=9 倍」とするのは、n 回で p 倍を 1 回 p/n 倍と読む誤り。9 倍を 3 回かけると 729 倍で、27 倍にならない。(3) を「1 回で 1/18 倍」や「1/9 の半分ずつ減る」とするのも同じ型の誤りで、(1/18)^2=1/324≠1/9 である。

**問5** 説明の例:「累乗の法則 (a^m)^n=a^(mn) が指数 1/n でもそのまま成り立つようにすると、(a^(1/n))^n=a^((1/n)×n)=a^1=a でなければならない。つまり a^(1/n) は n 乗すると a になる正の数で、それは ⁿ√a である。だから a^(1/n)=ⁿ√a と決める（a>0）。」
　※「a を n 等分するから」「a の n 分の 1 だから」という説明は、指数を割り算と読んでいるので説明になっていない。説明の中に「指数法則が成り立つように決めた」という筋と「n 乗すると a に戻る」という確かめがあれば正解とする。

**問6** 累乗の法則を p=1/n、q=n に当てると (a^(1/n))^n=a^((1/n)×n)=a^1=a である。よって a^(1/n) は n 乗すると a になる数、すなわち a の n 乗根である。a^(1/n) は正の数だから、正の n 乗根 **ⁿ√a** に等しい。
　検算: a=8、n=3 で 8^(1/3)=2、2^3=8 ✓
　（指導メモ: 「a^(1/n) は正の数だから」の 1 手で、2 つある偶数乗根のうち正の方に決まる。この 1 手が無い答案には、4 乗して 16 になる数が 2 つあることを問い返す。）

**S1**
(1) (³√8)^2=2^2=**4**、³√(8^2)=³√64=**4** で一致する。
　検算: 2^3=8、4^3=64 ✓
(2) 8^(4/6)=⁶√(8^4)=⁶√4096=**4** で、(1) の値と一致する。
　検算: 4^6=4096、8^4=4096 ✓。4/6=2/3 ✓
　説明の例:「8^(4/6)=⁶√(8^4) は 6 乗すると 8^4 になる正の数で、8^(2/3)=³√(8^2) も 6 乗すると (8^2)^2=8^4 になる正の数である。6 乗して同じ 8^4 になる正の数はただ 1 つだから、2 つの値は等しい。底が正の数なら、m を整数、n を 2 以上の整数、k を正の整数として、一般の a^(mk/nk) と a^(m/n) も同じで、どちらも nk 乗すると a^(mk) になる正の数だから一致する。」（「同じ値の有理数だから」とだけ書く説明は、示すべきことを前提にしているので不十分とする。）
　※底が負のときはこの性質が崩れる場合があるので、本文の約束どおり底は正の数に限る。

## L03 指数関数とそのグラフ——同じ倍率で変わる関数

**問1**
(1)

| x | −2 | −1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| y=3^x | 1/9 | 1/3 | 1 | 3 | 9 |

　検算: 隣どうしの比はすべて 3（1/9→1/3→1→3→9） ✓
(2) グラフは右上がりの曲線。特徴 4 つの確かめ: ①値はすべて正 ②点 (0, 1) を通る（3^0=1） ③左へ行くほど x 軸に近づくが触れない（1/9、1/27、…と正のまま小さくなる） ④底 3 は 1 より大きいので増加。
　※y=2^x より、x>0 では上に、x<0 では下にある（3>2、1/3<1/2）。

**問2**
(1) 底を 2 にそろえる。4^0.1=(2^2)^0.1=2^0.2、8^0.2=(2^3)^0.2=2^0.6 である。底 2>1 だから指数の順に 0.2<0.3<0.6 で、小さい順に **4^0.1、2^0.3、8^0.2**
　検算: 小数で 4^0.1≒1.1487、2^0.3≒1.2311、8^0.2≒1.5157 ✓
(2) 底を 3 にそろえる。√3=3^(1/2)、³√9=3^(2/3)、⁴√27=3^(3/4) である。1/2<2/3<3/4 だから、小さい順に **√3、³√9、⁴√27**
　検算: 小数で √3≒1.7321、³√9≒2.0801、⁴√27≒2.2795 ✓

**問3**
(1) 底 1/2 は 1 より小さいので、指数が大きいほど値は小さい。指数は −1<0.5<2 だから、値は逆順になり、小さい順に **(1/2)^2、(1/2)^0.5、(1/2)^(−1)**
　検算: (1/2)^2=1/4、(1/2)^0.5≒0.7071、(1/2)^(−1)=2 で 1/4<0.7071<2 ✓
(2) 底を 1/2 にそろえる。(1/4)^(1/3)=((1/2)^2)^(1/3)=(1/2)^(2/3) である。底 1/2<1 で、指数は 2/3>1/2 だから、値は (1/2)^(2/3)<(1/2)^(1/2)。よって **(1/4)^(1/3)<(1/2)^(1/2)**
　検算: 小数で (1/4)^(1/3)≒0.6300、(1/2)^(1/2)≒0.7071 ✓
　※底をそろえた後に「指数が大きい方が大きい」と向きを変え忘れると、(2) の答えが逆になる。1 点代入（小数で確かめる）で向きの誤りに気づける。

**問4** 説明の例（4 つと理由）:
①「y の値はいつも正である。」——2^x は負の指数のときも 1/2^n で正だから。
②「点 (0, 1) を通る。」——2^0=1 だから。
③「左へ行くほど x 軸に限りなく近づくが、触れない。」——半分にし続けても 0 にはならず、2^x=0 となる x は無いから。
④「x が増えると y も増える（増加）。」——底 2 が 1 より大きく、x が 1 増えるごとに 2 倍になるから。
　※「右上がり」「y 軸と (0, 1) で交わる」など言い方が違っても、4 つの内容と理由が対応していれば正解とする。

**問5**
(1) 点 **(0, 1)**（2^0=3^0=(1/2)^0=1 だから、底が何でも通る）
(2) x>0 では **y=3^x** が上にある。x<0 では **y=2^x** が上にある。理由の例:「x>0 では、x=0 の 1 から出発して x が 1 増えるごとに 3^x は 3 倍、2^x は 2 倍になるので 3^x の方が大きく（x=1 で 3>2、x=2 で 9>4）、x<0 では 3^x=1/3^(−x)、2^x=1/2^(−x) と x>0 のときの値の逆数になるので、大小が逆になるから（x=−1 で 1/2>1/3）。」（x>0 で上下が途中で入れ替わらないことは、この単元ではグラフで認める。）
　検算: x=1 で 2^1=2<3=3^1、x=−1 で 2^(−1)=1/2>1/3=3^(−1) ✓
(3) **y=(1/2)^x**（底 1/2 が 1 より小さいので減少）

**S1**
(1) x=2 のとき 2^(x＋1)=2^3=**8**、2×2^x=2×2^2=**8** で一致する。
　検算: x=−1 でも 2^0=1、2×2^(−1)=1 で一致する ✓
(2) 説明の例:「積の法則 a^(m＋n)=a^m×a^n により、2^(x＋1)=2^x×2^1=2×2^x である。だから、x を 1 増やした値（グラフを x 軸方向に −1 動かした物）と、y を 2 倍した値は、どの x でも同じになる。」
　※平行移動は数学Ⅰ「二次関数」で学んだ型。指数関数では「横に動かす」ことと「縦に倍にする」ことが同じグラフになる、という読み替えが成り立つ。

## L04 指数関数を含む方程式・不等式——底をそろえて指数を比べる

**問1**
(1) 5^x=5^3 だから **x=3**
　検算: 5^3=125 ✓
(2) 8^x=(2^3)^x=2^(3x)、16=2^4 だから 3x=4 から **x=4/3**
　検算: 8^(4/3)=(³√8)^4=2^4=16 ✓
(3) 4^x=2^(2x)、1/32=2^(−5) だから 2x=−5 から **x=−5/2**
　検算: 4^(−5/2)=1/(√4)^5=1/32 ✓

**問2**
(1) 1/8=2^(−3) だから x−1=−3 から **x=−2**
　検算: 2^(−2−1)=2^(−3)=1/8 ✓
(2) 4^(x＋1)=2^(2x＋2)、1/2=2^(−1) だから 2x＋2=−1 から **x=−3/2**
　検算: 4^(−3/2＋1)=4^(−1/2)=1/√4=1/2 ✓
　※(1) で x−1=3 として x=4 とするのは、1/8 を 2^3 と読んだ誤り。1/8 は 2 で 3 回割った数なので指数は −3。

**問3**
(1) 16=2^4 だから 2^x>2^4。底 2>1 なので **x>4**
　検算: x=5 で 32>16 成立、x=3 で 8>16 不成立 ✓
(2) 9^x=3^(2x)、3=3^1 だから 3^(2x)<3^1。底 3>1 なので 2x<1 から **x<1/2**
　検算: x=0 で 1<3 成立、x=1 で 9<3 不成立 ✓。境界 x=1/2 で 9^(1/2)=3 ✓

**問4**
(1) 1/27=(1/3)^3 だから (1/3)^x≦(1/3)^3。底 1/3<1 なので向きが逆になり **x≧3**
　検算: x=4 で 1/81≦1/27 成立、x=2 で 1/9≦1/27 不成立 ✓
(2) 8=2^3 で、1/4=2^(−2) だから 8=(1/4)^(−3/2) と書ける。(1/4)^x>(1/4)^(−3/2) で、底 1/4<1 なので向きが逆になり **x<−3/2**
　検算: x=−2 で (1/4)^(−2)=16>8 成立、x=−1 で (1/4)^(−1)=4>8 不成立 ✓
　（別解: (1/4)^x=2^(−2x) と底 2 にそろえると 2^(−2x)>2^3 で、底 2>1 だから −2x>3、x<−3/2。どちらの底にそろえても同じ答えになる。）
　※(1) で向きを変え忘れて x≦3 とすると、x=2 で 1/9≦1/27 が成り立たない。1 点代入で気づく。

**問5**
(1) 9^x=(3^x)^2 だから t=3^x とおく（t>0）。t²−10t＋9=0、(t−1)(t−9)=0 で t=1、9。どちらも正だから 3^x=1 より x=0、3^x=9 より x=2 である。よって **x=0、2**
　検算: x=0 で 1−10＋9=0、x=2 で 81−90＋9=0 ✓
(2) t=3^x とおく（t>0）。t²＋t−12=0、(t＋4)(t−3)=0 で t=−4、3。t=−4 は t>0 に反するので捨て、3^x=3 より **x=1**
　検算: x=1 で 9＋3−12=0 ✓
(3) 4^x=(2^x)^2 だから t=2^x とおく（t>0）。t²−6t＋8<0、(t−2)(t−4)<0 で 2<t<4。これは t>0 を満たす。2<2^x<4、つまり 2^1<2^x<2^2 で、底 2>1 だから **1<x<2**
　検算: x=1.5 で 4^1.5−6×2^1.5＋8=8−16.97…＋8<0 成立、x=0 で 1−6＋8=3<0 不成立、x=3 で 64−48＋8=24<0 不成立 ✓
　※(2) で t=−4 を 3^x=−4 として「x は無い」まで書いた答案は正解。t=−4 を捨てずに 2 つの解を書いた答案は、t>0 を書いていないことが原因。

**問6** 説明の例:「底が 1 より小さい指数関数のグラフは右下がりで、y が大きい点ほど x は小さい。だから a^p<a^q という y の大小は p>q という x の大小に対応し、指数の不等号の向きが逆になる。」
　※「公式だから」「底が 1 より小さいときはそういう決まりだから」は理由になっていない。説明の中にグラフの増減（右下がり・減少）があれば正解とする。

**S1** 3^x＋3^(−x)=4 の両辺を 2 乗する。(3^x＋3^(−x))^2=(3^x)^2＋2×3^x×3^(−x)＋(3^(−x))^2=9^x＋2＋9^(−x) である（3^x×3^(−x)=3^0=1 を使った）。左辺は 4^2=16 だから 9^x＋9^(−x)=16−2=**14**
　検算: u=3^x が u＋1/u=4 を満たすとき、u²＋1/u²=(u＋1/u)²−2=16−2=14 ✓
　（指導メモ: 3^x の値を求めてから代入する解き方もあるが、3^x は無理数になり計算が重い。2 乗して既習の関係 3^x×3^(−x)=1 を使う方が早い。相加平均と相乗平均の関係はこの単元では使わない。）

## L05 対数——「何乗すると M になるか」を表す数

**問1**
(1) **log_2 64=6**
　検算: 2^6=64 ✓
(2) **5^3=125**
　検算: 5 を 3 乗すると 125 ✓
(3) 3^4=81 だから log_3 81=**4**
　検算: 3^4=81 ✓
(4) 2^(−5)=1/32 だから log_2 (1/32)=**−5**
　検算: 2^(−5)=1/32 ✓
(5) (1/3)^(−3)=3^3=27 だから log_(1/3) 27=**−3**
　検算: (1/3)^(−3)=27 ✓
(6) 16^(1/4)=⁴√16=2 だから log_16 2=**1/4**
　検算: 16^(1/4)=2 ✓
　※(3) を 27（3×27=81）とするのは、対数をかけ算で読んだ誤り。「3 を何乗すると 81 になるか」を言葉にして 3^p=81 と書き直す。(6) を 4（log_2 16 の値）とするのは、底と真数の取り違え。

**問2** a>0、a≠1。
(1) a^3=64 だから **a=4**
　検算: 4^3=64 ✓
(2) a^(−3)=1/8、つまり a^3=8 だから **a=2**
　検算: 2^(−3)=1/8 ✓
(3) a^(1/2)=6、つまり √a=6 だから **a=36**
　検算: 36^(1/2)=6 ✓

**問3**
(1) M=2^5=**32**
　検算: log_2 32=5 ✓
(2) M=3^(−2)=**1/9**
　検算: log_3 (1/9)=−2 ✓
(3) M=4^(3/2)=(√4)^3=**8**
　検算: log_4 8=3/2 ✓

**問4**
(1) 2^2=4<7<8=2^3 だから **2<log_2 7<3**
　検算: log_2 7≒2.807 で 2 と 3 の間 ✓
(2) 5^2=25<100<125=5^3 だから **2<log_5 100<3**
　検算: log_5 100≒2.861 で 2 と 3 の間 ✓
　※底の累乗を並べて、真数がどの 2 つの間に入るかを見る。底 2>1 だから、真数の大小と対数の大小の向きは同じ。

**問5** 解答の例: 言葉「log_a M は、a を何乗すると M になるかを表す数である。」式「a^p=M ⇔ p=log_a M（a>0、a≠1、M>0）」
　※言葉と式の両方があり、式に底の条件（1 でない正の数）と真数の条件（正の数）が添えてあれば正解とする。「指数の逆」「log を付けた物」だけでは、何を表す数かが述べられていないので不十分。

**問6**
(1) a^0=1 である。定義 a^p=M ⇔ p=log_a M に p=0、M=1 を当てると **log_a 1=0**
　検算: a=3 で 3^0=1 ✓
(2) p=log_a M とおくと、定義から a^p=M である。p を元の形に戻すと **a^(log_a M)=M**
　検算: a=3、M=7 で 3^(log_3 7)=7（log_3 7 は 3 を何乗すると 7 になるかを表す数） ✓
　（指導メモ: (2) は「名前を付けた数を、その名前のとおりに使った」だけの式で、計算は何も無い。ここで止まる場合は「log_a M は何を表す数か」を言葉で言わせてから、a をその数だけ乗じるとどうなるかを問う。）

**S1** 2^(3/2)=√8≒2.828 で、3 より小さい。y=2^x は増加だから、高さ 3 になる x は 3/2 より右にある。よって **3/2<log_2 3**
　検算: log_2 3≒1.585>1.5 ✓
　※本文の 1.5<log_2 3<2 と同じ内容。指数の式に戻して「2 を 3/2 乗した値と 3 を比べる」ことができれば正解とする。

## L06 対数の性質と底の変換——積が和になる

**問1** M=a^p、N=a^q とおくと、定義から p=log_a M、q=log_a N である。商の法則で M/N=a^p÷a^q=a^(p−q) だから、定義に戻ると log_a (M/N)=p−q=**log_a M−log_a N**
　検算: a=2、M=32、N=4 で log_2 (32/4)=log_2 8=3、log_2 32−log_2 4=5−2=3 ✓

**問2** M=a^p とおくと、定義から p=log_a M である。累乗の法則で M^r=(a^p)^r=a^(pr) だから、定義に戻ると log_a M^r=pr=**r log_a M**
　検算: a=2、M=8、r=2 で log_2 8^2=log_2 64=6、2 log_2 8=2×3=6 ✓
　（指導メモ: 問1・問2 とも「M=a^p とおく」の 1 行が書けるかが分かれ目。書けない場合は、本文 §1 の積の性質の導き方を隣に置いて、どこを商・累乗に変えればよいかを指でたどらせる。）

**問3**
(1) log_2 (12/3)=log_2 4=**2**
　検算: 2^2=4、12÷3=4 ✓
(2) log_5 (10×5/2)=log_5 25=**2**
　検算: 5^2=25 ✓
(3) √27=27^(1/2) だから log_3 √27=(1/2) log_3 27=(1/2)×3=**3/2**
　検算: 3^(3/2)=√(3^3)=√27 ✓
(4) log_6 (8×27)=log_6 216=**3**
　検算: 6^3=216 ✓
(5) 2 log_10 5=log_10 25 だから log_10 25＋log_10 4=log_10 100=**2**
　検算: 10^2=100 ✓

**問4**
(1) log_3 (18/2)=log_3 9=**2**
　検算: 3^2=9 ✓
(2) log_2 (6×12/9)=log_2 8=**3**
　検算: 6×12=72、72÷9=8、2^3=8 ✓
(3) 3 log_2 ³√4=log_2 (³√4)^3=log_2 4=**2**
　検算: ³√4=2^(2/3) だから log_2 ³√4=2/3 で、3×(2/3)=2 ✓
　※(2) で log_2 6＋log_2 12 を log_2 18 とするのは、和の対数と対数の和を取り違えた誤り。足すのは真数ではなく対数の値で、真数側ではかける。

**問5** log_2 (8＋8)=log_2 16=**4**、log_2 8＋log_2 8=3＋3=**6** で、一致しない。
　説明の例:「log_a (M＋N) は log_a M＋log_a N に分けてはいけない。積の性質は真数のかけ算を対数の足し算に変える物であって、真数の足し算をそのまま対数の足し算に変える性質は無いからである。」
　検算: 2^4=16、2^6=64≠16 ✓
　※本文の反例 log_2 (4＋4) と同じ型。2 つの値を別々に計算して違いを見せる、という確かめ方そのものが答えの一部。

**問6**
(1) log_4 32=log_2 32／log_2 4=**5/2**
　検算: 4^(5/2)=(√4)^5=2^5=32 ✓
(2) log_8 4=log_2 4／log_2 8=**2/3**
　検算: 8^(2/3)=(³√8)^2=2^2=4 ✓
(3) log_5 8=log_2 8／log_2 5 だから log_2 5×log_5 8=log_2 5×(log_2 8／log_2 5)=log_2 8=**3**
　検算: 2^(log_2 5)=5、5^(log_5 8)=8 だから (2^(log_2 5))^(log_5 8)=2^(log_2 5×log_5 8)=8 で、2→5→8 と進む指数は和ではなく積になり、8=2^3 ✓
　※(1) で分子と分母を逆にすると log_32 4 の値（2/5）になる。底の変換公式は「分子が真数・分母が底」で、出した値は a^p=b に戻して確かめる。

**S1**
(1) log_2 8=**3**、log_8 2=**1/3** で、積は 3×(1/3)=**1**。一般に、底の変換公式で底を a にそろえると log_b a=log_a a／log_a b=1／log_a b だから、log_a b×log_b a=log_a b×(1／log_a b)=1 である。
　検算: 2^3=8、8^(1/3)=2 ✓
(2) log_8 32=log_2 32／log_2 8=**5/3**。一般に、底の変換公式で底を a にそろえると log_(a^n) M=log_a M／log_a a^n=log_a M／(n log_a a)=log_a M／n=(1/n) log_a M である（log_a a=1 と累乗の性質を使った）。
　検算: 8^(5/3)=(³√8)^5=2^5=32 ✓。(1/3)×log_2 32=(1/3)×5=5/3 ✓
　（指導メモ: (2) の関係は、本教材では覚えさせず「底の変換公式から 3 行で出る」ことを確かめる問いにとどめる。教科書での扱いは指導ノート L06 の節のとおりで、現行の教科書本文は未目視。）
