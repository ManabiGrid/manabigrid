# L13 剰余の定理と因数定理——A=BQ＋R に代入する

- unit_id: hs-math-ii-various-expressions

## 1. 割り算の等式に代入する——余りだけが残る

L03 の例題1 で、2x³−5x＋4 を x−2 で割り、次の等式を得た。

2x³−5x＋4=(x−2)(2x²＋4x＋3)＋10

L05 で見たように、割り算の結果を表す等式は x についての恒等式だから、x にどんな値を代入しても成り立つ。そこで、割る式 x−2 を 0 にする値 x=2 を代入してみる。右辺の (x−2)(2x²＋4x＋3) は 0 になり、余りの 10 だけが残る。

2×2³−5×2＋4=0×(2×2²＋4×2＋3)＋10=10

左辺は、2x³−5x＋4 に x=2 を代入した値である。つまり、**x−2 で割った余りは、x=2 を代入した値に等しい**。筆算をしなくても、代入するだけで余りが分かる。

これを一般の形で書く。x の多項式を P(x) のように書き、x に数 α を代入した値を P(α) と書くことにする。たとえば P(x)=2x³−5x＋4 なら、P(2)=10 である。

P(x) を1次式 x−α で割った商を Q(x)、余りを R とする。余りの次数は割る式の次数 1 より低いので、R は定数である。

P(x)=(x−α)Q(x)＋R

この等式は恒等式なので、x=α を代入すると、P(α)=0×Q(α)＋R=R となる。

**剰余の定理**（じょうよのていり） 多項式 P(x) を1次式 x−α で割った余りは、P(α) である。

1次式 ax＋b（a≠0）で割るときも同じように、P(x)=(ax＋b)Q(x)＋R に、ax＋b を 0 にする値 x=−b/a を代入すると、余りは R=P(−b/a) となる。

**例題1** P(x)=x³−3x²＋4x−5 を、次の式で割った余りを求めよ。
(1) x−2  (2) x＋1  (3) 2x−1

(1) P(2)=8−12＋8−5=−1
(2) x＋1=x−(−1) だから、余りは P(−1)=−1−3−4−5=−13
(3) 2x−1 を 0 にする値は x=1/2 だから、余りは P(1/2)=1/8−3/4＋2−5=−29/8

検算: (1) を筆算で確かめる。x³−3x²＋4x−5 を x−2 で割ると、商は x²−x＋2、余りは −1 で、剰余の定理の答えと一致する。

:::guide
**剰余の定理は「代入公式」ではなく、A=BQ＋R の読みかえ**

「x−α で割った余りは P(α)」を理由抜きの代入公式として覚えると、すぐに迷う。x＋2 で割るときは P(2) か P(−2) か。2次式で割るときは何を代入すればよいのか。こうした迷いは、理由に戻れば消える。剰余の定理の中身は、割り算の等式 P(x)=(割る式)×Q(x)＋R は恒等式だから、割る式を 0 にする x を代入すれば余りだけが残る、という1行だけである。x＋2 で割るなら、x＋2 を 0 にする x=−2 を代入する。2次式で割るなら、その2次式が異なる2つの1次式の積に分解できるとき、それぞれを 0 にする x を代入すればよい（§3）。有理数の範囲で分解できないときや、同じ1次式が2つ重なるときは、L03 の筆算か L05 の未定係数法で余りを求める。割る式が何であっても「割る式を 0 にする値を代入する」と覚えておけば、どの場合にも考え方の出発点になる。
:::

## 2. 余りの条件から係数を決める

**例題2** x³＋ax²−2x＋3 を x−1 で割った余りが 5 であるとき、定数 a の値を求めよ。

P(x)=x³＋ax²−2x＋3 とおく。剰余の定理から、余りは P(1)=1＋a−2＋3=a＋2 である。これが 5 に等しいので、a＋2=5 より a=3。

**例題3** P(x)=x³＋ax²＋bx−4 を x−1 で割ると余りが 2、x−2 で割ると余りが 10 である。定数 a, b の値を求めよ。

剰余の定理から、P(1)=2、P(2)=10 である。
P(1)=1＋a＋b−4=2 より、a＋b=5
P(2)=8＋4a＋2b−4=10 より、2a＋b=3
2つの式から、a=−2, b=7。

検算: P(x)=x³−2x²＋7x−4 のとき、P(1)=1−2＋7−4=2、P(2)=8−8＋14−4=10 で、条件を満たす。

## 3. 2次式で割った余り

2次式で割った余りは、1次以下の式である（L03）。そこで、余りを px＋q（p, q は定数）とおく。

**例題4** P(x)=x⁴−3x³＋2x−5 を x²−3x＋2 で割った余りを求めよ。

x²−3x＋2=(x−1)(x−2) である。商を Q(x)、余りを px＋q とすると、

P(x)=(x−1)(x−2)Q(x)＋px＋q

これは恒等式なので、割る式を 0 にする x=1, 2 を代入すると、商の部分が消える。
x=1 のとき: P(1)=1−3＋2−5=−5 だから、p＋q=−5
x=2 のとき: P(2)=16−24＋4−5=−9 だから、2p＋q=−9
2つの式から p=−4, q=−1。余りは −4x−1 である。

検算: 筆算で割ると、商は x²−2、余りは −4x−1 で一致する。

これは、L05 で学んだ未定係数法（値を代入する方法）そのものである。余りの形を px＋q と決めてから、恒等式に都合のよい値を代入して、p, q を求めている。

:::guide
**余りが定数・余りが 0 を、式で言い換える**

L03 では、2次式で割った余りを px＋q とおいた。すると、余りが定数であることは p=0 と、割り切れることは p=0 かつ q=0 と言い換えられる。そのときは余りを筆算で求めたが、剰余の定理を使うと、p と q は、割る式を 0 にする値を代入するだけで求められる。例題4 なら、x=1 と x=2 を代入した2つの式から、p と q が決まった。言葉の条件を余りの式の条件に言い換え、余りの式を代入で求める。この2段で、割り算の問題の多くは筆算なしで解ける。
:::

## 4. 因数定理——余りが 0 のとき

剰余の定理で、余りが 0 になる場合を考える。P(α)=0 なら、P(x)=(x−α)Q(x)＋0=(x−α)Q(x) で、P(x) は x−α で割り切れる。逆に、P(x) が x−α で割り切れて P(x)=(x−α)Q(x) と書けるなら、x=α を代入して P(α)=0 である。

**因数定理** 多項式 P(x) が1次式 x−α を因数にもつ（x−α で割り切れる）⇔ P(α)=0

**例題5** x³−6x²＋11x−6 を因数分解せよ。

P(x)=x³−6x²＋11x−6 とおく。P(1)=1−6＋11−6=0 だから、因数定理より x−1 は P(x) の因数である。P(x) を x−1 で割ると、商は x²−5x＋6 だから、

x³−6x²＋11x−6=(x−1)(x²−5x＋6)=(x−1)(x−2)(x−3)

検算: 展開して戻す。(x−1)(x−2)=x²−3x＋2 で、これに x−3 を掛けると x³−3x²＋2x−3x²＋9x−6=x³−6x²＋11x−6 になる。

## 5. 因数の候補の探し方

因数定理を使うには、P(α)=0 となる α を見つける必要がある。やみくもに代入するのではなく、候補を絞る。

係数が整数で、x³ の係数が 1 の3次式 P(x)=x³＋ax²＋bx＋c を考える。整数 α が P(α)=0 を満たすとすると、α³＋aα²＋bα＋c=0 から c=−α(α²＋aα＋b) で、かっこの中は整数だから、α は定数項 c の約数である。そこで、定数項の約数（正の数と負の数の両方）を候補にして、絶対値の小さいものから代入していく。定数項が 0 のときは、この方法を使う前に、x でくくれるだけくくっておく。

最高次の係数が 1 でないときは、±（定数項の約数）/（最高次の係数の約数）の形の分数も候補に入れる。

**例題6** 2x³−3x²−3x＋2 を因数分解せよ。

P(x)=2x³−3x²−3x＋2 とおく。候補は ±1, ±2, ±1/2 である。
P(1)=2−3−3＋2=−2、P(−1)=−2−3＋3＋2=0
よって x＋1 が因数である。P(x) を x＋1 で割ると、商は 2x²−5x＋2 だから、

2x³−3x²−3x＋2=(x＋1)(2x²−5x＋2)=(x＋1)(x−2)(2x−1)

検算: 候補のうち x=2 と x=1/2 も P(x)=0 を満たす（P(2)=16−12−6＋2=0、P(1/2)=1/4−3/4−3/2＋2=0）。これらは、因数 x−2 と 2x−1 に対応している。

:::guide
**因数の候補は、なぜ定数項の約数なのか**

x³−6x²＋11x−6 の因数 x−1 を見つけられたのは、1 が定数項 −6 の約数だったからである。(x−1)(x−2)(x−3) を展開すると、定数項は (−1)×(−2)×(−3)=−6 で、各因数の定数の部分をすべて掛けたものになる。だから、係数が整数で x³ の係数が 1 のとき、整数 α について x−α が因数なら、α は定数項の約数でなければならない（最高次の係数が 1 でないときは、上の分数の候補も入る）。例題6 の (x＋1)(x−2)(2x−1) を展開すると、最高次の係数 2 は各因数の x の係数 1, 1, 2 の積で、定数項 2 は各因数の定数の部分 1, −2, −1 の積である。だから、因数 2x−1 を 0 にする値 1/2 は、分子が定数項の約数、分母が最高次の係数の約数になっている。候補を絞るのは、この展開の仕組みを逆にたどっているのである。候補をすべて試しても P(α)=0 にならないときは、この方法では1次の因数が見つからない。この単元で、この方法を使って解く問題は、候補の中に因数が見つかるように作ってある（L14 の複二次方程式のように、置き換えで解く問題は別である）。
:::

## 6. 手順の型——高次式を因数分解する

1. 定数項が 0 なら、先に x でくくれるだけくくり、以後は残った式について調べる（残った式が2次以下なら、すでに学んだ方法で分解する）。定数項の約数を、P(α)=0 となる α の候補として挙げる（最高次の係数が 1 でなければ、±（定数項の約数）/（最高次の係数の約数）も入れる）。
2. 候補を代入して、P(α)=0 となる α を1つ見つける。因数定理から、x−α が因数である。
3. P(x) を x−α で割る（筆算、または商を文字でおく未定係数法で）。
4. 商をさらに因数分解する。2次式なら、中3・数学Ⅰの方法か、L12 の解を使う方法で。
5. 展開して戻して確かめる。
