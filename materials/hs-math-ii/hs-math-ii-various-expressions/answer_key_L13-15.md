## L13 剰余の定理と因数定理——A=BQ＋R に代入する

**問1**
(1) P(2)=16−4＋6−4=**14**
(2) P(−1)=−2−1−3−4=**−10**
(3) P(−2)=−16−4−6−4=**−30**
(4) 2x−1 を 0 にする値は x=1/2 だから、P(1/2)=1/4−1/4＋3/2−4=**−5/2**
　検算: (4) を筆算で確かめる。2x³−x²＋3x−4 を 2x−1 で割ると、商は x²＋3/2、余りは −5/2 ✓（(2x−1)(x²＋3/2)−5/2=2x³−x²＋3x−3/2−5/2=2x³−x²＋3x−4）

**問2** P(x)=x³＋ax²＋bx−6 とおく。x−1 で割り切れるので P(1)=0、x＋2 で割った余りが −12 なので P(−2)=−12 である。
P(1)=1＋a＋b−6=0 より、a＋b=5
P(−2)=−8＋4a−2b−6=−12 より、2a−b=1
2つの式から **a=2, b=3**
　検算: P(x)=x³＋2x²＋3x−6 で、P(1)=1＋2＋3−6=0 ✓、P(−2)=−8＋8−6−6=−12 ✓

**問3**
(1) x²−x−2=(x＋1)(x−2)。P(x)=x⁴＋2x³−x＋1 とおき、商を Q(x)、余りを px＋q とすると、P(x)=(x＋1)(x−2)Q(x)＋px＋q。
x=−1 を代入すると、P(−1)=1−2＋1＋1=1 だから、−p＋q=1
x=2 を代入すると、P(2)=16＋16−2＋1=31 だから、2p＋q=31
2つの式から p=10, q=11。余りは **10x＋11**
　検算: 筆算で割ると、商は x²＋3x＋5、余りは 10x＋11 ✓
(2) x²−1=(x−1)(x＋1)。余りを px＋q とすると、x⁷=(x−1)(x＋1)Q(x)＋px＋q。
x=1 を代入すると 1=p＋q、x=−1 を代入すると −1=−p＋q。
2つの式から p=1, q=0。余りは **x**
（指導メモ: 7次式の筆算は長いが、剰余の定理なら2回の代入で済む。筆算をしなくても余りが分かる便利さを実感させる問題である。）

**問4**
(1) P(x)=x³−7x＋6 とおくと、P(1)=1−7＋6=0。x−1 で割ると商は x²＋x−6 だから、**(x−1)(x−2)(x＋3)**
　検算: 展開 (x−1)(x²＋x−6)=x³＋x²−6x−x²−x＋6=x³−7x＋6 ✓
(2) P(x)=x³＋3x²−4 とおくと、P(1)=1＋3−4=0。x−1 で割ると商は x²＋4x＋4=(x＋2)² だから、**(x−1)(x＋2)²**
　検算: 展開 (x−1)(x²＋4x＋4)=x³＋4x²＋4x−x²−4x−4=x³＋3x²−4 ✓
(3) P(x)=2x³−x²−7x＋6 とおくと、P(1)=2−1−7＋6=0。x−1 で割ると商は 2x²＋x−6=(x＋2)(2x−3) だから、**(x−1)(x＋2)(2x−3)**
　検算: 展開 (x−1)(2x²＋x−6)=2x³＋x²−6x−2x²−x＋6=2x³−x²−7x＋6 ✓
(4) P(x)=x⁴−2x³−7x²＋8x＋12 とおくと、P(−1)=1＋2−7−8＋12=0、P(2)=16−16−28＋16＋12=0。x＋1 と x−2 が因数だから、P(x) は (x＋1)(x−2)=x²−x−2 で割り切れる。割ると商は x²−x−6=(x＋2)(x−3) だから、**(x＋1)(x−2)(x＋2)(x−3)**
　検算: x=−2 のとき 16＋16−28−16＋12=0、x=3 のとき 81−54−63＋24＋12=0 で、どちらも P(x)=0 になる ✓
　※(4) は、x＋1 で1回割ってできた3次式に、もう一度因数定理を使ってもよい。

**問5**
(1) **P(3)=0**  (2) **P(−2)=5**  (3) **P(−1)=0**  (4) **P(1/2)=0**
（指導メモ: (2) の x＋2 は x−(−2) と読む。(4) は、2x−1 を 0 にする x=1/2 を代入する。）

**問6**
(1) 解答例: P(x) を x−α で割った商を Q(x)、余りを R とすると、余りは定数で、P(x)=(x−α)Q(x)＋R が x についての恒等式として成り立つ。この等式に x=α を代入すると、(x−α)Q(x) の部分が 0 になり、P(α)=R となる。だから、余りは P(α) である。
(2) **正しくない**。x＋2=x−(−2) だから、余りは P(−2) である。割る式 x＋2 を 0 にする値は x=−2 であり、これを割り算の等式に代入したときに、商の部分が消えて余りだけが残る。

**S1**
(1) 余りを px＋q とすると、P(x)=(x−1)(x＋3)Q(x)＋px＋q。
x=1 を代入すると 4=p＋q、x=−3 を代入すると −8=−3p＋q。
2つの式から p=3, q=1。余りは **3x＋1**
(2) P(x) は2次式で x² の係数が 1 だから、(x−1)(x＋3) で割った商は 1 である。P(x)=(x−1)(x＋3)＋3x＋1=x²＋2x−3＋3x＋1=**x²＋5x−2**
　検算: P(1)=1＋5−2=4 ✓、P(−3)=9−15−2=−8 ✓
(3) P(x) は3次式で x³ の係数が 2 だから、(x−1)(x＋3) で割った商は 2x＋c（c は定数）とおける。P(x)=(x−1)(x＋3)(2x＋c)＋3x＋1 の定数項は (−1)×3×c＋1=−3c＋1 で、これが 7 に等しいので c=−2。
P(x)=(x²＋2x−3)(2x−2)＋3x＋1=2x³＋2x²−10x＋6＋3x＋1=**2x³＋2x²−7x＋7**
　検算: P(1)=2＋2−7＋7=4 ✓、P(−3)=−54＋18＋21＋7=−8 ✓
（指導メモ: L03 の stretch（割る式と余りから割られる式を復元する）と同じ型を、剰余の定理を使って解いている。）

## L14 高次方程式——因数定理で次数を下げる・複二次

**問1**
(1) x³−27=0 と変形し、L01 の公式で (x−3)(x²＋3x＋9)=0。x=3、または x²＋3x＋9=0 から x=(−3±√(9−36))/2=(−3±3√3 i)/2。
解は **x=3, (−3±3√3 i)/2**
(2) 8x³＋1=(2x)³＋1³=(2x＋1)(4x²−2x＋1)=0。x=−1/2、または 4x²−2x＋1=0 から x=(2±√(4−16))/8=(2±2√3 i)/8=(1±√3 i)/4。
解は **x=−1/2, (1±√3 i)/4**
　検算: x=(1＋√3 i)/4 のとき、x²=(1＋2√3 i−3)/16 で 4x²=(−1＋√3 i)/2、2x=(1＋√3 i)/2 だから、4x²−2x＋1=(−1＋√3 i−1−√3 i)/2＋1=0 ✓

**問2**
(1) P(x)=x³−4x²＋x＋6 とおくと、P(−1)=−1−4−1＋6=0。P(x)=(x＋1)(x²−5x＋6)=(x＋1)(x−2)(x−3)。**x=−1, 2, 3**
(2) P(1)=1＋1＋1−3=0。P(x)=(x−1)(x²＋2x＋3) で、x²＋2x＋3=0 から x=−1±√2 i。**x=1, −1±√2 i**
　検算: x=−1＋√2 i を x²＋2x＋3 に代入すると、(1−2√2 i−2)＋(−2＋2√2 i)＋3=0 ✓
(3) P(1)=2−3＋4−3=0。P(x)=(x−1)(2x²−x＋3) で、2x²−x＋3=0 から x=(1±√(1−24))/4=(1±√23 i)/4。**x=1, (1±√23 i)/4**
(4) P(1)=1−5＋8−4=0。P(x)=(x−1)(x²−4x＋4)=(x−1)(x−2)²。**x=1, 2**（x=2 は重解）

**問3**
(1) x²=X とおくと、X²−3X−4=(X−4)(X＋1)=0。x²=4 から x=±2、x²=−1 から x=±i。**x=±2, ±i**
(2) X²＋5X＋6=(X＋2)(X＋3)=0。x²=−2 から x=±√2 i、x²=−3 から x=±√3 i。**x=±√2 i, ±√3 i**
(3) X=x²＋x とおくと、X²−8X＋12=(X−2)(X−6)=0。
x²＋x=2 から x²＋x−2=(x＋2)(x−1)=0 で、x=−2, 1
x²＋x=6 から x²＋x−6=(x＋3)(x−2)=0 で、x=−3, 2
**x=1, −2, 2, −3**
（指導メモ: (3) は x² ではなく x²＋x というまとまりを置き換える。置き換えたら、最後に必ず x に戻す。）

**問4**
(1) x=3 を代入して 27−18＋3a＋6=0 より、a=−5。方程式は x³−2x²−5x＋6=0 で、x−3 で割ると商は x²＋x−2=(x＋2)(x−1)。**a=−5**、ほかの解は **x=1, −2**
(2) x=−1＋2i を代入する。(−1＋2i)²=−3−4i、(−1＋2i)³=(−1＋2i)(−3−4i)=11−2i だから、
(11−2i)＋a(−3−4i)＋b(−1＋2i)−5=0、つまり (6−3a−b)＋(−2−4a＋2b)i=0。
a, b は実数なので、6−3a−b=0、−2−4a＋2b=0。これを解いて **a=1, b=3**。
方程式は x³＋x²＋3x−5=0 で、P(1)=1＋1＋3−5=0 だから x−1 が因数である。x³＋x²＋3x−5=(x−1)(x²＋2x＋5) で、x²＋2x＋5=0 から x=−1±2i。
ほかの解は **x=1, −1−2i**
　※実部と虚部に分けるときは「a, b は実数」と書いてから比べる（L09 の相等）。

**問5** 誤り（例）: 3乗して 1 になる数を実数の範囲でしか探しておらず、虚数解を落としている。x³−1=(x−1)(x²＋x＋1)=0 で、x²＋x＋1=0 からも解が出る。
正しい解: **x=1, (−1±√3 i)/2**
　検算: x=(−1＋√3 i)/2 のとき、x²=(1−2√3 i−3)/4=(−1−√3 i)/2 で、x³=x²×x=(−1−√3 i)(−1＋√3 i)/4=(1＋3)/4=1 ✓

**問6**
(1) x⁴−16=(x²−4)(x²＋4)=0 で、解は x=±2, ±2i。**実数解2個、虚数解2個**
(2) x²−4=0 から x=±2、x²＋2x＋2=0 から x=−1±i。**実数解2個、虚数解2個**
(3) P(1)=0 から、x³＋x²−x−1=(x−1)(x²＋2x＋1)=(x−1)(x＋1)²。解は x=1, −1（x=−1 は重解）。**実数解3個（重解を2つと数える）、虚数解0個**

**S1**
(1) x³−8=(x−2)(x²＋2x＋4)=0。x=2、または x²＋2x＋4=0 から x=−1±√3 i。**x=2, −1＋√3 i, −1−√3 i**
(2) α, β は x²＋2x＋4=0 の2つの解だから、解と係数の関係より **α＋β=−2、αβ=4**。
確かめ: (−1＋√3 i)＋(−1−√3 i)=−2 ✓、(−1＋√3 i)(−1−√3 i)=1＋3=4 ✓
(3) α²＋β²=(α＋β)²−2αβ=4−8=**−4**、α³＋β³=(α＋β)³−3αβ(α＋β)=−8＋24=**16**
理由（例）: α, β は x³=8 の解だから α³=8、β³=8 で、α³＋β³=8＋8=16 となるから。
（指導メモ: 対称式の計算と、方程式の解であることという2つの道から、同じ値 16 が出ることを確かめさせる。三次方程式の解と係数の関係には入らない。）

## L15 方程式の活用——直方体の容積から三次方程式へ

**問1** 高さを x cm とすると、縦は (x−1) cm、横は (x＋3) cm。長さは正だから x>1 である。容積の条件から x(x−1)(x＋3)=160 で、展開して整理すると x³＋2x²−3x−160=0。
P(x)=x³＋2x²−3x−160 とおくと、P(5)=125＋50−15−160=0。x−5 で割ると商は x²＋7x＋32 だから、(x−5)(x²＋7x＋32)=0。
x²＋7x＋32=0 は D=49−128=−79<0 で、実数解をもたない（虚数解 x=(−7±√79 i)/2）。
吟味: 高さは x>1 を満たす実数だから、虚数解は捨てる。x=5 は条件を満たす。
**縦 4cm、横 8cm、高さ 5cm**
　検算: 4×8×5=160 ✓

**問2**
(1) 箱の底面は1辺 (12−2x) cm の正方形、高さは x cm だから、容積は **x(12−2x)² cm³**。x>0 かつ 12−2x>0 より、**0<x<6**
(2) x(12−2x)²=100 を整理する。(12−2x)²=4(6−x)² だから 4x(6−x)²=100 で、x(6−x)²=25、つまり x³−12x²＋36x−25=0。
x=1 を代入すると 1−12＋36−25=0 だから、x−1 が因数で、(x−1)(x²−11x＋25)=0。
x²−11x＋25=0 から、x=(11±√(121−100))/2=(11±√21)/2。
吟味: 0<x<6 を満たすかを調べる。x=1 は満たす。√21 は 4 と 5 の間の数なので、(11−√21)/2 は 3 と 3.5 の間にあり、条件を満たす。(11＋√21)/2 は 7.5 より大きく、条件を満たさない。
**x=1, (11−√21)/2**
　検算: x=1 のとき 1×10²=100 ✓。x=(11−√21)/2 のとき 12−2x=1＋√21 で、(1＋√21)²=22＋2√21 だから、x(12−2x)²=((11−√21)/2)×2(11＋√21)=121−21=100 ✓
（指導メモ: 表で x=1 だけを見つけて終えると、もう1つの答えを見落とす。本文 §3 の「表で1つ見つけて安心すると、もう1つを見落とす」の具体例である。）

**問3** もとの立方体の体積は x³ cm³、直方体の体積は (x＋2)(x−2)x cm³ である。横の長さ x−2 は正だから、x>2。
x³−x(x＋2)(x−2)=20 より、x³−(x³−4x)=20、4x=20 で、**x=5**
立式した方程式は、x³ の項が打ち消し合って、**一次方程式**になった。
　検算: 立方体は 125cm³、直方体は 7×3×5=105cm³ で、差は 20cm³ ✓

**問4** 解答例: 方程式を立てて因数分解すると、x=7 のほかの2つの解は虚数であり、実数の答えは x=7 だけだと確かめられる。表では整数の値しか調べていないので、それだけでは、整数でない答えがあるかどうかは分からない。方程式を解けば、条件を満たす値を、整数でないものも含めて全部そろえてから、事象に合うものを選べる。
（採点の目安: 「ほかに答えがないことが確かめられる」「整数でない値も含めて調べられる」のどちらかに触れていればよい。「x が大きいほど容積も大きい」ことから答えが1つだと述べる答えも、方程式を立てた場合との比較として書いていれば正解とする。）

**S1**
(1) 2x＋2y＋1=21 より **y=10−x**、x＋z＋2=18 より **z=16−x**。容積は **V=x(10−x)(16−x)**
(2) V=240 より x(10−x)(16−x)=240。展開して整理すると、x³−26x²＋160x−240=0。
x=6 を代入すると 216−936＋960−240=0 だから、x−6 が因数で、(x−6)(x²−20x＋40)=0。
x²−20x＋40=0 から x=10±√60=10±2√15。
解は **x=6, 10＋2√15, 10−2√15**
(3) 寸法として適するには、x>0、y=10−x>0、z=16−x>0、つまり 0<x<10 が必要である。√15 は 3 と 4 の間の数なので、10−2√15 は 2 と 4 の間にあって条件を満たし、10＋2√15 は 16 より大きく、条件を満たさない。
適するのは **x=6 と x=10−2√15 の2つ**
x=6 のとき、**底面の2辺は 6cm と 4cm、高さは 10cm**
x=10−2√15 のとき、**底面の2辺は (10−2√15) cm と 2√15 cm、高さは (6＋2√15) cm**
　検算: x=6 のとき 6×4×10=240 ✓。x=10−2√15 のとき、(10−2√15)(6＋2√15)=60＋20√15−12√15−60=8√15 で、これに 2√15 を掛けると 16×15=240 ✓
（指導メモ: 容積が 240cm³ になる寸法が2通りあるのは、x を大きくすると底面のもう1辺と高さが短くなり、x が大きいほど容積も大きい、とは言えないからである。容積が最大になる寸法は、数学Ⅱ「微分・積分の考え」で扱う。）
