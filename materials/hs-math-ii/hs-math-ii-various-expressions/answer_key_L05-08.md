## L05 恒等式——「いつでも成り立つ」と未定係数法

**問1**
(1) 左辺を展開すると x²−9 で、右辺と同じ式になる。**恒等式**
(2) 移項して整理すると (x²＋2x＋1)−(x²＋1)=2x=0。x=0 のときだけ成り立つ**方程式**で、解は **x=0**
※x=1 を入れると左辺は 4、右辺は 2 で成り立たないので、恒等式ではない（(x＋1)² を x²＋1 としてしまう誤りと同じ形の等式）。
(3) 左辺=x²＋2x−(x²＋2x＋1)=−1 で、右辺と同じ式になる。**恒等式**
(4) 左辺を展開すると x²−2x＋1。x²−2x＋1=x²−2x を整理すると 1=0 となり、どんな x でも成り立たない。**恒等式ではなく、解をもたない方程式である**（成り立つ x はない）

**問2**
(1) 右辺=ax²＋(3a＋b)x＋3b。係数を比べて a=2、3a＋b=5、3b=−3。第1式・第3式から a=2, b=−1 で、第2式 3×2＋(−1)=5 も満たす。**a=2, b=−1**
　検算: (x＋3)(2x−1)=2x²−x＋6x−3=2x²＋5x−3 ✓
※条件の式が3つで文字が2つなので、求めた値が残りの式も満たすかを必ず確かめる（満たさなければ、恒等式にする a, b はない）。
(2) 右辺=a(x²＋2x＋1)＋b(x＋1)＋c=ax²＋(2a＋b)x＋(a＋b＋c)。係数を比べて a=1、2a＋b=4、a＋b＋c=1。よって **a=1, b=2, c=−2**
　検算: (x＋1)²＋2(x＋1)−2=x²＋2x＋1＋2x＋2−2=x²＋4x＋1 ✓

**問3** x=1 を代入すると 1−1＋3=c より c=3。x=2 を代入すると 4−2＋3=b＋c より b=2。x=0 を代入すると 3=a×(−1)×(−2)＋b×(−1)＋c=2a−2＋3 より a=1。
確かめ: a=1, b=2, c=3 のとき、右辺=(x−1)(x−2)＋2(x−1)＋3=x²−3x＋2＋2x−2＋3=x²−x＋3 で左辺と同じ式になり、恒等式である ✓。よって **a=1, b=2, c=3**

**問4** 3次式を2次式で割るので、商は1次式で、x の係数は 1。商を x＋a、余りを bx＋c とおく。
x³−4x²＋2x＋5=(x²−x＋2)(x＋a)＋bx＋c
右辺=x³＋(a−1)x²＋(2−a＋b)x＋(2a＋c)。係数を比べて a−1=−4、2−a＋b=2、2a＋c=5。よって a=−3, b=−3, c=11。
商 **x−3**、余り **−3x＋11**
筆算での確かめ: x(x²−x＋2)=x³−x²＋2x を引いて −3x²＋0x＋5。−3(x²−x＋2)=−3x²＋3x−6 を引いて −3x＋11 ✓

**問5** 左辺を k について整理すると (x＋2)k＋(3−y)。これがどんな k でも 0 になる（k についての恒等式になる）には、k の係数と定数項がどちらも 0 であればよい。x＋2=0、3−y=0 より **x=−2, y=3**
　確かめ: x=−2, y=3 のとき、左辺=−2k＋2k−3＋3=0 で、k の値によらず成り立つ ✓
（指導メモ: 数学Ⅱ「図形と方程式」で、k を含む直線の式が k の値によらず通る点を求める場面の前触れ。ここでは図形の意味には触れない。）

**問6** 解答例: 1つの値（x=0）で成り立っても、恒等式とは言えない。恒等式は x にどんな値を入れても成り立つ等式であり、実際、x=1 を入れると左辺は 4、右辺は 2 で成り立たない。正しくは、この等式は x=0 のときだけ成り立つ方程式である（問1(2)）。
（採点の目安: 「どんな値でも成り立つ必要がある」ことと、成り立たない値（反例）を1つ挙げていれば十分。）

**S1** 両辺に (x＋1)(x＋3) を掛けると 1=a(x＋3)＋b(x＋1)=(a＋b)x＋(3a＋b)。これが x についての恒等式になるので、係数を比べて a＋b=0、3a＋b=1。よって **a=1/2, b=−1/2**
確かめ: (1/2)/(x＋1)−(1/2)/(x＋3)=((x＋3)−(x＋1))/(2(x＋1)(x＋3))=2/(2(x＋1)(x＋3))=1/((x＋1)(x＋3)) で、左辺に戻る ✓
（別解: 1=a(x＋3)＋b(x＋1) に x=−1 を入れると 1=2a、x=−3 を入れると 1=−2b。分母を払った等式は多項式どうしの恒等式なので、もとの式で考えなかった x=−1, −3 を入れてもよい。）

## L06 等式の証明——A−B=0 を示す

**問1**
(1) 左辺−右辺=(a²＋2ab＋b²)−(a²−2ab＋b²)−4ab=0。よって (a＋b)²−(a−b)²=4ab
(2) 左辺=(x³＋3x²y＋3xy²＋y³)−(x³−3x²y＋3xy²−y³)=6x²y＋2y³。よって 左辺−右辺=(6x²y＋2y³)−2y(3x²＋y²)=6x²y＋2y³−6x²y−2y³=0。よって等式は成り立つ。
(3) 右辺を展開すると (a²x²＋2abxy＋b²y²)−(a²y²＋2abxy＋b²x²)=a²x²−a²y²−b²x²＋b²y²。左辺を展開すると a²x²−a²y²−b²x²＋b²y²。よって 左辺−右辺=0 で、等式は成り立つ。
　検算（(3)）: a=2, b=1, x=3, y=1 → 左辺 3×8=24、右辺 7²−5²=24 ✓

**問2**
(1) 条件から c=−a−b。左辺=a²−b(−a−b)=a²＋ab＋b²、右辺=b²−(−a−b)a=a²＋ab＋b²。よって 左辺−右辺=0 で、等式は成り立つ。
　別解: 左辺−右辺=a²−b²−bc＋ca=(a−b)(a＋b)＋c(a−b)=(a−b)(a＋b＋c)。条件から a＋b＋c=0 なので、左辺−右辺=0。
(2) 条件から a＋b=−c、b＋c=−a、c＋a=−b。よって 左辺=(−c)(−a)(−b)＋abc=−abc＋abc=0=右辺。
（指導メモ: c を消去して展開しても示せるが、条件式を「2つの和は、残りの1つの符号を変えたもの」と読み替えると1行で済む。式をひとまとまりとして見る例。）

**問3** a/b=c/d=k とおくと、a=bk, c=dk。
(1) 左辺=(bk＋b)/b=k＋1、右辺=(dk＋d)/d=k＋1。よって 左辺=右辺。
(2) 左辺=(b²k²＋d²k²)/(b²＋d²)=k²(b²＋d²)/(b²＋d²)=k²、右辺=(bk×dk)/(bd)=k²。よって 左辺=右辺。

**問4** よくない理由（例）: a=1 と a=2 の2つの値で成り立つことを確かめただけで、ほかの値について成り立つことを示していない。証明では、どんな値の a についても成り立つことを、文字のまま示す必要がある。
正しい証明: 左辺−右辺=(a²＋2a＋1)−(a²−2a＋1)−4a=0。よって (a＋1)²−(a−1)²=4a
（指導メモ: この等式そのものは正しい。結論が正しくても、示し方が証明になっていないことを区別させる。）

**問5**
(1) 左辺=(x²−1)(x²＋1)=x⁴−1=右辺（(x−1)(x＋1)=x²−1 を先に計算し、もう一度「和と差の積」の公式を使う）
(2) 左辺を展開すると x⁴−1 なので、左辺−右辺=(x⁴−1)−(x⁴−1)=0。よって 左辺=右辺。
どちらが短いか（例）: (1) のほうが短く書けた。和と差の積の公式を2回使えば、左辺がそのまま右辺になるから。
（採点の目安: どちらを選んでもよく、理由が式の形に基づいていればよい。見通しが立つときは (1)、立たないときは (2)、と使い分けられることが大切。）

**S1**
(1) 解答例: x:y:z=2:3:4 は、x, y, z が 2, 3, 4 をそれぞれ同じ倍率で拡大（縮小）した数であることを表す。その倍率を k とすると、x=2k, y=3k, z=4k と書ける。x, y, z は 0 でないので、k は 0 でない。
(2) (xy＋yz＋zx)/(x²＋y²＋z²)=(6k²＋12k²＋8k²)/(4k²＋9k²＋16k²)=26k²/(29k²)=**26/29**
　検算: k=1（x=2, y=3, z=4）のとき (6＋12＋8)/(4＋9＋16)=26/29 ✓

## L07 不等式の証明①——実数の平方は0以上・等号が成り立つとき

**問1** a>b, x>y を満たすすべての実数について示す。左辺−右辺=ax＋by−ay−bx=a(x−y)−b(x−y)=(a−b)(x−y)。a−b>0, x−y>0 だから (a−b)(x−y)>0。よって ax＋by>ay＋bx。
　検算: a=3, b=1, x=2, y=1 → 左辺 6＋1=7、右辺 3＋2=5 で 7>5 ✓

**問2**
(1) すべての実数 a, b について示す。左辺−右辺=4a²−4ab＋b²=(2a−b)²≧0。よって 4a²＋b²≧4ab。等号は 2a−b=0、つまり **b=2a のとき**。
　検算: a=1, b=2 → 左辺 4＋4=8、右辺 4×1×2=8 で等しい ✓
(2) すべての実数 x, y について示す。左辺−右辺=x²−2x＋1＋y²−2y＋1=(x−1)²＋(y−1)²≧0。よって x²＋y²≧2(x＋y−1)。等号は x−1=0 かつ y−1=0、つまり **x=y=1 のとき**。
　検算: x=y=1 → 左辺 2、右辺 2(1＋1−1)=2 で等しい ✓
※−2(x＋y−1)=−2x−2y＋2 の ＋2 を 1 と 1 に分けて、x と y をそれぞれ平方完成する。
(3) すべての実数 x, y について示す。右辺−左辺=2x²＋2y²−(x²＋2xy＋y²)=x²−2xy＋y²=(x−y)²≧0。よって (x＋y)²≦2(x²＋y²)。等号は **x=y のとき**。
※≦ の不等式では、大きい方の辺から小さい方の辺を引いた「右辺−左辺」を作ると、符号を考えやすい。

**問3** x²＋6x＋10=(x＋3)²＋1。(x＋3)²≧0 だから (x＋3)²＋1≧1>0。よって、すべての実数 x について x²＋6x＋10>0。

**問4** すべての実数 a, b について示す。a に着目して平方完成すると、
a²−ab＋b²=(a−b/2)²−b²/4＋b²=(a−b/2)²＋(3/4)b²
(a−b/2)²≧0、(3/4)b²≧0 だから、a²−ab＋b²≧0。等号は a−b/2=0 かつ b=0、つまり **a=b=0 のとき**。
　検算: a=b=1 → 1−1＋1=1>0 ✓、a=b=0 → 0 ✓
※(a−b/2)² を展開すると a²−ab＋b²/4 なので、残りの (3/4)b² を足して帳尻を合わせる。

**問5** a>b>0 より、L07 §4（正の数どうしは2乗で比べてよい）から √a>√b>0。よって左辺 √a−√b は正で、右辺 √(a−b) も正。両辺が正なので、2乗の差を調べる。
(√(a−b))²−(√a−√b)²=(a−b)−(a−2√a√b＋b)=2√a√b−2b=2√b(√a−√b)
√b>0、√a−√b>0 だから、これは正。よって (√a−√b)²<(√(a−b))² で、両辺とも正なので √a−√b<√(a−b)。
　検算: a=9, b=4 → 左辺 3−2=1、右辺 √5（2 より大きい）で 1<√5 ✓

**問6**
(1) 正しくない。a=0 のとき a²=0 であり、a²>0 は成り立たない。正しくは「すべての実数 a について a²≧0 である（等号が成り立つのは a=0 のとき）」。
(2) x=3, y=3 のとき、左辺 9＋9=18、右辺 2×3×3=18 で等しい（等号が成り立つ）。x=3, y=1 のとき、左辺 9＋1=10、右辺 6 で、左辺のほうが大きい（等号は成り立たない）。「等号が成り立つのは x=y のとき」とは、x と y が等しいときにだけ両辺がちょうど等しくなり、それ以外のときは左辺のほうが大きい、という意味である。

**S1** すべての実数 a, b, c について示す。
2(左辺−右辺)=2a²＋2b²＋2c²−2ab−2bc−2ca=(a²−2ab＋b²)＋(b²−2bc＋c²)＋(c²−2ca＋a²)=(a−b)²＋(b−c)²＋(c−a)²≧0
よって 左辺−右辺≧0 で、a²＋b²＋c²≧ab＋bc＋ca。等号は a−b=0 かつ b−c=0 かつ c−a=0、つまり **a=b=c のとき**。
　検算: a=b=c=2 → 左辺 12、右辺 12 で等しい ✓。a=1, b=2, c=3 → 左辺 14、右辺 11 で 14>11 ✓

## L08 不等式の証明②——絶対値の性質と相加・相乗平均の関係

**問1**
(1) a を a−b に置き換えると |(a−b)＋b|≦|a−b|＋|b|、つまり **|a|≦|a−b|＋|b|**
(2) (1) の不等式はすべての実数 a, b について成り立つ（例題1 の不等式の a に a−b を入れただけである）。両辺から |b| を引くと |a|−|b|≦|a−b| となり、証明できた。
（指導メモ: 例題1 の不等式を道具として使い、置き換えで別の不等式を導く例。式をひとまとまりとして見る見方の応用である。）

**問2**
(2, 3): 左辺 |2−3|=1、右辺 2＋3=5 で、等しくない。
(2, −3): 左辺 |2＋3|=5、右辺 2＋3=5 で、等しい。
(0, −3): 左辺 |0＋3|=3、右辺 0＋3=3 で、等しい。
条件（例）: |a−b|=|a＋(−b)|、|b|=|−b| なので、例題1 の「|a＋b|=|a|＋|b| ⇔ ab≧0」の b を −b に替えると、a(−b)≧0、つまり **ab≦0 のとき**（a と b が異なる符号か、少なくとも一方が 0 のとき）に等号が成り立つ。

**問3**
(1) a/b>0, b/a>0 だから、相加・相乗平均の関係より a/b＋b/a≧2√((a/b)×(b/a))=2。等号は a/b=b/a、つまり a²=b² のときで、a>0, b>0 より **a=b のとき**。
(2) 左辺=1＋2a/b＋2b/a＋4=5＋2(a/b＋b/a)。(1) より a/b＋b/a≧2 だから、左辺≧5＋4=9。等号は **a=b のとき**。
　検算: a=b=1 → (1＋2)(1＋2)=9 ✓

**問4**
(1) x>0, 9/x>0 だから x＋9/x≧2√(x×9/x)=6。等号は x=9/x、つまり x²=9 で、x>0 より x=3。**最小値 6**（x=3 のとき）
(2) 2x>0, 8/x>0 だから 2x＋8/x≧2√(2x×8/x)=2√16=8。等号は 2x=8/x、つまり x²=4 で、x>0 より x=2。**最小値 8**（x=2 のとき）
(3) (x＋1)(x＋4)/x=(x²＋5x＋4)/x=x＋5＋4/x。x>0, 4/x>0 だから x＋4/x≧2√4=4 で、x＋5＋4/x≧9。等号は x=4/x、つまり x=2。**最小値 9**（x=2 のとき）
　検算: (3) x=2 → 3×6/2=9 ✓
※(3) は、分数式を項ごとに分けて（L04）、積が定数になる2つの項 x と 4/x を作るのが要。

**問5** 理由（例）: 不等式 x＋4/x≧3 は正しいが、x＋4/x=3 となる x は存在しない（実際、相加・相乗平均の関係から x＋4/x≧4 なので、3 になることはない）。最小値と言えるのは、その値に実際に等しくなる x があるときだけである。
正しい最小値: x>0, 4/x>0 だから x＋4/x≧2√4=4。等号は x=4/x、つまり x²=4 で、x>0 より x=2。**最小値 4**（x=2 のとき）

**問6** 横の長さを x cm（x>0）とすると、縦の長さは 16/x cm で、周の長さは 2(x＋16/x) cm。x>0, 16/x>0 だから x＋16/x≧2√16=8 で、周の長さは 16 以上。等号は x=16/x、つまり x²=16 で、x>0 より x=4。このとき縦の長さも 16/4=4 である。
**周の長さの最小値は 16 cm**（縦 4 cm・横 4 cm の正方形のとき）
（指導メモ: 「面積が一定の長方形のうち、周の長さが最小になるのは正方形」という事実を、式で確かめた形。）

**S1**
(1) (a＋1/b)(b＋4/a)=ab＋4＋1＋4/(ab)=ab＋4/(ab)＋5。ab>0, 4/(ab)>0 だから ab＋4/(ab)≧2√4=4 で、全体は 4＋5=9 以上。等号は ab=4/(ab)、つまり (ab)²=4 で、ab>0 より ab=2 のとき。**最小値 9**（ab=2 のとき）（たとえば a=1, b=2 のとき (1＋1/2)(2＋4)=9）
(2) 解答例: 1つ目の不等式の等号は a=1/b、つまり ab=1 のときに、2つ目の不等式の等号は b=4/a、つまり ab=4 のときに成り立つ。この2つは同時には成り立たないので、掛け合わせてできる (a＋1/b)(b＋4/a)≧8 の等号は、どんな a, b でも成り立たない。8 は下からおさえる値としては正しいが、式が 8 に等しくなることはないので、最小値ではない。実際の最小値は (1) の 9 である。
（指導メモ: 2つの不等式を組み合わせるときは、それぞれの等号が同時に成り立つかを確かめる必要がある。L08 の guide の「等号は確かめるもの」の応用。）
