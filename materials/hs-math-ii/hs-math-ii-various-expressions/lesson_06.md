## 1. 等式を証明するとは

L05 で、文字にどんな値を入れても成り立つ等式を恒等式と呼んだ。等式 A=B を**証明する**とは、A=B が恒等式であること、つまり文字にどんな値を入れても A と B の値が等しくなることを、式の変形によって示すことである（§3 の条件がついた等式では、条件を満たすどんな値でも成り立つことを示す）。

値をいくつか入れて確かめるだけでは、証明にならない。L05 で見たように、(x＋2)²=x²＋4 は x=0 では成り立つが、恒等式ではなかった。どれほど多くの値で確かめても、まだ確かめていない値が残っている。「どんな値でも」を示すには、文字のまま式を変形する（L05 の guide のように、両辺の次数を根拠にして、決まった個数の値で済ませる方法もあるが、この単元の証明では文字のまま変形する型を使う）。

:::guide
**具体例で確かめて終わり、ではなぜいけないのか**

証明を求められて、a=1 や a=2 を入れて両辺が等しいことを確かめて「よって成り立つ」と書く考え方は、よく見られる。具体例で確かめることには、ちゃんと意味がある。成り立ちそうだという見通しが立つし、成り立たない値が見つかれば「その等式は誤り」と確定できる。しかし「成り立つ」ことの証明にはならない。確かめた値が a=1 と a=2 の2つなら、示せたのはその2つの値で成り立つことだけで、a=3 や a=−5 や a=1/3 については何も言えていない。文字 a は「どんな値でもよい数」の代表として書いている。だから、文字のまま変形して等しいことを示せば、すべての値について一度に示したことになる。具体例は「証明の前の見通し」と「証明の後の検算」に使い、証明そのものは文字で書く、と役割を分けよう。
:::

## 2. 3つの方法を1つの例題で比べる

等式の証明には、主に次の3つの方法がある。

1. 一方の辺を変形して、他方の辺を導く。
2. 両辺をそれぞれ変形して、同じ式を導く。
3. 左辺−右辺 を計算して、0 になることを示す。

同じ等式を3つの方法で証明して、違いを比べる。

**例題1** 等式 (a²＋b²)(c²＋d²)=(ac＋bd)²＋(ad−bc)² を証明せよ。

方法1（左辺を変形して右辺を導く）: 左辺を展開すると a²c²＋a²d²＋b²c²＋b²d²。右辺の形に近づけるため、2abcd を足して引く工夫をする。

左辺=(a²c²＋2abcd＋b²d²)＋(a²d²−2abcd＋b²c²)=(ac＋bd)²＋(ad−bc)²=右辺

方法2（両辺をそれぞれ変形して同じ式にする）:

左辺=a²c²＋a²d²＋b²c²＋b²d²
右辺=(a²c²＋2abcd＋b²d²)＋(a²d²−2abcd＋b²c²)=a²c²＋a²d²＋b²c²＋b²d²

両辺が同じ式になったので、左辺=右辺。

方法3（左辺−右辺=0 を示す）:

左辺−右辺=(a²c²＋a²d²＋b²c²＋b²d²)−(a²c²＋2abcd＋b²d²＋a²d²−2abcd＋b²c²)=0

よって、左辺=右辺。

3つを比べると、方法1 は「2abcd を足して引く」という工夫を思いつく必要があり、行き先が見えていないと書けない。方法2 と方法3 は、展開して整理するだけで進められる。とくに方法3 は「左辺−右辺 を作り、整理して 0 になるかを見る」と手順が1本に決まっているので、どんな等式にも同じ形で使える。この教材では、練習の多くを方法3 で書く。

:::guide
**証明は「左辺=右辺」と書いて始めない**

証明を「(a²＋b²)(c²＋d²)=(ac＋bd)²＋(ad−bc)²」と書いて始め、両辺を変形して「0=0」にたどり着いて終える書き方がある。これは、示したい結論を最初に正しいと認めて書いてしまっているので、証明の形になっていない。結論から出発して正しい式にたどり着いても、結論が正しいことにはならないからだ。極端な例を挙げる。「−1=1」から出発して両辺を2乗すると「1=1」という正しい式になるが、もちろん −1=1 は正しくない。方法3 の書き方なら、この問題は起こらない。「左辺−右辺」という1つの式を計算しているだけで、等号は「式を変形して同じ値の式に書き換えた」ことしか表していないからだ。最後に「0 になった、よって左辺=右辺」と結論を書く。方法2 も、左辺と右辺を別々に計算して最後に見比べるので、結論の等式を最初に書いてはいない。等号の向きと、結論を書く位置に気をつけよう。
:::

## 3. 条件つきの等式——条件を使って文字を減らす

「a＋b=1 のとき」のように条件がついた等式は、どんな値でも成り立つわけではなく、条件を満たす値について成り立つ。証明では、その条件を必ずどこかで使う。

**例題2** a＋b=1 のとき、等式 a²＋b=b²＋a を証明せよ。

方法A（文字を1つ減らす）: 条件から b=1−a。これを両辺に代入すると、

左辺=a²＋(1−a)=a²−a＋1、右辺=(1−a)²＋a=1−2a＋a²＋a=a²−a＋1

両辺が同じ式になったので、左辺=右辺。

方法B（左辺−右辺 を因数分解して、条件を使う）:

左辺−右辺=a²−b²−(a−b)=(a−b)(a＋b)−(a−b)=(a−b)(a＋b−1)

条件から a＋b−1=0 なので、左辺−右辺=(a−b)×0=0。よって、左辺=右辺。

方法A は、条件式を「1つの文字について解いて代入する」やり方で、手順が決まっている。方法B は、左辺−右辺 の中に条件式の形（a＋b−1）を見つけて使うやり方で、式の形を見る目が要るが、計算は短い。どちらも、条件を使わなければ示せない等式を、条件を使って示している。

## 4. 比例式——「=k」とおく

a/b=c/d のように、2つの比の値が等しいことを表す等式は、教科書で**比例式**と呼ばれる（分母は 0 でないとする）。中学で学んだ a:b=c:d を、比の値で書いた形である。比例式の条件がついた等式は、比の値を k とおいて文字を置き換えると、見通しよく証明できる。

**例題3** a/b=c/d のとき、等式 (a＋c)/(b＋d)=(a−c)/(b−d) を証明せよ。ただし、分母はどれも 0 でないとする。

a/b=c/d=k とおくと、a=bk、c=dk。これを使うと、

左辺=(bk＋dk)/(b＋d)=k(b＋d)/(b＋d)=k
右辺=(bk−dk)/(b−d)=k(b−d)/(b−d)=k

両辺がどちらも k に等しいので、左辺=右辺。

:::guide
**比例式は「=k」で1つの文字にまとめる**

a/b=c/d には a, b, c, d の4つの文字が出てくるが、条件は「2つの比の値が等しい」という1つだけである。この「共通の比の値」を k という1つの文字で表すと、a=bk、c=dk となり、a と c を b, d, k で書き直せる。すると、示したい等式の両辺が k の式にまとまり、あとは約分するだけになる。これは L01 の診断2で x−2 を M とおいたのと同じで、式のまとまりに名前をつける見方である。k とおかずに a/b=c/d を分母を払って ad=bc と書き直し、そこから示すこともできるが、どこで ad=bc を使えばよいかを探す手間がかかる。「=k とおく」は、その探索を手順に置き換える工夫だと言える。
:::

## 5. 手順の型——等式の証明

1. 示したい等式の左辺と右辺が何かを書き出す。「左辺=右辺」を最初に書いて、そこから変形を始めない。
2. 左辺−右辺 を計算して 0 になることを示す（または、一方の辺を変形して他方の辺を導く）。
3. 条件式があれば、1つの文字について解いて代入するか、条件式の形（a＋b−1 など）を作って使う。
4. 比例式の条件は、比の値を k とおいて、文字を k の式で書き直す。
5. 最後に「よって、左辺=右辺」のように結論を書く。

(1) a²−bc=b²−ca

(1) (a＋b)/b=(c＋d)/d
(2) (a²＋c²)/(b²＋d²)=ac/(bd)

**問4** 次の「証明」がよくない理由を説明し、正しい証明に書き直せ。
「(a＋1)²−(a−1)²=4a を証明する。a=1 のとき、左辺は 4−0=4、右辺は 4 で等しい。a=2 のとき、左辺は 9−1=8、右辺は 8 で等しい。よって、この等式は成り立つ。」
