## L01 三次の乗法公式と因数分解——公式は4本・展開して戻す

**問1**
(1) (x＋4)³=x³＋3×x²×4＋3×x×4²＋4³=**x³＋12x²＋48x＋64**
　検算: x=1 → 5³=125、1＋12＋48＋64=125 ✓
(2) (3x−2)³=(3x)³−3×(3x)²×2＋3×3x×2²−2³=**27x³−54x²＋36x−8**
　検算: x=1 → 1³=1、27−54＋36−8=1 ✓
(3) (2a＋3b)³=(2a)³＋3×(2a)²×3b＋3×2a×(3b)²＋(3b)³=**8a³＋36a²b＋54ab²＋27b³**
　検算: a=1, b=1 → 5³=125、8＋36＋54＋27=125 ✓
※(2a)³ を 2a³、(3b)² を 3b² としない。かっこごと累乗する。

**問2** 予想: どれも公式3・4の右辺と同じ形なので、途中の項が打ち消し合って2つの項だけが残る。
(1) (x−3)(x²＋3x＋9)=x³＋3x²＋9x−3x²−9x−27=**x³−27**（公式4で a を x、b を 3 と読んだ形）
(2) (2a＋1)(4a²−2a＋1)=8a³−4a²＋2a＋4a²−2a＋1=**8a³＋1**（公式3で a を 2a、b を 1 と読んだ形）
(3) (x＋2y)(x²−2xy＋4y²)=x³−2x²y＋4xy²＋2x²y−4xy²＋8y³=**x³＋8y³**
　検算: (1) x=1 → (−2)×13=−26、1−27=−26 ✓　(2) a=1 → 3×3=9、8＋1=9 ✓　(3) x=1, y=1 → 3×3=9、1＋8=9 ✓
（指導メモ: 形を見て公式3・4の右辺だと気づけば、展開は1行で済む。気づけなかった場合も、分配法則で展開すれば同じ答えになる。予想と結果を比べる習慣が、式の形を見る目を育てる。）

**問3**
(1) 125=5³ だから公式4で x³−125=**(x−5)(x²＋5x＋25)**
　検算: 展開 x³＋5x²＋25x−5x²−25x−125=x³−125 ✓
(2) 8a³=(2a)³、27b³=(3b)³ だから公式3で 8a³＋27b³=**(2a＋3b)(4a²−6ab＋9b²)**
　検算: 展開 8a³−12a²b＋18ab²＋12a²b−18ab²＋27b³=8a³＋27b³ ✓
(3) 共通因数 3 をくくり出して 3(x³＋8)=**3(x＋2)(x²−2x＋4)**
　検算: (x＋2)(x²−2x＋4)=x³＋8、3倍して 3x³＋24 ✓
※3x³＋24 のまま「何の3乗か」を探すと、3x³ が3乗の形にならず行き詰まる。共通因数を先にくくり出す（手順の型の1）。
(4) 共通因数 x をくくり出して x(x³＋1)=**x(x＋1)(x²−x＋1)**
　検算: (x＋1)(x²−x＋1)=x³＋1、x 倍して x⁴＋x ✓

**問4**
(1) x=1 を代入すると、左辺は 3³=27、右辺は 1＋8=9 で一致しないので誤り。正しくは (x＋2)³=**x³＋6x²＋12x＋8**
　検算: x=1 → 27、1＋6＋12＋8=27 ✓
(2) 右辺を展開すると x³−2x²＋4x−2x²＋4x−8=x³−4x²＋8x−8 となり、左辺に戻らないので誤り（2つ目のかっこの真ん中の符号が逆）。正しくは x³−8=**(x−2)(x²＋2x＋4)**
　検算: 展開 x³＋2x²＋4x−2x²−4x−8=x³−8 ✓
(3) a=1, b=1 を代入すると、左辺は 0、右辺は 1−3−3−1=−6 で一致しないので誤り（第3項の符号が逆）。正しくは (a−b)³=**a³−3a²b＋3ab²−b³**
　検算: a=2, b=1 → 1、8−12＋6−1=1 ✓
（指導メモ: (1) は「3乗をそれぞれに配る」誤り、(2) は符号の覚え違い、(3) は b を −b に置き換えるときに (−b)²=b² の符号を落とした誤り。どれも、1つの値の代入か展開して戻すことで自分で見つけられる。値の代入で一致しても正しいとは限らないが、一致しなければ誤りと確定できる。）

**問5**
(1) x＋1=M とおくと M³−8=M³−2³=(M−2)(M²＋2M＋4)。M を戻して (x＋1−2){(x＋1)²＋2(x＋1)＋4}=**(x−1)(x²＋4x＋7)**
　検算: 答えを展開すると x³＋4x²＋7x−x²−4x−7=x³＋3x²＋3x−7。もとの式を直接展開しても (x³＋3x²＋3x＋1)−8=x³＋3x²＋3x−7 で一致 ✓
※(x＋1)²＋2(x＋1)＋4 は展開・整理して x²＋4x＋7 まで進める。M を残したまま答えない。
(2) x³=M とおくと M²−64=(M−8)(M＋8)。M を戻して (x³−8)(x³＋8)。それぞれに公式4・3を使って **(x−2)(x²＋2x＋4)(x＋2)(x²−2x＋4)**
　検算: 展開して戻す。(x−2)(x²＋2x＋4)=x³−8、(x＋2)(x²−2x＋4)=x³＋8 で、その積は (x³−8)(x³＋8)=x⁶−64 ✓。値でも x=1 → もとの式 1−64=−63、答え (−1)×7×3×3=−63 ✓

**問6** 解答例: 1辺 a＋b の立方体を各辺で a と b の長さに分けて切ると、縦・横・高さのうち1つの向きだけが b で、残りの2つの向きが a の直方体（体積 a²b）ができる。b になる向きは縦・横・高さの3通りあるので、この直方体は3個あり、体積の合計が 3a²b になる。
（採点の目安: 「a²b の直方体が3個ある」ことと、その「3」がどこから来るか（b の長さの辺の向きが3通り）の両方が書けていればよい。L02 では、この「3通り」を「3つのかっこのどれから b を選ぶか」と読み替える。）

**S1**
(1) 右辺=(a³＋3a²b＋3ab²＋b³)−(3a²b＋3ab²)=a³＋b³ で、左辺に等しい ✓
(2) (1) より a³＋b³=M³−3abM。よって
a³＋b³＋c³−3abc=M³−3abM＋c³−3abc=(M³＋c³)−3ab(M＋c)
=(M＋c)(M²−Mc＋c²)−3ab(M＋c)=(M＋c)(M²−Mc＋c²−3ab)
ここで M＋c=a＋b＋c、M²−Mc＋c²−3ab=a²＋2ab＋b²−ac−bc＋c²−3ab=a²＋b²＋c²−ab−bc−ca。
よって **a³＋b³＋c³−3abc=(a＋b＋c)(a²＋b²＋c²−ab−bc−ca)**
(3) a=1, b=2, c=3 のとき、もとの式は 1＋8＋27−18=**18**、答えは 6×(1＋4＋9−2−6−3)=6×3=**18** で一致 ✓
（指導メモ: M³＋c³ に公式3を使うところが要。M を1つの文字とみる置き換えが、3文字の式でも働くことを確かめさせる。）

## L02 二項定理——(a＋b)ⁿ の係数を「選び方」で数える

**問1**
(1) 5C0〜5C5 は 1, 5, 10, 10, 5, 1 だから (x＋1)⁵=**x⁵＋5x⁴＋10x³＋10x²＋5x＋1**
　検算: x=1 → 2⁵=32、1＋5＋10＋10＋5＋1=32 ✓
(2) a を a、b を −2b と読む。(a−2b)⁴=a⁴＋4a³(−2b)＋6a²(−2b)²＋4a(−2b)³＋(−2b)⁴=**a⁴−8a³b＋24a²b²−32ab³＋16b⁴**
　検算: a=1, b=1 → (−1)⁴=1、1−8＋24−32＋16=1 ✓
(3) a を 3x、b を 1 と読む。(3x＋1)⁴=(3x)⁴＋4(3x)³＋6(3x)²＋4(3x)＋1=**81x⁴＋108x³＋54x²＋12x＋1**
　検算: x=1 → 4⁴=256、81＋108＋54＋12＋1=256 ✓

**問2**
(1) 一般項 7Cr x⁷⁻ʳ3ʳ。x⁵ の項は r=2 で、係数は 7C2×3²=21×9=**189**
(2) (2x−1)⁸=(2x＋(−1))⁸。一般項 8Cr(2x)⁸⁻ʳ(−1)ʳ。x³ の項は 8−r=3 より r=5 で、係数は 8C5×2³×(−1)⁵=56×8×(−1)=**−448**
※8C5=8C3=(8×7×6)/(3×2×1)=56。r=5 は奇数なので符号は−。r と x の指数を取り違えて r=3 とし、8C3×2⁵×(−1)³=−1792 とする誤りに注意。
(3) 一般項 5Cr x⁵⁻ʳ(−3y)ʳ。x²y³ の項は r=3 で、係数は 5C3×(−3)³=10×(−27)=**−270**
（指導メモ: 1つの項だけを求める問題は、一般項の r を決めるところが要。「x の指数が n−r」であることを毎回書かせると、r と指数の取り違えが減る。）

**問3**
(1) (10＋1)⁴=10⁴＋4×10³＋6×10²＋4×10＋1=10000＋4000＋600＋40＋1=**14641**
(2) 解答例: 11⁵=(10＋1)⁵=10⁵＋5×10⁴＋10×10³＋10×10²＋5×10＋1 で、係数に 10 という2桁の数が現れる。10×10³ は1つ上の位（10⁴ の位）に1繰り上がり、10×10² も 10³ の位に1繰り上がるので、位ごとの数字が 1, 5, 10, 10, 5, 1 のままにならない（実際は 11⁵=161051）。
（採点の目安: 「係数が10以上になり、繰り上がりが起こる」ことが書けていればよい。n=4 の段は係数がすべて1桁なので繰り上がりが起こらない、と対比できればなおよい。）

**問4** 一般項 5Cr x⁵⁻ʳaʳ。x³ の項は r=2 で、係数は 5C2×a²=10a²。10a²=40 より a²=4。a>0 だから **a=2**
　検算: a=2 のとき (x＋2)⁵ の x³ の係数は、例題1の展開の 40 と一致 ✓
※a=−2 でも a²=4 になるが、問題の「正の定数」という条件で除く。

**問5** 解答例: (a＋b)⁵ は5つのかっこ (a＋b) の積で、a²b³ の項は、5つのかっこのうち3つから b を、残りの2つから a を選んで掛けたときに現れる。b を選ぶ3つのかっこの選び方が 5C3 通りあるので、a²b³ は 5C3 回現れ、係数は 5C3 になる。また、b を選ぶ3つのかっこを決めることは、a を選ぶ残りの2つのかっこを決めることと同じなので、選び方の数は a を選ぶ2つを決める 5C2 通りとも等しい（5C3=5C2=10）。

**問6** 予想: (x＋1)⁴ の一般項は 4Cr x⁴⁻ʳ、(x−1)⁴ の一般項は 4Cr x⁴⁻ʳ(−1)ʳ。r が偶数の項（x⁴、x²、定数項）は両方で同じなので引くと消え、r が奇数の項（x³、x）は符号が逆なので2倍になって残る。
計算: (x⁴＋4x³＋6x²＋4x＋1)−(x⁴−4x³＋6x²−4x＋1)=**8x³＋8x**
　検算: x=2 → 3⁴−1⁴=80、64＋16=80 ✓

**S1**
(1) (1＋x)⁶=6C0＋6C1x＋6C2x²＋6C3x³＋6C4x⁴＋6C5x⁵＋6C6x⁶。x=1 を代入して 6C0＋6C1＋…＋6C6=2⁶=**64**
(2) x=−1 を代入すると左辺は 0⁶=0 だから、6C0−6C1＋6C2−6C3＋6C4−6C5＋6C6=0。つまり、r が偶数の 6Cr の和と奇数の 6Cr の和は等しい。(1) と合わせると、6C0＋6C2＋6C4＋6C6=64÷2=**32**
　検算: 1＋15＋15＋1=32、6＋20＋6=32 ✓
(3) 解答例: 展開した式の各項は、6つのかっこのそれぞれで「1 か x か」を選んで掛けたものを足し合わせてできている。x=1 を代入すると、どの選び方の積も 1 になるので、代入した値は選び方の総数 2⁶=64 に等しくなる。

## L03 多項式の除法——整数の筆算と同じ形・A=BQ＋R

**問1**
(1) x²÷x=x、x(x＋3)=x²＋3x を引いて 4x＋5。4x÷x=4、4(x＋3)=4x＋12 を引いて −7。商 **x＋4**、余り **−7**。
x²＋7x＋5=**(x＋3)(x＋4)−7**
　検算: (x＋3)(x＋4)−7=x²＋7x＋12−7=x²＋7x＋5 ✓
(2) 3x³−2x²＋0x＋4 と書いて割る。3x²(x−1)=3x³−3x² を引いて x²＋0x。x(x−1)=x²−x を引いて x＋4。1×(x−1)=x−1 を引いて 5。商 **3x²＋x＋1**、余り **5**。
3x³−2x²＋4=**(x−1)(3x²＋x＋1)＋5**
　検算: x=2 → 左辺 24−8＋4=20、右辺 1×15＋5=20 ✓
※欠けた x の項に 0x を書かないと、x＋4 の位置がずれて引き算を誤りやすい。
(3) 2x(x²＋2x−1)=2x³＋4x²−2x を引いて −3x²−3x＋1。−3(x²＋2x−1)=−3x²−6x＋3 を引いて 3x−2。商 **2x−3**、余り **3x−2**。
2x³＋x²−5x＋1=**(x²＋2x−1)(2x−3)＋3x−2**
　検算: (x²＋2x−1)(2x−3)=2x³＋x²−8x＋3、これに 3x−2 を足して 2x³＋x²−5x＋1 ✓
(4) x⁴＋0x³＋x²＋0x＋1 と書いて割る。x²(x²−x＋1)=x⁴−x³＋x² を引いて x³＋0x²＋0x。x(x²−x＋1)=x³−x²＋x を引いて x²−x＋1。1×(x²−x＋1) を引いて 0。商 **x²＋x＋1**、余り **0**（割り切れる）。
x⁴＋x²＋1=**(x²−x＋1)(x²＋x＋1)**
　検算: (x²＋1−x)(x²＋1＋x)=(x²＋1)²−x²=x⁴＋2x²＋1−x²=x⁴＋x²＋1 ✓
（指導メモ: L01 例題3(2) で「一工夫が要る」とした x⁴＋x²＋1 の因数分解が、割り算で見つかる。割り切れることは、割る式が因数であることと同じだと確かめさせる。）

**問2** x に着目して降べきの順に整理すると x²＋(2y)x＋3y²。x(x＋y)=x²＋xy を引いて xy＋3y²。y(x＋y)=xy＋y² を引いて 2y²。商 **x＋y**、余り **2y²**。
x²＋2xy＋3y²=(x＋y)(x＋y)＋2y²
理由（例）: x に着目しているので、次数は x についての次数で見る。余り 2y² は x を含まない（x について0次）ので、x について1次の x＋y より次数が低く、割り算はここで終わる。y は数と同じ扱いである。
　検算: (x＋y)²＋2y²=x²＋2xy＋y²＋2y²=x²＋2xy＋3y² ✓

**問3**
(1) 余り R が 0。**A=(x−3)Q**（Q は多項式）
(2) 余り R が定数。**A=(x²＋1)Q＋c**（c は定数。c=0 の場合も含む）
(3) 商 Q は**1次式**、余り R は**1次以下の式**（R=px＋q とおける。p=0 や R=0 の場合もある）
（指導メモ: (3) は次数の見積り。A=BQ＋R の両辺の最高次の項を比べると、Q の次数は A の次数から B の次数を引いたものになる。R は 0 であるか、次数が B の次数より低い。）

**問4** A=BQ＋R より BQ=A−R=(x³＋3x−1)−(2x＋1)=x³＋x−2。これを Q=x−1 で割る。x²(x−1)=x³−x² を引いて x²＋x。x(x−1)=x²−x を引いて 2x−2。2(x−1)=2x−2 を引いて 0。よって **B=x²＋x＋2**
　検算: (x²＋x＋2)(x−1)＋2x＋1=(x³＋x−2)＋2x＋1=x³＋3x−1 ✓。余り 2x＋1 の次数（1次）が B の次数（2次）より低いことも確かめる ✓
※A−R を作らずに A を Q で割ろうとすると、商と余りの役割が入れかわってしまう。「A−R が B と Q の積になる」ことから始める。

**問5**
(1) x³＋0x²＋ax＋b を割る。x(x²＋x＋1)=x³＋x²＋x を引いて −x²＋(a−1)x＋b。−1×(x²＋x＋1)=−x²−x−1 を引いて ax＋(b＋1)。商 **x−1**、余り **ax＋b＋1**
(2) 余りが定数になるのは、x の係数が 0 のとき。**a=0**（このとき余りは b＋1）
(3) 割り切れるのは、余りが 0 のとき。a=0 かつ b＋1=0 より **a=0, b=−1**
　検算: a=0, b=−1 のとき x³−1=(x²＋x＋1)(x−1)（L01 の公式4）で、割り切れる ✓
（指導メモ: 条件が係数の式に翻訳される。「余りが定数」は「a=0」に当たり、割り切れることは「a=0 かつ b=−1」に当たる。(2) では b は何でもよい、という点も確かめさせる。）

**問6** 解答例: 筆算の各段では、残っている式の先頭の項を、割る式の先頭の項で割って商の項を決める。残りの次数が割る式の次数より低くなると、たとえば 3 を x で割った 3/x のように、この割り算の結果が多項式にならず、商に立てる項が作れない。だから、そこで割り算は終わり、残った式が余りになる。
（採点の目安: 「先頭の項どうしの割り算で、多項式の商が立たなくなる」ことが書けていればよい。整数の筆算で、余りが割る数より小さくなると商が立たないことと対応づけられれば、なおよい。）

**S1**
(1) A は3次式、割る式は2次式だから、商 Q は **1次式**。A の x³ の項は、x² と Q の x の項との積から出るので、Q の x の係数は 1。よって **Q=x＋c**（c は定数） とおける。
(2) A=(x²−1)(x＋c)＋2x＋1=x³＋cx²−x−c＋2x＋1=x³＋cx²＋x＋(1−c)。定数項が 4 だから 1−c=4 より c=−3。よって **A=x³−3x²＋x＋4**
(3) x³−3x²＋x＋4 を x²＋0x−1 で割る。x(x²−1)=x³−x を引いて −3x²＋2x＋4。−3(x²−1)=−3x²＋3 を引いて 2x＋1。商は x−3、余りは **2x＋1** で、条件と一致する ✓
（指導メモ: A=BQ＋R を逆向きに使うには、まず Q の形（次数と最高次の係数）を決める必要がある。次数の見積り（問3(3)）が、ここで道具になる。）

## L04 分数式の計算——分数と同じ約分・通分

**問1**
(1) 6x²y=3xy×2x、9xy³=3xy×3y² だから、共通な因数 3xy で割って **2x/(3y²)**
