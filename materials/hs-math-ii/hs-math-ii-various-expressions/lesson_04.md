## 1. 分数式——分数と同じ約束

分数 2/3 は「2 を 3 で割った数」だった。同じように、多項式を多項式で割った形の式を考える。A、B を多項式とし、B が文字を含む（定数でない）とき、A/B の形の式を**分数式**という。A を分子、B を分母という。1/x、(x＋1)/(x²−1)、2x/(x＋3) はどれも分数式である。一方、(x＋1)/2 は分母が定数なので、(1/2)x＋1/2 と書ける多項式であり、分数式とは呼ばない。

分数式では、分母を 0 にする値は考えない。分数で分母が 0 の数を考えないのと同じ約束である。

分数式の計算は、次の基本の性質の上に成り立つ。C を 0 でない多項式とするとき、

A/B=(A×C)/(B×C)、A/B=(A÷C)/(B÷C)

分数の 2/4=1/2 と同じく、分母と分子に同じ式を掛けても、分母と分子に共通な因数で割っても、式の値は変わらない。ただし、C の値が 0 になる x では (A×C)/(B×C) の分母が 0 になるので、この性質はそのような x を除いて使う。約分したあとの式についても、もとの式の分母を 0 にする x は考えない（問6 で確かめる）。約分は2つ目の性質を、通分は1つ目の性質を使う計算である。

:::zatsudan
教科書によっては「多項式」のかわりに「整式」という呼び名が使われている。どちらも、この教材で多項式と呼んでいる同じものを指す。この教材は、学習指導要領解説と同じ「多項式」を使っている（数学Ⅰ「数と式」でも同じ呼び名を使った）。ほかの教科書で「整式の除法」という見出しを見かけたら、L03 で学んだ多項式の割り算のことだと読み替えればよい。
:::

## 2. 約分——因数分解してから、共通な因数で割る

分数式の分母と分子に共通な因数があるとき、それで分母と分子を割って式を簡単にすることを**約分**という（分数の約分と同じ言葉である）。これ以上約分できない分数式は、教科書で**既約分数式**（きやくぶんすうしき）と呼ばれる。約分の手順は、分母と分子をそれぞれ因数分解し、共通な因数で割る、の1つだけである。

**例題1** 次の分数式を約分せよ。
(1) 4a²b/(6ab²)  (2) (x²−4)/(x²＋x−2)

(1) 4a²b=2ab×2a、6ab²=2ab×3b だから、共通な因数 2ab で割って 2a/(3b)。
(2) 分子と分母を因数分解すると (x＋2)(x−2)/((x＋2)(x−1))。共通な因数 x＋2 で割って (x−2)/(x−1)。

検算: (2) に x=3 を入れると、もとの式は 5/10=1/2、約分後も 1/2 で一致する（x=3 は分母を 0 にしない値である）。

約分で起こりやすい誤りの1つは、分子と分母の「項」を消してしまうことだ。たとえば (x＋6)/(x＋2) を「x を消して 6/2=3」とするのは誤りである。x=1 を入れると、もとの式は 7/3 で、3 にはならない。(x＋6)/(x＋2) の分子と分母には共通な因数がないので、これ以上約分できない。

:::guide
**約分できるのは「因数」だけ——2/4=1/2 と同じ理由**

2/4=1/2 とできるのは、2/4=(1×2)/(2×2) と書けて、分子と分母に共通に掛かっている 2 で割れるからだ。分数式の約分も同じで、割ってよいのは分子全体・分母全体に掛かっている式（因数）だけである。(x＋6)/(x＋2) の x は、分子の 6 や分母の 2 に足されているだけで、分子全体に掛かってはいない。数で言えば、(1＋6)/(1＋2)=7/3 を「1 を消して 6/2」とするのと同じ誤りになる。約分の前に分子と分母を因数分解するのは、式を掛け算の形にして、どれが因数なのかを目に見えるようにするためだ。因数分解できない式（x²＋9 など）が分子や分母にあるときは、その式を丸ごと1つのかたまりとして扱い、途中の項だけを消すことはしない。
:::

## 3. 乗法と除法

分数と同じく、乗法は分子どうし・分母どうしを掛け、除法は割る式の分子と分母を入れかえて掛ける。

A/B×C/D=(A×C)/(B×D)、A/B÷C/D=A/B×D/C
（A/B、C/D は、それぞれが1つの分数式である。÷ の後ろの C/D は、全体で1つの割る式として読む。分数で 0 では割れないのと同じく、割る式 C/D の値が 0 になる x、つまり C=0 となる x も考えない。）

掛けてから展開するのではなく、先に分母と分子を因数分解しておき、掛けた形のまま約分する。

**例題2** (x²−1)/(x²＋3x)×(x＋3)/(x＋1) を計算せよ。

(x²−1)/(x²＋3x)×(x＋3)/(x＋1)=(x＋1)(x−1)/(x(x＋3))×(x＋3)/(x＋1)=(x−1)/x

（x＋1 と x＋3 で約分した。）検算: x=2 を入れると、もとの式は (3/10)×(5/3)=1/2、結果は (2−1)/2=1/2 で一致する。

**例題3** (x²−x−6)/(x²−4)÷(x−3)/(x＋2) を計算せよ。

(x²−x−6)/(x²−4)÷(x−3)/(x＋2)=(x−3)(x＋2)/((x＋2)(x−2))×(x＋2)/(x−3)=(x＋2)/(x−2)

検算: x=4 を入れると、もとの式は (6/12)÷(1/6)=3、結果は 6/2=3 で一致する。

## 4. 加法と減法——通分

分母が同じなら分子どうしを足し引きし、分母が違えば、分母をそろえてから（**通分**して）足し引きする。通分に使う共通の分母は、それぞれの分母を因数分解し、現れる因数をすべて掛け合わせた式にする（同じ因数は、1つの分母に現れる回数のうちいちばん多い回数だけ使う。たとえば (x−1)² と (x−1)(x＋1) なら (x−1)²(x＋1)）。

**例題4** 次の計算をせよ。
(1) (2x＋1)/(x²−4)−(x−1)/(x²−4)  (2) 1/(x−1)−1/(x＋1)

(1) 分母が同じなので、分子どうしを引く。引く分子はかっこごと符号を変えて、(2x＋1)−(x−1)=x＋2。

(x＋2)/(x²−4)=(x＋2)/((x＋2)(x−2))=1/(x−2)

足し引きしたあとにも約分できることがある。計算の最後に、もう一度約分できないかを確かめる。

(2) 共通の分母は (x−1)(x＋1)。

1/(x−1)−1/(x＋1)=((x＋1)−(x−1))/((x−1)(x＋1))=2/((x−1)(x＋1))=2/(x²−1)

検算: (1) は x=3 を入れると、もとの式は 7/5−2/5=1、結果は 1/(3−2)=1 で一致する。(2) は x=2 を入れると、もとの式は 1−1/3=2/3、結果も 2/3 で一致する。

**例題5** (x＋3)/(x²−1)−2/(x−1) を計算せよ。

x²−1=(x＋1)(x−1) だから、共通の分母は (x＋1)(x−1)。

(x＋3)/(x²−1)−2/(x−1)=((x＋3)−2(x＋1))/((x＋1)(x−1))=(−x＋1)/((x＋1)(x−1))

分子の −x＋1 は −(x−1) と書けるので、

=−(x−1)/((x＋1)(x−1))=−1/(x＋1)

検算: x=2 を入れると、もとの式は 5/3−2=−1/3、結果も −1/3 で一致する。

:::guide
**x−1 と 1−x——符号を1つ外に出す**

例題5 の分子 −x＋1 は、分母の因数 x−1 と見た目が違う。しかし −x＋1=−(x−1) だから、−1 を外に出せば共通な因数が現れる。一般に 1−x=−(x−1) であり、2つは「符号だけが違う同じかたまり」である。これに気づかないと、約分できる式を約分しないまま答えにしたり、逆に符号を落として (1−x)/(x−1)=1 のように約分してしまったりする（正しくは −1）。気づくコツは、分母・分子の各因数を「x の係数が正になる形」にそろえて書くことだ。1−x を見たら −(x−1) に書き直す、と決めておけば、共通な因数を見落とさない。
:::

:::guide
**どこまで扱うか——分母は2次式程度まで**

学習指導要領解説（平成30年告示）は、分数式の計算について「ここでいう『簡単な場合』とは，分数式の分母の次数が二次程度までのもののことである」と説明している。この教材の例題と練習も、この範囲にそろえた。分母が2次式程度までなら、分母の因数分解は中3・数学Ⅰの公式で済み、通分の見通しも立ちやすい。分母がもっと複雑な式になっても、使う考え方は変わらない。因数分解してから約分・通分し、最後にもう一度約分を確かめる、の3つである。
:::

## 5. 手順の型

1. 分母と分子をそれぞれ因数分解する（1−x の形は −(x−1) に直す）。
2. 乗法・除法なら、掛けた形のまま共通な因数で約分する。加法・減法なら、共通の分母で通分してから分子を計算する。
3. 分子を整理したら、もう一度因数分解して、約分できないかを確かめる。
4. 結果は既約分数式で答える（分母と分子は、因数分解した形でも展開した形でもよい）。約分で分母がなくなったときは、多項式で答える。
5. 検算: 分母も割る式も 0 にしない値を1つ入れて、もとの式と結果の値を比べる。

## 6. 練習

**問1** 次の分数式を約分せよ。
(1) 6x²y/(9xy³)  (2) (x²−5x＋6)/(x²−9)  (3) (x³−1)/(x²−1)

**問2** 次の約分は正しいか。正しくないものは、どこが誤りかを述べて正しく直せ（約分できないものは「これ以上約分できない」と答えよ）。
(1) (x²＋9)/(x＋3)=x＋3
(2) (3x＋6)/(x＋2)=3
(3) (x²−2x)/(x²−4)=−2x/(−4)=x/2

**問3** 次の計算をせよ。
(1) (x²−4)/(x＋3)×(x²＋3x)/(x−2)
(2) (x²＋2x−3)/(x²−x)÷(x²＋3x)/(x＋1)

**問4** 次の計算をせよ。
(1) 3/(x＋2)＋1/(x−2)
(2) 2/(x²−1)＋1/(x＋1)
(3) (x＋5)/(x²＋x−2)−2/(x−1)

**問5** 次の計算をし、結果を既約分数式または多項式で表せ。
(1) (x＋1)/x−x/(x＋1)
(2) x/(x−1)＋1/(1−x)

**問6** 約分の前と後の式を比べる。
(1) (x²−1)/(x−1) と x＋1 の値を、x=0, 2, 3 のそれぞれについて計算して比べよ。
(2) x=1 のとき、2つの式はそれぞれどうなるか。
(3) (1)(2) の結果と §1 の約分の性質から、約分した式 x＋1 がもとの式と同じ値をとるのはどのような x についてか、1文で述べよ。
