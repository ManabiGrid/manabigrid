## 構成方針（内部調査要約 準拠）

- **単一単元・16レッスン・30.0時間**。教科書3種の本単元にあたる時数は 30／31／28.5 時間で、本マップは 30.0時間を採る。理由: (a) 啓林館『数学Ⅱ』（令和4年度授業担当計画）の第1章「式と証明・方程式」の計30時間と同じで、その節の配分（8／8／7／5＋章末2）が本マップの4つのまとまりの時数と一致する。(b) 数学Ⅱは標準単位数4（140単位時間）で5つの内容からなり、均等に分けると1内容あたり約28時間になる。30時間はこれに近い。(c) 啓林館『新編数学Ⅱ』の31時間（課題学習1を含む）と数研出版『数学Ⅱ』の28.5時間（問題・演習問題を含む）の間にある。監修で L16 を1.0時間に縮めて 29.0時間とする代替案を残す（下の代替案）。
- **順序は教科書順**。3資料とも「式の計算（3次の公式→二項定理→割り算→分数式）→恒等式・等式の証明・不等式の証明→複素数→二次方程式の虚数解と解の判別→解と係数の関係→剰余の定理・因数定理→高次方程式→活用」の順である。依存関係もこの順を支える。剰余の定理は恒等式（A=BQ＋R を恒等式として読む・L05）と虚数解（L10）の後、高次方程式は複素数の後、恒等式の未定係数法は多項式の割り算（L03）の後に置く。
- **2つの大区分と4つのまとまり、親直属のまとめ**。啓林館『新編数学Ⅱ』と数研出版『数学Ⅱ』が本単元を「式と証明」「複素数と方程式」の2章に分けていることから、大区分Ⅰ「式と証明」（L01〜L08・16時間）と大区分Ⅱ「複素数と方程式」（L09〜L15・12時間）を先に切り、その中に4つのまとまり（A 多項式の計算 8時間／B 恒等式と証明 8時間／C 複素数と二次方程式 7時間／D 因数定理と高次方程式 5時間）を置く。L16 はどのまとまりにも割り付けない親直属のまとめ（章末相当・2時間）である。解答編・指導ノートの分冊の境界は、まとまりの境界にそろえる（L01-04／L05-08／L09-12／L13-15／L16）。
- **単元の背骨を「式をひとまとまりの対象として見る」にする**。L01 の前提診断で置き換えを確かめ、L03 で A=BQ＋R を「割り算の結果を表す等式」として読み、L05 で恒等式（どんな値でも成り立つ等式）を方程式と対比し、L13 で A=BQ＋R に値を代入して剰余の定理を導き、L16 で「条件を式で言い換える」総合問題に束ねる。練習の配分は「計算：式の見方・条件の言い換え：証明＝4：4：2」を目安にする（仮置き）。計算はおおむね通るが、式の見方と条件の言い換えで落ちやすい、という調査の読みによる。
- **到達目標は「他の単元の計算の土台として使える」に置く**。共通テストでは本単元だけの大問は置かれず（旧課程の令和6年度は第1問の一部〔2〕として出題）、図形と方程式・微分積分・数列の中の計算の土台として現れる（令和6〜8年度の大学入試センターの問題評価・分析委員会報告書と設問別正答率の公表資料で確認）。各レッスンの練習や guide に、後の単元の文脈を一言ずつ混ぜる（L05 の「k がどんな値でも成り立つ」など）。
- **複素数は「数と認める」ことを主題に導入し、境界を宣言する**。数学Ⅰ「二次関数」の教材が本単元へ送った問い「√の中が負になったら？」を L09 の入口に置く。そのうえで「解なし」だった方程式に解を与える→四則が閉じる→虚数には大小（不等号）がない、の順で書く。不等式の証明（L07〜L08）は実数の範囲で行うことを L07 の冒頭で宣言する。複素数平面・複素数の絶対値・偏角は数学Cへの予告1文のみ（L16）。
- **記法**: 用語は「多項式」（「整式」は L04 の雑談枠で「教科書によっては」と一言）／判別式 D=b²−4ac（教科書で呼ばれる名として導入）／虚数単位 i（a＋bi の形）／共役な複素数は語のみで、上線の記号は立てない（本文は「a＋bi と a−bi」と書き下す）／nCr は 5C2 のように半角の文字を並べて書く（数学A「場合の数と確率」の教材と統一）／文字の指数は Unicode 上付き文字（aⁿ⁻ʳbʳ）／相加・相乗平均の関係は「(a＋b)/2≧√(ab)（a>0, b>0）、等号は a=b のとき」／分数式はスラッシュ書きで、分母・分子が多項式なら括弧で範囲を示す／全角 ＋ −・≦ ≧、× は必要なときのみ（数学Ⅰ「数と式」と同じ）。Markdown の表の中に縦棒を含む式（絶対値）は置かない。

- **紙面原則**: 誤答の定量値（正答率等）は指導ノートのみに置き、生徒本文と guide に出さない。数値の引用は資料名＋年度＋母集団つき（課程の違いを併記）。例題・練習の数値は自作（試験・調査・論文の設問設定の転写なし）。学習指導要領解説の例（158÷12 の筆算の並置・複二次方程式 x⁴＋x²−2=0・直方体の箱の容積 350cm³・紙パックの容積 240cm³）は、出典を併記して本文に昇格してよい（数学Ⅰ「数と式」L10 の先例）。雑談枠の話題は、調査で確認した許可リスト（Z1 複素数の歴史〔人名は出さない〕／Z2 いろいろな平均／Z3 二項定理と数学Bの二項分布／Z4 「多項式」と「整式」）の範囲内に限る。
- **タグ付き標準形**: `:::stretch`（各レッスン1個・指導要領内の限定的発展）・`:::guide`（2〜4個・定量値なし）・`:::zatsudan`（任意・許可リストのみ）。`:::plus` は予約枠で本単元の本線では使わない（組立除法・三次方程式の解と係数の関係・1の3乗根・共役な虚数解の性質・多項式の最大公約数は発展モジュール候補）。
