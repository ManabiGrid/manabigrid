## L13〜L15 に共通する注意

- L13〜L14 は、指導事項 ア(オ)「因数定理について理解し，簡単な高次方程式について因数定理などを用いてその解を求めること」にあたる。解説は「多項式 A を多項式 B で割ったときの商を Q，余りを R とすると，A＝BQ＋R（R の次数＜B の次数）という関係式が成り立つ。この関係式に基づき剰余の定理や因数定理を導く」と書き、続けて「因数定理や因数分解の公式を用いて因数分解できるような簡単な高次方程式や，x⁴＋x²−2＝0 のような複二次方程式も取り上げ，解を求めることができるようにする」とする。L13 §1 で A=BQ＋R への代入から剰余の定理を導いたこと、L14 例題4 で複二次方程式の例を本文に置いたことは、この明文による。〔根拠区分: Established〕（高等学校学習指導要領解説 数学編・平成30年告示）
- L15 は、指導事項 イ(ウ)「日常の事象や社会の事象などを数学的に捉え，方程式を問題解決に活用すること」にあたる。解説は例として、縦の長さが高さよりも 2cm 短く、横の長さが高さよりも 3cm 長い直方体の形状で、容積が 350cm³ の箱を作るときの縦・横・高さを求める問題を挙げている。この例を、出典を明記して L15 例題1 に置いた。また、解説の課題学習の例〈いろいろな式〉（長方形の紙から作る飲料用の紙パックの容積を 240cm³ にする問題）を、三次方程式に帰着して解くところまで stretch に置いた。同じ課題学習の例が続けて挙げている、容積の変化や最大値の考察は、数学Ⅱ「微分・積分の考え」との関連づけとされているので、本文では予告の1文にとどめた。〔根拠区分: Established〕（高等学校学習指導要領解説 数学編・平成30年告示）
- 用語の格: 「剰余の定理」「因数定理」「高次方程式」「複二次方程式」は解説本文の語である。**組立除法**は解説全文で0件（対照検索:「因数定理」は6件）で、啓林館『数学Ⅱ』では研究、啓林館『新編数学Ⅱ』では探究の枠、数研出版『数学Ⅱ』では研究の扱いである（令和4年度の授業担当計画・年間指導計画・シラバス）。本文では扱っていない。**三次方程式の解と係数の関係**は、解説では専門教科「理数」の理数数学Ⅱで「発展，拡充させる内容」として挙げられるもので、共通の数学Ⅱの範囲の外である（啓林館『数学Ⅱ』は研究〔発展〕、数研出版は発展、啓林館『新編数学Ⅱ』には項目がない）。本文では扱っていない。「方程式が虚数を解にもてば、その共役な複素数も解である」ことの証明は、数研出版のシラバスで研究の扱いであり、本文では性質として使っていない（L14 例題6 では、係数を決めたあとに因数分解して、ほかの解を確かめる手順をとった）。〔根拠区分: Established〕（高等学校学習指導要領解説 数学編・平成30年告示／啓林館『数学Ⅱ』授業担当計画・『新編数学Ⅱ』年間指導計画・令和4年度／数研出版『数学Ⅱ』シラバス・観点別評価規準例・令和4年度用）
- 記法: 多項式を P(x) と書き、x に α を代入した値を P(α) と書く記法は、L13 §1 で導入した（数研出版のシラバスの規準にも〔P(a)＝0〕の形が現れる）。〔根拠区分: Derived〕
- 定量値の扱い: 高校生を母集団とする、剰余の定理・因数定理・高次方程式・因数の候補探しの誤答率つき調査は、執筆時の調査では見つかっていない。以下の共通テストの数値は、本単元が大問（枝問）として出題された旧課程の年のものと、他単元の中に本単元の技能が現れる新課程の年のものである。〔根拠区分: Established（調査の申告）〕

## L13 剰余の定理と因数定理——A=BQ＋R に代入する

**ねらい**: 剰余の定理を、A=BQ＋R（L03）が恒等式であること（L05）から、代入1行で導く。因数定理は剰余の定理で余りが 0 の場合として位置づけ、因数の候補の探し方を手順の型にする。数研出版『数学Ⅱ』シラバス（令和4年度用）の「剰余の定理を利用して，多項式を1次式で割ったときの余りを求めることができる」「剰余の定理を利用して，多項式を1次式や2次式で割ったときの余りを求めることができる」「〔P(a)＝0〕である a の値の求め方を理解し，高次式を因数分解できる」を、§1〜§5 に対応させた。〔根拠区分: Established〕（高等学校学習指導要領解説 数学編・平成30年告示／数研出版『数学Ⅱ』シラバス・令和4年度用）

**語りの軸**: L03 の本文は「この翻訳は、L13 で剰余の定理を学ぶと、筆算をしなくてもできるようになる」と予告し、L05 の guide は「L13 で A=BQ＋R に値を代入して剰余の定理を導く」と予告していた。L13 はこの2つを受け、§1 で L03 の例題1 の等式をそのまま使い、§3 で2次式で割った余りを L05 の未定係数法（値を代入する方法）として解いた。〔根拠区分: Derived〕

**つまずきと対応**:
- **剰余の定理を代入公式として覚え、条件の言い換えで落ちる**: 大学入試センター 令和6年度 本試験の第1問〔2〕（**旧課程**の『数学Ⅱ・数学B』と『数学Ⅱ』の共通問題）は、整式を2次式で割ったときに余りが定数になる条件を考察させる枝問で、本単元が単独の設問群として出題された直近の例である。問題作成部会の見解（自己評価）によると、余りが定数になる必要条件を導く論理を問う「チ」の正答率は『数学Ⅱ・数学B』（受験者 312,255人）で 52.84% だった。『数学Ⅱ』（受験者 4,499人）では 34.67% だった。関係団体（日本数学教育学会）の評価は、この設問について、余りが 0 であることと割る式の2つの解での値の関係を「拡張でき，深められる教材にもなっている」と述べる。計算の技能は通っても、余りについての条件を式の言葉に言い換える段で落ちる、という読みから、剰余の定理を導出ごと扱い（§1・guide「剰余の定理は『代入公式』ではなく…」）、言い換えの練習（問5）を置いた。設問の設定と数値は転写していない。余りが定数になる条件そのものを扱う問題も、本レッスンには置いていない（L03 で割り算の筆算によって扱った）。〔根拠区分: Derived〕（大学入試センター 令和6年度 問題評価・分析委員会報告書〔問題作成部会の見解・関係団体の評価〕）
- **x＋2 で割った余りを P(2) とする**（符号の取り違え）は、執筆者想定・出典未確認。対応=guide の「割る式を 0 にする値を代入する」と、問5(2)・問6(2)。〔根拠区分: Experimental〕
- **因数の候補の探し方**: 3次方程式で因数を見つけられない、という困難について、定量的な根拠は執筆時の調査で0件だった。〔根拠区分: Established（調査の申告）〕
- 本文は、整数の解の候補が定数項の約数に限られる理由を、x³ の係数が 1 の場合に1行で示した。最高次の係数が 1 でないときの分数の候補（±定数項の約数/最高次の係数の約数）は、例題6 の展開を使った具体例による説明（§5 の guide）にとどめ、一般の証明は示していない。この扱いの深さは監修判断である。〔根拠区分: Experimental〕
- **組立除法**（1段落）: 規範の語になく、教科書3種とも研究または探究の枠で扱う（共通注意）。本文では扱っていない。1次式で割る筆算の係数だけを並べて書く省略記法として、筆算に慣れた生徒に紹介する余地はあるが、本教材の解答編はすべて筆算か剰余の定理で書いている。数研出版のシラバスには、態度の規準として「多項式を1次式で割る計算に，組立除法を積極的に利用する」（研究）がある。〔根拠区分: Established（扱いの実態）〕（数研出版『数学Ⅱ』シラバス・令和4年度用／啓林館『数学Ⅱ』授業担当計画・『新編数学Ⅱ』年間指導計画・令和4年度）
- 問3(2)（x⁷ を x²−1 で割った余り）は、筆算では長い割り算の余りが代入2回で分かることを実感させるために置いた。次数は自作である。〔根拠区分: Experimental〕
- stretch S1（2つの1次式で割った余りから、2次式で割った余りと割られる式を求める）は、割付の段階で「教科書標準の延長」とした候補で、(3) は L03 の stretch（割る式と余りから割られる式を復元する）と同じ型である。〔根拠区分: Experimental〕

## L14 高次方程式——因数定理で次数を下げる・複二次

**ねらい**: 3次・4次の方程式を、因数分解の公式・因数定理・置き換えで1次・2次の方程式に帰着させ、虚数解まで含めて解く。数研出版『数学Ⅱ』シラバス（令和4年度用）の「因数分解や因数定理を利用することにより，高次方程式を解くことができる」「高次方程式の既知の解から，方程式の係数を決定することができる」「高次方程式の虚数解から，方程式の係数を決定することができる」「高次方程式を，1次・2次方程式に帰着して考察することができる」を、§1〜§3 に対応させた。〔根拠区分: Established〕（数研出版『数学Ⅱ』シラバス・令和4年度用）

**語りの軸**: 例題1 の x³＋8=0 は、L01 例題2 の x³＋8=(x＋2)(x²−2x＋4) と、L12 例題1(3) の x²−2x＋4 の複素数の範囲での因数分解を受けて、同じ式を方程式として解き直す構成にした。解の個数（重解を重なった数だけ数える）は、本レッスンで扱う方程式について、1次式と2次式の積に分解できることと、2次方程式が複素数の範囲でいつも解をもつこと（L10）から説明し、一般の n 次方程式についての定理には触れていない。〔根拠区分: Derived〕

**つまずきと対応**:
- 3次方程式の因数の見つけ方・高次方程式の解の書き落としについて、高校生を母集団とする誤答率データは、執筆時の調査で0件だった。〔根拠区分: Established（調査の申告）〕
- **3次式の扱いそのものは、受験層では通っている**: 大学入試センター 令和8年度 本試験『数学Ⅱ，数学B，数学C』（受験者 317,586人）の第3問（微分・積分の考え）について、問題作成部会の見解（自己評価）は、一定の手順に従って極大値・極小値やグラフの概形を問う「ア」〜「キ」の正答率が「いずれも85％を上回っている」と述べる。これは微分・積分の文脈での3次関数の処理であり、本単元の到達度として引くことはできない。3次式の計算は、手順が決まっていれば受験層で定着している、という弱い傍証として、本レッスンの重点を、手順の型（次数を下げる・解の個数を数える・代入で確かめる）に置いた。〔根拠区分: Derived〕（大学入試センター 令和8年度 問題評価・分析委員会報告書〔問題作成部会の見解〕）
- **虚数解の書き落とし**（x³−1=0 の解を x=1 だけとする、など）は、執筆者想定・出典未確認。対応=guide「次数を1つ下げるごとに、解が1つ出る」と問5・問6（解の個数を数える）。〔根拠区分: Experimental〕
- **置き換えの戻し忘れ・x=±1 の片方落とし**（複二次方程式）は、執筆者想定・出典未確認。対応=guide「置き換えたら、最後に必ずもとの文字に戻す」と問3。置き換えは、中3と数学Ⅰ「数と式」L02 の語をそのまま使った。〔根拠区分: Experimental〕
- 例題6・問4(2)（虚数解から係数を決める）では「a, b は実数」の条件を使って、実部と虚部に分けて2つの式を作る（L09 の相等）。この条件を書かずに比べる誤りは、執筆者想定・出典未確認。〔根拠区分: Experimental〕
- stretch S1（x³=8 の虚数解の和・積・2乗の和・3乗の和）は、L11 の解と係数の関係を、x³=8 の2次の因数に当てはめる形にとどめた。三次方程式の解と係数の関係（3つの解の和・積）と、1の3乗根の性質には入っていない。〔根拠区分: Established（扱いの境界）〕（高等学校学習指導要領解説 数学編・平成30年告示）

## L15 方程式の活用——直方体の容積から三次方程式へ

**ねらい**: 事象を方程式で表し、解き、解を事象の条件に照らして選ぶ（吟味する）までを1つの流れとして扱う。例題1 は解説の例（容積 350cm³ の箱）で、出典を本文に明記した。〔根拠区分: Established〕（高等学校学習指導要領解説 数学編・平成30年告示）

**語りの軸**: 「三次方程式を必ず使う」前提にしないことを、本文 §3（表で探す方法と、x が大きいほど容積が大きいという見方との比較）と guide「方程式は、必ず使う道具ではなく、選べる道具」と問3（立式すると1次方程式になる）で示した。方程式のよさは、答えの候補を整数でないものまで含めて全部そろえられること、単調でない場面でも使えること（問2・S1 で答えが2つある）として言葉にした。〔根拠区分: Derived〕

**つまずきと対応**:
- **方程式を使う前提が、方法の比較を消す**: 〔著者名未確認〕（2023）「2次方程式を利用するよさを実感させる授業について——協同的探究学習を用いた中学校数学の授業開発——」全国数学教育学会誌 数学教育学研究29(2)（中学3年生の授業開発・定量データなし）は、2次方程式の利用の導入で、2次方程式を活用することを前提とした問題を出すと、生徒は2次方程式を必ず使うものだと推測し、ほかの方法との比較が生じず、2次方程式を用いるよさが感じ取りにくい、と指摘している。本文 §3 と問4 は、この指摘を3次方程式の場面に翻案したものである。〔根拠区分: Adapted〕
- **立式と解の吟味**: 平成17年度 高等学校教育課程実施状況調査（国立教育政策研究所・数学Ⅰ）で、具体的な場面で問題の解決に必要な二次方程式をつくる問題の通過率は 37.7%（設定通過率65・無解答率29.4%）、問題場面に即して二次方程式の解を吟味する問題は 65.6%（設定通過率65・無解答率21.4%）だった。**現行より前の課程（旧々課程）での調査**であり、実施時期・集計人数は執筆時に確認していない。立式が最も落ちやすいという読みから、例題1 では立式の前に「高さを x とすると、縦は x−2、横は x＋3」と文字の置き方を書き、立式のときに x の範囲（x>2）を書いておく型にした。〔根拠区分: Derived〕（国立教育政策研究所 平成17年度 高等学校教育課程実施状況調査 教科・科目別分析と改善点 数学Ⅰ）
- 中学校段階では、平成15年度 小・中学校教育課程実施状況調査（国立教育政策研究所・中学校第3学年）で、日常生活の問題を解決するための二次方程式を解き、その解の適否を判断する問題の通過率が 66.3%（設定通過率55）だった。**現行より前の課程での調査**である。解の適否の判断（吟味）は中学で経験しているので、L15 では、吟味の対象に虚数解が加わること（長さを表さないので捨てる）を新しい点として扱った。〔根拠区分: Derived〕（国立教育政策研究所 平成15年度 小・中学校教育課程実施状況調査 ペーパーテスト調査集計結果 中学校数学）
