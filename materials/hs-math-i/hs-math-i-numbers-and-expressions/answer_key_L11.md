## L11 単元のまとめ——3つの新しい枠組み

**問1**
(1) x＋2y=M とおくと (M＋3)(M−3)=M²−9。M を元に戻して (x＋2y)²−9=**x²＋4xy＋4y²−9**
　検算: x=1, y=1 → もとの式 (1＋2＋3)(1＋2−3)=6×0=0、展開後 1＋4＋4−9=0 ✓
※M²−9 のまま答えを終えない（借りた名前は返す——L02）。(x＋2y)² の展開で 4xy（真ん中の項）を落とさないこと。
(2) 積が 6x²・−3 になる組から候補を作り、x の項で照合すると、外 2x×1=2x と内 (−3)×3x=−9x の和が −7x で一致する組が見つかる。**(2x−3)(3x＋1)**
　検算: 展開 6x²＋2x−9x−3=6x²−7x−3 ✓
※符号を入れかえた (2x＋3)(3x−1) は x の項が −2x＋9x=＋7x となり合わない——「x の項で照合→展開で検算」の2段で確かめる（L04）。
(3) x に着目して整理: x²＋(4y＋2)x＋(3y²＋4y＋1)。定数部分は 3y²＋4y＋1=(y＋1)(3y＋1)、和は (y＋1)＋(3y＋1)=4y＋2 で x の係数と一致。**(x＋y＋1)(x＋3y＋1)**
　検算: 展開すると x²＋4xy＋3y²＋2x＋4y＋1 で元に戻る ✓（1点代入でも x=1, y=1 → もとの式 15・積 3×5=15 ✓）

**問2**
(1) 12=2²×3 で、分母に 2 と 5 以外の素因数 3 があるから**循環小数**と予想できる。割り算で確かめると 7÷12=0.58333…（小数第3位から 3 が限りなく繰り返される）——予想どおり循環小数 ✓
　検算: 余りを追うと 7→10→4→4→4→…。余り 4 が2回目に現れた瞬間から、商は同じ数字 3 を繰り返す（L05の仕組み）。
(2) (√3＋√2)²=3＋2√6＋2=5＋2√6、(√3−√2)²=3−2√6＋2=5−2√6。差は (5＋2√6)−(5−2√6)=**4√6**
　別ルート（和と差の積）: 与式=((√3＋√2)＋(√3−√2))((√3＋√2)−(√3−√2))=(2√3)(2√2)=4√6 ✓
　検算: 近似値の突き合わせ（L06の型）——(√3＋√2)²=9.898…、(√3−√2)²=0.101…、差は 9.797…。4√6 も 9.797… で重なる ✓
(3) 分子と分母に √6−2 を掛ける。1/(√6＋2)=(√6−2)/((√6＋2)(√6−2))=(√6−2)/(6−4)=**(√6−2)/2**
　検算: 答えに元の分母を掛けて戻す——(√6−2)/2×(√6＋2)=(6−4)/2=1 で元の分子 1 に戻る ✓
※相方は「符号だけ変えた √6−2」。同じ √6＋2 をもう一度掛けると (√6＋2)²=10＋4√6 で根号が残り、失敗する（L07）。

**問3**
(1) ①は 3x−x<11−1 → 2x<10 → x<5。②は −3x−x≦10−2 → −4x≦8 → 両辺を −4 で割って向きが変わり x≧−2。数直線で共通部分をとって **−2≦x<5**（−2 に ●・5 に ○）
　検算: 中 x=0 → ① 1<11 ✓・② 2≦10 ✓／外の右 x=6 → ① 19<17 ✗不成立／外の左 x=−3 → ② 11≦7 ✗不成立／端 x=5 → ①の両辺とも 16（等号なし→含まない○）／端 x=−2 → ②の両辺とも 8（等号つき→含む●）
※−4x≦8 から x≦−2 とするのが典型ミス（負の数で割るときに向きを変えていない）。端の印は、もとの2つの不等式の両方に聞いて決める（L09）。
(2) パンを x 個とすると、おにぎりは (10−x) 個。表に整理してから条件の行を式に写す（L10の型）。

| 数量 | xで表すと |
|---|---|
| パンの代金 | 120x円 |
| おにぎりの代金 | 90(10−x)円 |
| 代金の合計 | 120x＋90(10−x)=30x＋900（円） |
| 条件 | 代金の合計が1100円以下 |

　30x＋900≦1100 → 30x≦200 → x≦20/3。20/3=6.66… で、x は 0 以上 10 以下の整数（個数）だから、これを満たす最大の整数を拾って **6個**。
　検算: 事象に戻して境目の両側で（L10の型）——6個なら 720＋360=1080（円）で1100円以下に収まり、7個なら 840＋270=1110（円）で1100円を超える ✓
※x≦20/3 を「切り上げて7個」とするのが典型ミス。解（数直線上の範囲）と問題の答えは同じではない——文脈の条件（個数は整数）で絞ってから、聞かれた形で答える（L10）。

**S1**
(1) 左辺: x²=((1＋√5)/2)²=(1＋2√5＋5)/4=(6＋2√5)/4=**(3＋√5)/2**。右辺: x＋1=(1＋√5)/2＋1=(1＋√5＋2)/2=**(3＋√5)/2**。左辺=右辺となり、x=(1＋√5)/2 は x²=x＋1 を満たす ✓
　（指導メモ: x²=x＋1 を満たす数はもう1つ (1−√5)/2 があるが、√5>1 よりこれは負の数なので、長さの比である黄金比としては「正の数」の条件で除かれる。）
(2) 2.2²=4.84、2.3²=5.29 で 4.84<5<5.29 だから 2.2<√5<2.3（正の数どうしでは2乗の大小と数の大小の向きが一致する——L05）。各辺に 1 を足して 3.2<1＋√5<3.3、各辺を 2 で割って **1.6<(1＋√5)/2<1.65**。黄金比はおよそ 1.6 である。
　検算: 電卓で √5=2.2360… → (1＋2.2360…)/2=1.6180… で、たしかに 1.6 と 1.65 の間 ✓
(3) 分子と分母に √5−1 を掛ける。2/(1＋√5)=2(√5−1)/((1＋√5)(√5−1))=2(√5−1)/(5−1)=2(√5−1)/4=**(√5−1)/2**
　また (1＋√5)/2−1=(1＋√5−2)/2=**(√5−1)/2**。2つの結果は一致する——つまり、**黄金比の逆数は、黄金比から1を引いた数に等しい**（気づきの例）。
　検算: (√5−1)/2×(1＋√5)=(5−1)/2=2 で元の分子 2 に戻る ✓
　（指導メモ: 相方に 1−√5 を掛けても分母が 1−5=−4 になるだけで、整理すれば同じ (√5−1)/2 に着く。1/x=x−1 という関係は x²=x＋1 の両辺を x で割った形そのもの——(1)とつながっている、と気づく生徒がいたら大いにほめたい。）
