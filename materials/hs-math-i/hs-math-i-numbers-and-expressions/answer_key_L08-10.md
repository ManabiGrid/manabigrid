## L08 不等式とその解——「解く」は高校の新しい技

**問1**
(1) 左辺 2x＋1 の値は、x=3 で 7、x=4 で 9、x=5 で 11。9より大きいのは 11 だけだから、解であるのは **x=5 のみ**。
　検算: 7>9 ✗・9>9 ✗・11>9 ✓
※x=4 を解に入れるのが典型ミス。x=4 では両辺がともに 9 で等しく、9>9 は成り立たない（> に等号は含まれない）。
(2) **○**。解いてみると 2x>8 から x>4 で、x=4 は解の範囲の端点にあたる。x=4 では両辺がともに 9 になって 2x＋1>9 が成り立たない（x=4 自身は解でない）から、含まない印 ○ を置く。

**問2**
(1) 左辺 (−4)×(−3)=12、右辺 6×(−3)=−18。負の数を掛けたので向きが変わり、**12>−18**
　検算: 12 と −18 の大小はたしかに 12 が大きい ✓
(2) 左辺 (−4)÷(−2)=2、右辺 6÷(−2)=−3。負の数で割ったので向きが変わり、**2>−3**
　検算: 2 と −3 の大小はたしかに 2 が大きい ✓
※向きを変えずに 12<−18 と書くのが典型ミス。両辺の値そのものを見れば 12<−18 はあり得ない——書いたあとに大小を目で確かめれば、自分で気づける。

**問3**
(1) 5x−3<2x＋9 → 3x<12 → **x<4**
　検算: x=0（中）→ −3<9 ✓成立／x=5（外）→ 22<19 ✗不成立／端点 x=4 → 両辺とも 17 ✓
(2) 2x＋7≦4x−1 → −2x≦−8 → 両辺を −2 で割って向きが変わり **x≧4**
　（別ルート: 7＋1≦4x−2x → 8≦2x → 4≦x でも同じ）
　検算: x=5（中）→ 17≦19 ✓成立／x=0（外）→ 7≦−1 ✗不成立／端点 x=4 → 両辺とも 15（等号成立・x=4 も解に入る）✓
※(2)で −2x≦−8 から x≦4 とするのが典型ミス（負の数で割るときに向きを変えていない）。

**問4** 4−3x>x＋16 → −4x>12 → 両辺を −4 で割って向きが変わり **x<−3**
検算: x=−4（中）→ 左辺 16・右辺 12 で 16>12 ✓成立／x=0（外）→ 4>16 ✗不成立
※−4x>12 から x>−3 とするのが典型ミス。端点 x=−3 で両辺とも 13 になることまで見れば、境界の位置も確認できる。

**問5** 2(x−3)≧5(x＋3) → 2x−6≧5x＋15 → −3x≧21 → 両辺を −3 で割って向きが変わり **x≦−7**
検算: x=−8（中）→ −22≧−25 ✓成立／x=0（外）→ −6≧15 ✗不成立／端点 x=−7 → 両辺とも −20（等号成立）✓
※右辺の展開を 5x＋3 とする（5 を 3 に配りきらない）ミスと、−3x≧21 から x≧−7 とするミスの2か所が要注意。

**S1**（作例——答えは1通りではない。以下は条件を満たす例）
(1) 例: 3x＋1≧−5。解くと 3x≧−6 → **x≧−2** ✓
　検算: x=0（中）→ 1≧−5 ✓／x=−3（外）→ −8≧−5 ✗／端点 x=−2 → 両辺とも −5 ✓
(2) 例: −2x≦4。両辺を −2 で割って向きが変わり **x≧−2** ✓
　検算: x=0（中）→ 0≦4 ✓／x=−3（外）→ 6≦4 ✗／端点 x=−2 → 両辺とも 4 ✓
（指導メモ: 「x≧−2 に性質①〜④の操作を逆向きに施す」と考えれば、条件に合う不等式はいくらでも作れる。解の集まりが同じ不等式どうしは、性質①〜④の操作でつながっている——この見方は、L09 で複数の不等式を扱うときの土台になる。）

## L09 連立不等式——数直線で共通部分をとる

**問1** ①: 2x−x<2＋1 → x<3。②: 3x−x>−1−5 → 2x>−6 → x>−3。数直線で重ねて、共通部分は **−3<x<3**
検算: x=0（中）→ ① −1<2 ✓・② 5>−1 ✓／x=4（外右）→ ① 7<6 ✗／x=−4（外左）→ ② −7>−5 ✗／端点 x=3 → ①で両辺とも 5（相等・<なので含まない）✓／端点 x=−3 → ②で両辺とも −4（相等・>なので含まない）✓
※「x<3、x>−3」と2本並べたままで終えず、1つの範囲 −3<x<3 にまとめて書く。並べただけでは「両方を満たす範囲」を答えたことにならない。

**問2** ①: 4x−x≦10−1 → 3x≦9 → x≦3。②: −x−3x<10−2 → −4x<8 → 両辺を −4 で割って向きが変わり x>−2。共通部分は **−2<x≦3**
検算: x=0（中）→ ① 1≦10 ✓・② 2<10 ✓／x=4（外右）→ ① 17≦14 ✗／x=−3（外左）→ ② 5<1 ✗／端点 x=3 → ①で両辺とも 13（等号成立）かつ ② −1<19 ✓で両方成立→解に入る（●）／端点 x=−2 → ②で両辺とも 4（相等・<なので含まない＝○）✓
※②で向きを変えずに x<−2 とすると、共通部分が x<−2 になってしまう典型ミス。検算の中の点 x=0 で ② 2<10 が成立することと食い違うので、検算で捕まる。

**問3**
(1) ①: 3x−x≧4＋2 → 2x≧6 → x≧3。②: 5x−2x>8＋1 → 3x>9 → x>3。2つの範囲の端は同じ 3 だが、●（①）と ○（②）が同じ位置に重なっている。共通部分に残るのは両方に入っている方だから、解は **x>3**
検算: x=4（中）→ ① 10≧8 ✓・② 19>16 ✓／x=2（外）→ ① 4≧6 ✗／端点 x=3 → ②で両辺とも 14（相等）✓
(2) **解といえない**。x=3 を代入すると、①は両辺とも 7 になり等号成立で成り立つが、②は両辺とも 14 になり 14>14 は成り立たない。連立不等式の解は組にしたどの不等式も満たす値のことなので、②で落ちる x=3 は解に入らない。
※①だけを見て x≧3（3 を含む）と答えるのが典型ミス。● と ○ が同じ位置に重なったら、共通部分は ○ の側。

**問4** ①: x−3x<−1−9 → −2x<−10 → 両辺を −2 で割って向きが変わり x>5。②: 4x−2x≦3＋3 → 2x≦6 → x≦3。数直線にかくと、①の範囲は 5 から右・②の範囲は 3 から左で、重なりがない。**解はない**
検算: すき間の x=4 → ① 13<11 ✗・② 13≦11 ✗（両方落ちる）／x=6 → ① 15<17 ✓だが ② 21≦15 ✗／x=0 → ② −3≦3 ✓だが ① 9<−1 ✗——どの値も少なくとも一方で不成立 ✓
※x>5 と x≦3 を「3≦x≦5」「5<x≦3」のようにひとつなぎにまとめて書くのが典型ミス。a<x≦b 型の書き方は、重なりがあるときにだけ使える。まとめる前に、まず数直線。

**S1** ①: 2x−x≦5−3 → x≦2。②: 3x−x≧4 → 2x≧4 → x≧2。共通部分は「2以下」かつ「2以上」だから、x=2 のただ1つ。解は **x=2**
数直線に表すと、範囲（のびる線）ではなく、2 の位置の ● 1点だけが残る見た目になる。
検算: x=2 → ① 両辺とも 7（等号成立）✓・② 左辺 2・右辺 2（等号成立）✓／x=1 → ② −1≧1 ✗／x=3 → ① 9≦8 ✗
（指導メモ: 端の値の等号の有無が結果を分ける好例。もし①②の等号を外して 2x＋3<x＋5・3x−4>x にすると、x<2 かつ x>2 となり解はなくなる。連立不等式の解は「のびる範囲」とは限らず、1点につぶれることも、なくなることもある——どの場合も数直線にかけば同じ型で読める。L10 では、文章から立てた連立不等式の解を文脈に戻して解釈する段階が加わる。）

## L10 一次不等式の活用——図・表から立式する

**問1**
(1) （ア）**80x**　（イ）**80x＋200**
(2) 「代金の合計が1000円以下」だから **80x＋200≦1000**
(3) 200 を移項して 80x≦800、両辺を正の 80 で割って **x≦10**。個数は自然数だから、みかんは最大 **10個** 買える。10個のときの合計は 80×10＋200=**1000**（円）で、ちょうど1000円は「1000円以下」に合う。
　検算: 10個 → 1000≦1000 ✓収まる／11個 → 80×11＋200=1080>1000 ✗あふれる
※「9個」とするのが典型ミス（「以下」の等号を落として x<10 と立式している）。境目の値を文章に当てて確かめる——ちょうど1000円は「1000円以下にしたい」に合うから、等号は入る。

**問2**
(1) 近所の店: **300x円**　直売所: **240x＋360（円）**
(2) **240x＋360<300x**。理由の例: ちょうど同額のときは「安くなる」とは言えないから、等号は入れない。
(3) 移項して 360<300x−240x、整理して 360<60x、両辺を正の 60 で割って 6<x、すなわち **x>6**。直売所のほうが安くなるのは **6kgより多く買うとき**。
　検算: x=8（範囲の中）→ 直売所 240×8＋360=2280（円）・店 300×8=2400（円）で直売所が安い ✓成立／x=4（範囲の外）→ 直売所 1320円・店 1200円で直売所のほうが高い ✗不成立／端点 x=6 → どちらも1800円で同額（「安くなる」に入らない——(2)で等号を入れなかった理由がここで効く）
※重さはとびとびでない量なので、「7kg以上」のように自然数へ絞るのは誤り。範囲 x>6 がそのまま答えになる（本文§4 guide参照）。

**問3**
(1) 票の総数が60票だから **60−x票**
(2) 2人がともにx票以上取るには少なくとも2x票要る。それが残りの票より多ければ作れないから **2x>60−x**
(3) −x を左辺に移項して 3x>60、両辺を正の 3 で割って x>20。票数は自然数だから、必要な最低票数は **21票**。
　検算: 21票 → 自分以外は39票。2人が21票以上取るには42票要るが、39票しかないから作れない ✓必ず当選／20票 → 自分以外の40票を20票＋20票で2人に配ると、自分を含む3人が20票で並び、2つの枠をくじ引きで争う ✗「必ず当選」とは言えない
※「20票」とするのが典型ミス（x≧20 と立式、または x>20 の最小自然数の拾い違い）。境目の20票では上の内訳が実際に作れてしまうことまで確かめる。

**S1** ガーベラは (12−x)本。
条件A: 150x>100(12−x) → 150x>1200−100x → 250x>1200 → **x>24/5**（24/5=4.8）
条件B: 150x＋100(12−x)≦1700 → 50x＋1200≦1700 → 50x≦500 → **x≦10**
2つの解を数直線にかいて共通部分をとると 24/5<x≦10。本数は自然数だから、バラの本数として考えられるのは **5本・6本・7本・8本・9本・10本**（5本以上10本以下の6通り）。
　検算: x=5 → バラ 750円>ガーベラ 700円 ✓A成立・合計 1450≦1700 ✓B成立／x=4（Aの外）→ 600>800 ✗A不成立／x=10 → 1500>200 ✓A成立・合計 1700≦1700 ✓B成立（ちょうど1700円は「1700円以下」に合う）／x=11（Bの外）→ 合計 150×11＋100×1=1750>1700 ✗B不成立
（指導メモ: 端点の効き方が2条件で対照的——Aの境目 24/5 は本数としてありえない値なので端点の議論が不要になり、Bの境目 x=10 は等号でちょうど入る。L09の共通部分とL10の解の解釈の合流点として使える。）
