## L01 多項式の整理と展開——1つの文字に着目する

**問1**
(1) 5x−7＋2x²−9x＋3=2x²＋(5−9)x＋(−7＋3)=**2x²−4x−4**
　検算: x=2 → もとの式 10−7＋8−18＋3=−4、整理後 8−8−4=−4 ✓
(2) 4−x²＋6x＋3x²−2x−9=(−1＋3)x²＋(6−2)x＋(4−9)=**2x²＋4x−5**
　検算: x=1 → もとの式 4−1＋6＋3−2−9=1、整理後 2＋4−5=1 ✓

**問2** a に着目すると、a² の項は 2a²、a の項は ab−5a=(b−5)a、残りは −3b²＋4b−1。
**2a²＋(b−5)a−3b²＋4b−1**（a についての**次数は2**、**定数項は −3b²＋4b−1**）
検算: a=1, b=1 → もとの式 2＋1−3−5＋4−1=−2、整理後 2＋(1−5)×1−3＋4−1=−2 ✓
※−5a の書き落とし（(b)a とする誤り）に注意。a の項は「a が1個だけの項ぜんぶ」を集める。

**問3**
(1) (x＋6)²=**x²＋12x＋36**
　検算: x=1 → 7²=49、1＋12＋36=49 ✓
(2) (2x−5)²=(2x)²−2×2x×5＋5²=**4x²−20x＋25**
　検算: x=1 → (−3)²=9、4−20＋25=9 ✓
(3) (3a−2b)(3a＋2b)=(3a)²−(2b)²=**9a²−4b²**
　検算: a=1, b=1 → 1×5=5、9−4=5 ✓
(4) (x−4)(x＋9)=x²＋(−4＋9)x＋(−4)×9=**x²＋5x−36**
　検算: x=1 → (−3)×10=−30、1＋5−36=−30 ✓

**問4** (2x−1)²=4x²−4x＋1、(x＋3)(x−3)=x²−9。差をとって
4x²−4x＋1−(x²−9)=4x²−4x＋1−x²＋9=**3x²−4x＋10**
※−(x²−9) の符号処理に注意。−9 のまま引いて 3x²−4x−8 とする誤りに注意（正しくは −(−9)=＋9）。
検算: x=2 → もとの式 3²−5×(−1)=9＋5=14、整理後 12−8＋10=14 ✓

**S1**
(1) x に着目: **x²−(2y＋4)x＋3y²＋5y−6**（x についての**次数は2**、**定数項は 3y²＋5y−6**）
(2) y に着目: **3y²−(2x−5)y＋x²−4x−6**（y についての**次数は2**、**定数項は x²−4x−6**）
(3) x=2, y=1 のとき、もとの式は 4−4＋3−8＋5−6=**−6**。
　(1)の形: 4−6×2＋(3＋5−6)=4−12＋2=−6 ✓
　(2)の形: 3−(−1)×1＋(4−8−6)=3＋1−10=−6 ✓
（指導メモ: 着目する文字を替えても式そのものは変わらない——値が一致するのはそのためである。「整理」は式を別の式に変えるのではなく、同じ式の並べ替えであることを確認させる。）

## L02 展開の新公式——(ax＋b)(cx＋d)と置き換え

**問1** 新公式 (ax＋b)(cx＋d) = acx²＋(ad＋bc)x＋bd をそのまま使う。

(1) (2x＋3)(x＋4) = 2x²＋(2×4＋3×1)x＋12 = **2x²＋11x＋12**
検算: x=1 → (2＋3)(1＋4)=25・2＋11＋12=25 ✓

(2) (3x＋1)(2x＋5) = 6x²＋(3×5＋1×2)x＋5 = **6x²＋17x＋5**
検算: x=1 → (3＋1)(2＋5)=28・6＋17＋5=28 ✓

(3) (4x＋3)(2x＋1) = 8x²＋(4×1＋3×2)x＋3 = **8x²＋10x＋3**
検算: x=1 → (4＋3)(2＋1)=21・8＋10＋3=21 ✓

**問2** b・d は符号ごと読む。

(1) (4x−3)(2x＋1) = 8x²＋(4×1＋(−3)×2)x−3 = **8x²−2x−3**
検算（問題の指示）: x=1 → (4−3)(2＋1)=3・8−2−3=3 一致 ✓

(2) (3x−4)(2x−3) = 6x²＋(3×(−3)＋(−4)×2)x＋12 = **6x²−17x＋12**
検算（問題の指示）: x=1 → (3−4)(2−3)=(−1)×(−1)=1・6−17＋12=1 一致 ✓
※定数項は (−4)×(−3)=＋12。−12 とするのは符号ミス。x=0 の代入なら定数項だけを取り出して確かめられる。

**問3** 共通のまとまりを M とおく。

(1) x＋y=M とおくと (M＋5)(M−5)=M²−25。戻して (x＋y)²−25 = **x²＋2xy＋y²−25**
検算: x=1, y=2 → (1＋2＋5)(1＋2−5)=8×(−2)=−16・1＋4＋4−25=−16 ✓

(2) a−b=M とおくと (M＋2)(M＋6)=M²＋8M＋12。戻して (a−b)²＋8(a−b)＋12 = **a²−2ab＋b²＋8a−8b＋12**
検算: a=3, b=1 → (3−1＋2)(3−1＋6)=4×8=32・9−6＋1＋24−8＋12=32 ✓
※答えの式に M を残したままにしない（M は仮の名前）。

**問4** 2a＋b=M とおくと (M−1)(M＋4)=M²＋3M−4。戻して (2a＋b)²＋3(2a＋b)−4 = **4a²＋4ab＋b²＋6a＋3b−4**
（(2a＋b)² は (a＋b)² の公式で a のところを 2a と読んで (2a)²＋2×2a×b＋b²=4a²＋4ab＋b²）
検算: a=1, b=2 → (2＋2−1)(2＋2＋4)=3×8=24・4＋8＋4＋6＋6−4=24 ✓

**S1** a＋b=M とおくと (M＋c)²=M²＋2Mc＋c²。戻して (a＋b)²＋2(a＋b)c＋c² = a²＋2ab＋b²＋2ac＋2bc＋c²。2乗の項→積の項の順に整理して **a²＋b²＋c²＋2ab＋2bc＋2ca**
検算: a=1, b=2, c=3 → (1＋2＋3)²=36・1＋4＋9＋4＋12＋6=36 ✓
（指導メモ: 積の項 2ab＋2bc＋2ca の並びは a→b→c→a の循環順。どの2文字の組も1回ずつ現れることを確認させると、項の落としに気づきやすい。）

## L03 因数分解①——「積の形に表す」と共通因数

**問1**
(1) 解答例:「1つの多項式を、いくつかの式の積の形に表すこと」。「積の形に表す」という趣旨が入っていればよい（積の形＝全体が掛け算だけでつながった形。式の一部を抜き出すことでも、値を計算することでもない）。
(2) 因数分解になっているのは **ア・エ**。
　イ: 等式としては正しいが、右辺が「積から3を引いた形」で、全体が積の形になっていない。
　ウ: 展開すると (x−5)²=x²−10x＋25 となり、左辺の x²−25 に戻らない（等式そのものが誤り）。
　検算: x(x＋4)=x²＋4x ✓／x(x＋4)＋3=x²＋4x＋3 ✓（イは等式は成立）／(x＋5)(x−5)=x²−25 ✓

**問2**
(1) 6x²＋9x=**3x(2x＋3)**
　検算: 展開 3x(2x＋3)=6x²＋9x ✓
　※3(2x²＋3x) や x(6x＋9) で止めるのは不完全（かっこの中に共通因数が残る）。
(2) 4a²b−6ab²=**2ab(2a−3b)**
　検算: 展開 2ab(2a−3b)=4a²b−6ab² ✓

**問3** −x²＋10x−25=−(x²−10x＋25)=**−(x−5)²**
検算: 展開 −(x−5)²=−(x²−10x＋25)=−x²＋10x−25 ✓
※(x−5)² と答えるのは誤り（展開すると x²−10x＋25 となり、先頭が ＋x² で元に戻らない）。先頭が−の式は、−1のくくり出しを最初の独立ステップにする。

**問4**
(1) x²＋8x＋16=**(x＋4)²**
　検算: 展開 (x＋4)²=x²＋8x＋16 ✓
(2) x²−49=**(x＋7)(x−7)**
　検算: 展開 (x＋7)(x−7)=x²−49 ✓
　※(x−7)² は誤り（展開すると x²−14x＋49。「2乗の差」と「差の2乗」は別の式）。

**問5**
(1) 積が14・和が9になる2数は 2 と 7。x²＋9x＋14=**(x＋2)(x＋7)**
　検算: 展開 (x＋2)(x＋7)=x²＋9x＋14 ✓
(2) 積が−15・和が−2になる2数は 3 と −5。x²−2x−15=**(x＋3)(x−5)**
　検算: 展開 (x＋3)(x−5)=x²−2x−15 ✓

**S1**
(1) 検査4（展開の検算）で見つかる誤り。(x−6)²=x²−12x＋36 となり、x²−36 に戻らない（等式そのものが誤り）。正しくは x²−36=**(x＋6)(x−6)**。
　検算: 展開 (x＋6)(x−6)=x²−36 ✓
(2) 検査3（積の形の仕上がり）で見つかる誤り。3(x²−4x) は等式としては正しい（展開すると 3x²−12x に戻る）が、かっこの中に共通因数 x が残っていて、くくり出しが完了していない。正しくは 3x²−12x=**3x(x−4)**。
　検算: 展開 3x(x−4)=3x²−12x ✓
（指導メモ: (1)は「等式が誤り」、(2)は「等式は正しいが仕上がっていない」——2節・6節で分けた2つの検査が1問ずつ対応する設計。）

## L04 因数分解②——acx²＋(ad＋bc)x＋bdの型と1文字着目

**問1**
(1) 2x²＋7x＋3=**(x＋3)(2x＋1)**
　検算: 展開 2x²＋x＋6x＋3=2x²＋7x＋3 ✓
(2) 3x²−10x＋8=**(x−2)(3x−4)**
　検算: 展開 3x²−4x−6x＋8=3x²−10x＋8 ✓
(3) 4x²＋4x−3=**(2x−1)(2x＋3)**
　検算: 展開 4x²＋6x−2x−3=4x²＋4x−3 ✓

**問2**
(1) 6x²＋x−12=**(2x＋3)(3x−4)**
　検算: 展開 6x²−8x＋9x−12=6x²＋x−12 ✓
(2) 8x²−20x＋12=4(2x²−5x＋3)=**4(x−1)(2x−3)**
　検算: 展開 (x−1)(2x−3)=2x²−5x＋3、4倍して 8x²−20x＋12 ✓
　※共通因数4を先にくくり出す（手順の型の1）。8=2×4 などの探索から入ると係数が大きく、組を見つけにくい。

**問3**
(1) x²＋7xy＋12y²=**(x＋3y)(x＋4y)**（xに着目。積が12y²・和が7yの組は 3y と 4y）
　検算: 展開 x²＋4xy＋3xy＋12y²=x²＋7xy＋12y² ✓
(2) 2x²−5xy＋3y²=**(x−y)(2x−3y)**
　検算: 展開 2x²−3xy−2xy＋3y²=2x²−5xy＋3y² ✓

**問4** xに着目して降べきの順に整理する: x²＋(3y−1)x＋(2y²−3y−2)。
xを含まない部分は 2y²−3y−2=(y−2)(2y＋1)、和は (y−2)＋(2y＋1)=3y−1 でxの係数と一致する。
x²＋3xy＋2y²−x−3y−2=**(x＋y−2)(x＋2y＋1)**
（着目の一言の例:「xについて2次なので、xに着目して整理した」。yに着目して整理しても同じ答えに到達できる）
検算: 展開 (x＋y−2)(x＋2y＋1)=x²＋3xy＋2y²−x−3y−2 ✓

**問5**
(1) M=x＋2 とおくと M²−5M＋6=(M−2)(M−3)。もとに戻して (x＋2−2)(x＋2−3)=**x(x−1)**
　検算: x(x−1)=x²−x。もとの式を直接展開しても (x²＋4x＋4)−(5x＋10)＋6=x²−x ✓
　※括弧の中まで整理して x(x−1) まで進める。(x＋2−2)(x＋2−3) のままでは整理が完了していない。
(2) M=x−y とおくと M²＋2M−15=(M＋5)(M−3)。もとに戻して **(x−y＋5)(x−y−3)**
　検算: 展開 (x−y＋5)(x−y−3)=x²−2xy＋y²＋2x−2y−15。もとの式の直接展開 (x−y)²＋2(x−y)−15=x²−2xy＋y²＋2x−2y−15 と一致 ✓
　※Mのまま (M＋5)(M−3) と答えるのは誤り。最後に必ずもとの文字に戻す。

**S1** yの次数が1で低いから、yに着目して整理する:
x²＋xy＋2y−4=(x＋2)y＋(x²−4)=(x＋2)y＋(x＋2)(x−2)=**(x＋2)(x＋y−2)**
（説明の例:「yについては1次式なので、yに着目すると共通因数 x＋2 が見えるから」。xに着目した x²＋(y)x＋(2y−4) からでも解けるが、組の探索が要る分だけ遠回りになる）
検算: 展開 (x＋2)(x＋y−2)=x²＋xy−2x＋2x＋2y−4=x²＋xy＋2y−4 ✓
