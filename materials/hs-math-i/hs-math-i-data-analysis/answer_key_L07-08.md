## L07 仮説検定の考え方①——「偶然で説明できるか」を実験で測る

**問1**
(1) 20枚以上: 20枚 5回・21枚 1回・22枚 1回・23枚 1回で **8回**。相対度数 8/200=**0.04**。
(2) 16枚以上: 25＋18＋16＋9＋5＋1＋1＋1=**76回**。相対度数 76/200=**0.38**。
検算: 結果表200個を Python で数え直して 8・76 に一致。15枚以下は 1＋1＋2＋1＋11＋7＋18＋27＋22＋34=124 で、124＋76=200 ✓。
※(1)で「20枚ちょうど」の5回だけを数えるのが想定誤答。「以上」は 20, 21, 22, 23 をすべて含む。
※相対度数を 8/30 のように「30回投げ」で割らない。割るのは実験の回数 200。

**問2** 22枚以上は 22枚 1回・23枚 1回で **2回**。相対度数 2/200=**0.01**。主張A（24人・相対度数 0）に近い——偶然だけで22人以上が伸びることは200回中2回しかなく、非常に起こりにくい。主張B（18人・0.165）のように「偶然でもふつうに起こる」水準ではない。
検算: Python で 22 以上を数えて 2 ✓。
※「主張Aは0回だったが今回は2回あるので主張B寄り」は想定誤答。0.01 は「100回に1回」で、0.165（6回に1回）とは桁が違う。大小は 0 との比較ではなく、「ふつうに起こる」水準との比較で読む。

**問3** 7枚以下は 6枚 1回・7枚 1回で **2回**。相対度数 2/200=**0.01**。
検算: Python で 7 以下を数えて 2 ✓。
（指導メモ: 「伸びた人が少なすぎる」型の主張は、分布の左のすそを見る。「7人以下」で数える理由は問4の「以上」と同じで、極端すぎる側をひとまとめに見るため。判断の言い方は L08 で扱うので、ここでは相対度数まででよい。）
※「7枚ちょうど」の1回だけを数えるのが想定誤答。

**問4**（解答例）問いは「24人という結果は偶然にしては多すぎるか」であり、25人・26人ならなおさら多すぎるので、「24人以上のどれかになる」起こりやすさを見るのが問いに合っている。また「24枚ちょうど」の相対度数は「ちょうど24枚になる」起こりやすさを表す数であり、問いの「多すぎるか」には答えていない。
（採点の目安: ①「以上」が問いの意味に合うこと ②「ちょうど」の相対度数は「ちょうどその枚数になる」起こりやすさを表し、問いの「多すぎるか」には答えていないこと、の2点。どちらか一方でも理由になっていれば可。）

**問5**（解答例）行きすぎ: 0回になったのは200回という回数の中でのことで、もっとくり返せば24枚以上が出る可能性はある。「絶対にない」ではなく「200回では一度も起こらないほど非常に起こりにくい」までしか言えない。
1000回の予想（例）: 24枚以上が数回出るかもしれないが、相対度数はやはり 0 に近い小さな値になると予想できる。
（採点の目安: 前半は「実験回数の中での0」と「絶対にない」の区別。後半は「回数は増えるかもしれないが相対度数は小さいまま」の向きが合っていれば可。具体的な回数を当てる必要はない。）

**S1** 各枚数×回数の合計は 6×1＋7×1＋8×2＋9×1＋10×11＋11×7＋12×18＋13×27＋14×22＋15×34＋16×25＋17×18＋18×16＋19×9＋20×5＋21×1＋22×1＋23×1=2941。m=2941/200=**14.705**（枚）。半分の15枚にきわめて近い。「ちょうど15枚」は **34回**で、相対度数 34/200=**0.17**。
気づくこと（例）: 偶然だけの世界でも、平均値はほぼ半分（15枚）になるが、1回1回の実験でちょうど半分になるのは6回に1回ほどしかなく、多くの回は半分から少しずれる。「半々」とは、平均してみれば半分になるという意味である。
検算: Python の statistics.mean で 14.705 に一致。200個のうち 15 の個数を count で数えて 34 ✓。
※合計を 18（枚数の種類の数）や 30 で割るのが想定誤答。割るのは回数の合計 200。

## L08 仮説検定の考え方②——判断の基準と、その限界

**問1** 21枚以上は 21枚・22枚・23枚が1回ずつで **3回**。p=3/200=**0.015**。
- 基準(a): 0.015 は 0.05 以下 → 達する。
- 基準(b): 21 は m＋2s≒20.36 より大きい → 帯の外 → 達する。
結論（例）: 30人中21人が伸びたという結果は偶然だけでは説明しにくく（p=0.015・平均から 2s より外）、練習法Tに効果があるという主張を支持する根拠が得られた。
検算: Python で 21 以上を数えて 3 ✓。m=14.705、s≒2.828、m＋2s≒20.361 で 21>20.361 ✓。
※「効果があると証明された」「効果があると分かった」と書くのが想定誤答。結論は「偶然だけでは説明しにくい」「支持する根拠が得られた」までで止める。

**問2** 20枚以上は 5＋1＋1＋1=**8回**。p=8/200=**0.04**。
- 基準(a): 0.04 は 0.05 以下 → 達する（偶然だけでは説明しにくい）。
- 基準(b): 20 は m＋2s≒20.36 より小さい → 帯の中 → 達しない（判断を保留する）。
2つの基準で判断が割れる。結論の書き方（例）: どちらの基準で判断したかを明記して書く——「この200回の実験の表では、相対度数 0.04 を基準 0.05 と比べれば偶然だけでは説明しにくいが、平均から 2s の帯の中には入っており、基準によって判断が分かれる境目の結果である」。結果を見てから都合のよい基準に乗り換えないことが大切で、基準は前もって決めておく。（指導メモ: L07 で見たとおり p=0.04 は200回の実験での見積もりである。L07 §3 の結果表を実験の順に分けると、20枚以上は最初の100回で6回（6/100=0.06）、後半の100回で2回（2/100=0.02）で、0.05 の両側に分かれる。境目の近くの判断は、コインの実験をくり返す回数でも動く。調べる人数を増やす話（§4）とは別である。）
検算: Python で 20 以上を数えて 8 ✓。20<20.361 ✓。
※「基準(a)で達したから、(b)は無視してよい」は想定誤答。割れたこと自体が情報で、判定した基準を添えて報告する。
※「20枚ちょうど」の5回で p=0.025 とするのが想定誤答。「以上」で数える。

**問3** 9枚以上は 9枚 4回・10枚 0回で **4回**。p=4/200=**0.02**。
- 基準(a): 0.02 は 0.05 以下 → 達する。
- 基準(b): 9 は m＋2s≒8.48 より大きい → 帯の外 → 達する。
結論（例）: 10問中9問正解は当てずっぽうでは説明しにくく、Eさんは当てずっぽうではないという主張を支持する根拠が得られた。
気をつけること（例）: 8問（p=0.085・保留）と9問（p=0.02）のように、基準の境目の近くでは1問の違いで判断が変わるので、境目に近い結果ほど「問題数を増やして調べ直す」など慎重に扱う。
検算: 10回投げの結果表200個を Python で数えて 9 以上は 4、8 以上は 17 ✓。m=5.12、s≒1.681、m＋2s≒8.482 で 9>8.482、8<8.482 ✓。
※10回投げの表ではなく30回投げの表で「9枚以上」を数えるのが想定誤答（問題数が10問なので、コイン10回投げの表を使う）。

**問4** 60枚以上は 60〜64 の階級の 4回（65以上は0回）で **4回**。p=4/200=**0.02**。
- 基準(a): 0.02 は 0.05 以下 → 達する。
- 基準(b): 60 は m＋2s≒59.25 より大きい → 帯の外 → 達する。
結論（例）: 100問中60問正解は当てずっぽうでは説明しにくく、Fさんは当てずっぽうではないという主張を支持する根拠が得られた。
比べて分かること（例）: 正解の割合は Fさん（6割）のほうが Cさん（8割）より低いのに、Fさんは「説明しにくい」、Cさんは「保留」になった。判断を決めるのは割合だけではなく、それが何問中の話かである。問題数が多いほど、偶然だけで大きく偏ることは起こりにくい。
検算: 100回投げの結果表200個を Python で数えて 60 以上は 4（60枚 2回・61枚 1回・63枚 1回）、80 以上は 0 ✓。m=49.4、s≒4.923、m＋2s≒59.247 で 60>59.247 ✓。
※「6割は8割より低いから、Cさんより弱い根拠しかない」は想定誤答。割合ではなく、偶然の世界での起こりやすさ p で比べる。

**問5**（解答例）主張Bの「判断を保留する」は、「30人中18人という結果は、効果がなくても偶然で6回に1回ほど起こるので、このデータでは偶然と区別できない」という意味である。練習法Qに効果がないと分かったわけではなく、効果がある可能性は残っている。「主張は誤りである」は効果がないと言い切る表現で、このデータからは言えない。人数を増やすなど別の調べ方で決着がつくかもしれない。
（採点の目安: ①保留=偶然と区別できない ②効果がないと決まったのではない ③別の調べ方の余地、のうち①②が書けていれば可。）

**S1** 9枚以下は 6枚 1回・7枚 1回・8枚 2回・9枚 1回で 5回、21枚以上は 3回。合わせて **8回**。相対度数 8/200=**0.04**。
気づくこと（例）: この実験の表で「平均から 2s より外」に入る割合は、両側を合わせても 0.04 で、基準(a)の 0.05 より小さい。片側ずつでは、多い側（21枚以上）が 3/200=0.015、少ない側（9枚以下）が 5/200=0.025 で、どちらも 0.05 以下である。だからこの表では、主張の向きに合う側で帯の外に出た結果は、基準(a)にも達する。逆は成り立たず、20枚は p=0.04 で基準(a)に達するのに帯の中にある（問2）。2つの基準は別の物差しで、この関係はこの表で数えた観察である（ほかのデータでも同じ割合になるとは限らない）。
検算: Python で 9 以下と 21 以上を数えて 5・3 ✓。m−2s≒9.049 なので 9 は帯の外、10 は帯の中 ✓。
※m−2s≒9.05 を「9 は帯の中」と読むのが想定誤答。9 は 9.05 より小さいので帯の外。
