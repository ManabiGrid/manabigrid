## L01 中学の道具を棚卸しする——代表値・四分位範囲・箱ひげ図と「外れ値」

**問1**
- 平均値 m=(5＋6＋7＋7＋8＋8＋8＋9)/8=58/8=**7.25**（点）
- 中央値: 8個の真ん中は4番目と5番目の平均で (7＋8)/2=**7.5**（点）
- 最頻値: **8**（点）（3回）
- 範囲: 9−5=**4**（点）
検算: statistics.mean=7.25、statistics.median=7.5、statistics.mode=8 で一致。
※中央値を「4番目の 7」または「5番目の 8」のどちらか一方にするのが典型ミス。偶数個は真ん中2つの平均。
※範囲を「最大値そのもの（9）」と答えない。最大値−最小値。

**問2**
(1) 9個。中央値は5番目の **9**。中央値を除いて前半 3, 5, 6, 8 の中央値は (5＋6)/2=**5.5**（第1四分位数）、後半 11, 12, 14, 17 の中央値は (12＋14)/2=**13**（第3四分位数）。四分位範囲は 13−5.5=**7.5**。
検算: Q1=5.5 より小さい値は 3, 5 の2個、Q3=13 より大きい値は 14, 17 の2個——どちらも9個の約4分の1。スクリプト（中2方式）で再計算して 5.5／9／13 に一致。
(2) 10個。中央値は5番目と6番目の平均で (7＋8)/2=**7.5**。前半 2, 4, 5, 5, 7 の中央値は3番目の **5**（第1四分位数）、後半 8, 9, 10, 12, 15 の中央値は **10**（第3四分位数）。四分位範囲は 10−5=**5**。
検算: 5 より小さい値は 2, 4 の2個、10 より大きい値は 12, 15 の2個。スクリプトで 5／7.5／10 に一致。
※(1)で中央値 9 を前半・後半に入れて 5個ずつにしてしまうのが典型ミス（この教材の方式では奇数個の中央値はどちらにも入れない）。
※(2)で前半・後半を「5個ずつ」にせず、中央値 7.5 をまたぐ値の扱いで迷う人がいるが、偶数個は真ん中で二等分するだけ。

**問3**
- C班: 範囲 14−2=12、四分位範囲 10−5=5。D班: 範囲 15−4=11、四分位範囲 13−7=6。
(1) **○**。12>11。
(2) **○**。6>5。
(3) **×**。箱の長さは真ん中の約半数の散らばりの幅であって、データの個数ではない。C班も D班も11人で同数である。
(4) **○**。中央値 8<9、第1四分位数 5<7、第3四分位数 10<13 で、いずれも D班が大きい。
検算: (1)(2)は引き算の再計算で一致。(4)は3つの値の比較を個別に確認。
※(1)と(2)で「範囲が大きい方は四分位範囲も大きいはず」と思い込むのが典型ミス。範囲は両端で、四分位範囲は区切りで決まるので、大小が逆転してよい。

**問4**
(1) 12個。中央値は6番目と7番目の平均 (11＋12)/2=11.5。前半 5, 8, 9, 10, 10, 11 の中央値は (9＋10)/2=**9.5**（第1四分位数）、後半 12, 13, 14, 15, 16, 28 の中央値は (14＋15)/2=**14.5**（第3四分位数）。四分位範囲は 14.5−9.5=**5**。
(2) 1.5×5=7.5。下の線は 9.5−7.5=2、上の線は 14.5＋7.5=22。2 未満の値はなく（最小値 5 は 2 以上）、22 超の値は 28。よって外れ値は **28** の1つ。
(3) 28 を除いた11個: 5, 8, 9, 10, 10, 11, 12, 13, 14, 15, 16。中央値は6番目の 11。前半 5, 8, 9, 10, 10 の中央値は **9**、後半 12, 13, 14, 15, 16 の中央値は **14**。四分位範囲は 14−9=**5** で、(1)と同じ値になる。気づくこと（例）: **このデータでは、外れ値を1つ除いても四分位範囲は 5 のまま変わらない**（一方、範囲は 23 から 11 へ大きく変わる）。
検算: スクリプト（中2方式・1.5倍基準）で Q1=9.5、Q3=14.5、外れ値 [28]、除いた後 Q1=9、Q3=14 に一致。範囲は 28−5=23、16−5=11。
※(2)で「5 も小さいから外れ値」とするのが典型ミス。基準の線（2 未満）を計算してから判定する。
※(3)では、第1四分位数は 9.5→9、第3四分位数は 14.5→14 と、区切りの値はどちらも 0.5 ずつ下がっている。同じだけ下がったので、差である四分位範囲が 5 のまま変わらなかった。外れ値を除けば四分位範囲がいつも変わらない、というわけではない（L01 の A班から 18 を除くと、四分位範囲は 3 から 2 になる）。それでも範囲ほど大きくは動かないのは、四分位数が「何番目か」で決まるからである。

**問5**（解答例）
外れ値は、他の値から極端にかけ離れた値で、基準を決めて判定する（値が正しいかどうかは、この時点では問わない）。そのうち、測定ミスや入力ミスなど、原因が分かっている誤った値を異常値と呼んで区別する。異常値は訂正するか除いて分析するが、外れ値は理由なく除かず、なぜその値が出たのかという背景を探る。
（採点の目安: ①かけ離れた値であること ②原因が分かっている誤りか否かで区別すること ③扱いの違い（除く／背景を探る）の3点。3点そろって満点。）

**S1**（解答例——条件を満たすデータは1通りではない）
- E: 1, 2, 3, 4, 5, 6, 7, 8, 9 → 最小値 1、Q1=(2＋3)/2=2.5、Q3=(7＋8)/2=7.5、最大値 9。四分位範囲 5、範囲 8。
- F: 1, 4, 5, 5, 6, 6, 7, 8, 20 → 最小値 1、Q1=(4＋5)/2=4.5、Q3=(7＋8)/2=7.5、最大値 20。四分位範囲 3、範囲 19。
四分位範囲は E（5）>F（3）、範囲は E（8）<F（19）で、2つの条件を同時に満たす。
理由（例）: 範囲は最大値と最小値の2つだけで決まるので、1つのかけ離れた値（F の 20）で大きくなる。四分位範囲は上下4分の1の位置の値で決まるので、端の値がどれだけ極端でも順位が変わらなければ動かない。だから、真ん中の約半数が広く散らばり両端は近い E と、真ん中が狭く1つだけ遠い F のような組合せが作れる。
検算: E は9個・奇数個で中央値5を除き前半 1, 2, 3, 4・後半 6, 7, 8, 9。F は中央値 6 を除き前半 1, 4, 5, 5・後半 6, 7, 8, 20。スクリプト（中2方式）で E: 2.5／5／7.5、F: 4.5／6／7.5 に一致。
（指導メモ: 生徒の作ったデータが違っていても、五数の計算と2条件の確認が正しければ正解とする。中央値を除く扱いを忘れて四分位数を出している答案に注意。）

## L02 散らばりを1つの数にする——分散と標準偏差

**問1**
合計 25、m=25/5=**5**。偏差は −3, −1, 0, 1, 3（和は 0）。偏差の2乗は 9, 1, 0, 1, 9 で和 20。分散 s²=20/5=**4**、標準偏差 s=√4=**2**。
検算: statistics.pvariance=4.0。別の求め方: 値の2乗の平均 (4＋16＋25＋36＋64)/5=145/5=29、29−5²=4 で一致。
※偏差の和 0 を確かめずに進み、平均値の計算違い（合計 25 を 4 で割る等）に気づかないのが典型ミス。

**問2**
合計 80、m=80/8=**10**。偏差は −5, −3, −1, −1, 1, 1, 3, 5（和は 0）。2乗は 25, 9, 1, 1, 1, 1, 9, 25 で和 72。分散 s²=72/8=**9**、標準偏差 s=**3**（点）。
検算: statistics.pvariance=9.0。別の求め方: 値の2乗の和 25＋49＋81＋81＋121＋121＋169＋225=872、872/8=109、109−10²=9 で一致。
※2乗の和 72 を「8 で割る」のを忘れて 72 を分散とする、または分散 9 を標準偏差と答える（√ を忘れる）のが典型ミス。

**問3**
(1) X: 合計 40、m=**8**、中央値（3番目）**8**。Y: 合計 40、m=**8**、中央値 **8**。
(2) X: 偏差 −3, −1, 0, 1, 3、2乗の和 9＋1＋0＋1＋9=20、s²=4、s=**2**。Y: 偏差 −6, −2, 0, 2, 6、2乗の和 36＋4＋0＋4＋36=80、s²=16、s=**4**。**Y の方が散らばりが大きい**（標準偏差が2倍）。
検算: statistics.pvariance は X=4.0、Y=16.0。X の記録は Y の記録の「平均からのずれを半分にしたもの」になっており、s が半分になる（L03 の変量の変換で確かめる関係）。
※「平均も中央値も同じだから同じ分布」と答えない。散らばりは代表値とは別の情報。

**問4**
(1) 合計 160、m=160/8=**20**（人）。偏差は −6, −5, −3, −1, 0, 2, 2, 11（和は 0）。2乗は 36, 25, 9, 1, 0, 4, 4, 121 で和 200。分散 s²=200/8=25、標準偏差 s=**5**（人）。
(2) m−2s=20−10=**10**、m＋2s=20＋10=**30**。10 以上 30 以下に入るのは 14, 15, 17, 19, 20, 22, 22 の **7 日**。外に出るのは **31**（1日）。
検算: statistics.pvariance=25.0。別の求め方: 値の2乗の和 196＋225＋289＋361＋400＋484＋484＋961=3400、3400/8=425、425−20²=25 で一致。帯の判定は 31>30 のみ。
※偏差 11 の2乗 121 を 111 などと誤る計算ミスに注意。2乗の和が 200 にならなければどこかが違う。

**問5**（解答例）
偏差には正のものと負のものがあり、そのまま足すと打ち消し合って和が必ず 0 になるので、散らばりの数にならない。そこで偏差を2乗して符号を消してから足す。さらに、データの総数が多いほど和が大きくなってしまうので、総数で割って1個あたりにそろえる。
（採点の目安: ①打ち消し合って 0 になる ②2乗で符号を消す ③総数で割って個数の違いをそろえる、の3点。）

**S1**
(1) m=(2＋3＋7)/3=12/3=**4**。中央値は真ん中の **3**。
(2) p=3: (2−3)²＋(3−3)²＋(7−3)²=1＋0＋16=**17**。p=4: 4＋1＋9=**14**。p=5: 9＋4＋4=**17**。**p=4（平均値）のとき最小**。
(3) p=3: |2−3|＋|3−3|＋|7−3|=1＋0＋4=**5**。p=4: 2＋1＋3=**6**。p=5: 3＋2＋2=**7**。**p=3（中央値）のとき最小**。
(4)（解答例）偏差の2乗の和は平均値のところで最小になるので、分散・標準偏差は平均値と相性がよい。偏差の絶対値の和は中央値のところで最小になるので、絶対値で散らばりを測るなら中央値と組み合わせるのが自然である。
検算: スクリプトで p=3, 4, 5 の2乗の和 17, 14, 17、絶対値の和 5, 6, 7 に一致。(2)の最小が平均値になることは、一般に (値−p)² の和が p の2次式で、平均値のところで最小になるという性質の具体例（この教材では一般証明は扱わない）。
（指導メモ: (3)で p=3 と p=4 の差が小さいので、「最小」の判定を数値で明示させる。p=2 や p=7 まで調べさせると中央値での最小がはっきりする。）

## L03 分散・標準偏差を使う——2つのデータの比較と変量の変換

**問1**
- X: 合計 48、m=**8**。偏差 −3, −1, −1, 0, 2, 3、2乗の和 9＋1＋1＋0＋4＋9=24、s²=4、s=**2**。
- Y: 合計 48、m=**8**。偏差 −5, −5, 0, 1, 3, 6、2乗の和 25＋25＋0＋1＋9＋36=96、s²=16、s=**4**。
まとめ（例）: 平均は 8 で同じだが、散らばりは Y の方が大きく、標準偏差は X の2倍である。
検算: statistics.pvariance は X=4.0、Y=16.0。Y の偏差の和 −5−5＋0＋1＋3＋6=0 を確認。
※Y の偏差 −5 が2つあることを見落として2乗の和を 71 にするミスに注意。

**問2**
階級値×度数の合計 15×2＋25×3＋35×3＋45×1＋55×1=30＋75＋105＋45＋55=310、m=310/10=**31**（分）。偏差は −16, −6, 4, 14, 24、偏差の2乗は 256, 36, 16, 196, 576、偏差の2乗×度数は 512, 108, 48, 196, 576 で合計 1440。分散 s²=1440/10=144、標準偏差 s=**12**（分）。
検算: 各階級値を度数分だけ並べた生データ 15, 15, 25, 25, 25, 35, 35, 35, 45, 55 で statistics.mean=31、statistics.pvariance=144.0。
※階級値だけを足して 5 で割る（175/5=35 で、正しい 31 と違う）、偏差の2乗に度数を掛け忘れる（256＋36＋16＋196＋576=1080 で、正しい合計 1440 と違う。1080/10=108 から s≒10.4）、総数を 5 とする（1440/5=288 から s≒17.0）、が典型ミス。この問題の数値は、どのミスをしても答えが変わるように選んである。答えが合わなければ、途中の式に「階級値×度数」「偏差の2乗×度数」の列があるかを確かめる。

**問3**
(1) 合計 36、m=**6**。偏差 −3, −1, −1, 0, 2, 3、2乗の和 9＋1＋1＋0＋4＋9=24、s²=4、s=**2**。
(2) 4 を足したデータ 7, 9, 9, 10, 12, 13。合計 60、m=**10**（=6＋4）。偏差は −3, −1, −1, 0, 2, 3 で(1)と同じ、s²=4、s=**2**（変わらない）。規則「c を足すと m は c 増え、s は不変」と一致。
(3) 3 倍したデータ 9, 15, 15, 18, 24, 27。合計 108、m=**18**（=6×3）。偏差 −9, −3, −3, 0, 6, 9、2乗の和 81＋9＋9＋0＋36＋81=216、分散 s²=216/6=**36**（=4×3²）、標準偏差 s=**6**（=2×3）。規則「a 倍すると m は a 倍・s²は a² 倍・s は a 倍」と一致。
検算: statistics.pvariance は元=4.0、＋4=4.0、×3=36.0。
※(3)で標準偏差を 3²=9 倍して 18 と答える（分散と混同）のが典型ミス。分散が 9 倍、標準偏差が 3 倍。

**問4**
仮平均 155 との差 u は −2, 0, 0, 1, 3, 4、合計 6、u の平均は 6/6=1。よって m=155＋1=**156**（cm）。u の偏差（u−1）は −3, −1, −1, 0, 2, 3、2乗の和 9＋1＋1＋0＋4＋9=24、分散 24/6=4、標準偏差 s=**2**（cm）。
検算: 元の値で直接計算——合計 936、936/6=156、偏差 −3, −1, −1, 0, 2, 3 で分散 4。statistics.pvariance=4.0 で一致。
※u の平均 1 を足し戻さずに「平均 155」と答える、または u の偏差を u そのもの（−2, 0, …）と取り違えて2乗するのが典型ミス。u の分散は「u の平均 1 からのずれ」で計算する。

**問5**（解答例）
- 言えること: どちらの組も平均点は 60 点で同じだが、標準偏差 15 点の組の方が得点の散らばりが大きい（平均からのずれが、全体として大きい）。
- 言えないこと: どちらの組が「優秀か」（平均は同じ）、特定の生徒が何点か、分布の形が左右対称かどうかは、平均値と標準偏差だけからは分からない。
（採点の目安: 「言えること」に散らばりの大小、「言えないこと」に優劣や個人の得点・分布の形のいずれか1つが書けていれば正解。）

**S1**
(1) y の合計は (ax1＋b)＋(ax2＋b)＋…=a×(x の合計)＋n×b（n はデータの総数）。総数 n で割ると a×(x の平均)＋b=am＋b。
(2) y の平均値は am＋b だから、y の各値の偏差は (ax＋b)−(am＋b)=a(x−m)、つまり x の偏差の a 倍。2乗すると a²(x−m)² で、その平均（分散）は a²×s²。標準偏差はその正の平方根 √(a²s²)=|a|s。a が負のとき as は負の数になる（s=0 のときだけは 0）が、標準偏差は散らばりの大きさを表す 0 以上の数なので、絶対値 |a| を付ける必要がある。
(3) x: 合計 100、m=20、偏差 −3, −1, 0, 1, 3、s²=20/5=4、s=2。y=1.8x＋32 だから、平均値 1.8×20＋32=**68**（°F）、分散 1.8²×4=3.24×4=**12.96**、標準偏差 1.8×2=**3.6**。実際に直すと 62.6, 66.2, 68, 69.8, 73.4（合計 340、平均 68）。偏差 −5.4, −1.8, 0, 1.8, 5.4、2乗 29.16, 3.24, 0, 3.24, 29.16 で和 64.8、分散 64.8/5=12.96 で一致。
(4) y=100−x は a=−1、b=100。平均値 −62＋100=**38**、標準偏差 |−1|×8=**8**（分散は 64 で変わらない）。
検算: (3)は分数で厳密に再計算（statistics.pvariance=12.96、statistics.mean=68.0）。(4)は「全員の得点を 100 から引いても、点どうしの間隔は変わらない」ことから s 不変が直観的にも確かめられる。
※(4)で標準偏差を −8 とするのが典型ミス。標準偏差は負にならない。
