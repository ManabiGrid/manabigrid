## L10 図形の計量への活用——測れない距離と高さ

**問1**
(1) ∠ACB = 180°−60°−75° = **45°**
(2) BC は ∠CAB=60° の対辺、AB=100 は ∠ACB=45° の対辺だから、正弦定理で BC/sin 60°=100/sin 45°。
　BC = 100×sin 60°/sin 45° = 100×(√3/2)÷(√2/2) = 100√3/√2 = 100√6/2 = **50√6**（m）
　20√6≒48.99（L10 例題1）だから 50√6 ≒ 2.5×48.99 = 122.47… ≒ **122.5**（m）
　検算: 50√6 を2乗すると 2500×6=15000。122.47²≒14998.9 で重なる ✓
(3) AC は ∠CBA=75° の対辺。表から sin 75°=0.9659、sin 45°=0.7071。
　AC = 100×sin 75°/sin 45° = 100×0.9659/0.7071 = 136.60… ≒ **136.6**（m）
　検算: 大小の向き——角の大きい順 75°>60°>45° に対辺も AC(136.6)>BC(122.5)>AB(100) ✓。別の定理で戻す——△ABC で AB=100、BC≒122.47、その間の角 ∠ABC=75° から余弦定理: AC²=100²＋122.47²−2×100×122.47×cos 75°≒10000＋14998.9−24494×0.2588≒24998.9−6339.0=18659.9、AC≒136.6 ✓
※典型ミス: 対辺の取り違え（BC を 75° の対辺として 100×sin 75°/sin 45° と計算する）。正弦定理では「辺とその向かいの角」を必ず組で書く。また sin 75° を 0.97 と粗く丸めると AC≒137.2 となり小数第1位が狂う（途中は4桁のまま）。

**問2**
図: 気球 P の真下が H、H から見て同じ側に B（近い）、A（遠い）。BH=x、PH=h とおく。
　△PBH（∠PHB=90°）で tan 60°=h/x、tan 60°=√3 だから h=√3 x
　△PAH で AH=x＋200 なので tan 30°=h/(x＋200)、tan 30°=1/√3 だから √3 h=x＋200
　h=√3 x を代入して 3x=x＋200、x=100。よって PH = h = **100√3**（m）（≒173.2 m）
　検算: x=100 のとき tan 30°≒173.2/300=0.5773…（表 0.5774）✓、tan 60°≒173.2/100=1.732（表 1.7321）✓
※典型ミス: tan の分母・分子を逆にする（tan 60°=x/h）。「対辺/隣辺」で、見上げる角の対辺は高さ。なお A・B を H の反対側に置いて解くと 50√3 m になるが、本文は「H から見て同じ側」と指定している。

**問3**
　OP=80、OQ=50 とその間の角 ∠POQ=60°——「2辺とその間の角」なので余弦定理。
　PQ² = 80²＋50²−2×80×50×cos 60° = 6400＋2500−8000×(1/2) = 8900−4000 = 4900
　PQ>0 だから PQ = **70**（m）
　検算: 3辺 80・50・70 から角を戻す——cos∠POQ=(80²＋50²−70²)/(2×80×50)=4000/8000=1/2 で 60° ✓。また 80−50<70<80＋50 で三角形として成り立つ ✓
※典型ミス: 2×80×50×cos 60° の掛け忘れ（PQ²=8900）や、cos 60° を √3/2 と取り違える（sin と混同）。

**問4**
図: A を中心に、北を上・東を右にとる。T は A の真北、B は A の真東だから、△ABT は ∠TAB=90° の直角三角形で、AB=120。B から T を見た方向は「真北から西へ 30°」——B における真北の向きは AT と平行（A の北向きと同じ）で、BA は真西の向きだから、BT と BA のなす角は 90°−30°=60°。つまり ∠ABT=60°、∠ATB=30°。
　直角三角形 ABT で tan 60°=AT/AB だから AT = 120×tan 60° = **120√3**（m）（≒207.8 m）
　検算: 正弦定理で AT/sin 60°=AB/sin 30° → AT=120×(√3/2)÷(1/2)=120√3 ✓。斜辺 BT=AB/cos 60°=240 で、三平方の定理 120²＋(120√3)²=14400＋43200=57600=240² ✓
※典型ミス: ∠ABT を 30° と読む（「真北から西へ 30°」は、東西の線 BA から測ると 60°）。この誤りで AT=120×tan 30°=40√3≒69.3 m と出る——T が A の真北、B が真東なので、AT が AB=120 より短いのは、B からの方向が北寄り（30° 西）であることと合わない。図をかけば向きで気づける。

**問5**
　△ABD で AB=4、AD=6、その間の角 ∠BAD=60°。余弦定理で
　BD² = 4²＋6²−2×4×6×cos 60° = 16＋36−24 = 28、BD = **2√7**
　△ABC で AB=4、BC=AD=6、その間の角 ∠ABC=180°−60°=120°（平行四辺形の隣り合う角の和は 180°）。cos 120°=−1/2 だから
　AC² = 4²＋6²−2×4×6×cos 120° = 52＋24 = 76、AC = **2√19**
　検算: cos 120°=−cos 60° なので、2つの式を足すと cos の項が消えて BD²＋AC²=2(4²＋6²)=104 になるはず。28＋76=104 ✓。大小の向き——AC は鈍角 120° の対辺なので BD より長い（2√19≒8.7>2√7≒5.3）✓
※典型ミス: ∠ABC も 60° として AC=2√7 と出す（すると2本の対角線が等しくなるが、対角線が等しい平行四辺形は長方形だけ）。「隣り合う角の和が 180°」を図に書き込んでから余弦定理へ。

**S1**
(1) △PAB で ∠APB=180°−75°−45°=60°。AP は ∠PBA=45° の対辺、AB=50 は ∠APB=60° の対辺だから
　AP = 50×sin 45°/sin 60° = 50×(√2/2)÷(√3/2) = 50√2/√3 = **50√6/3**（m）（≒40.82 m）
(2) △QAB で ∠AQB=180°−30°−105°=45°。AQ は ∠QBA=105° の対辺。sin 105°=sin(180°−105°)=sin 75°=0.9659（L05）、sin 45°=0.7071 だから
　AQ = 50×sin 105°/sin 45° = 50×0.9659/0.7071 = 68.300… ≒ **68.30**（m）
(3) P と Q は直線 AB の同じ側にあり、どちらも A で AB から測った角なので ∠PAQ = ∠PAB−∠QAB = 75°−30° = **45°**
　△PAQ で AP≒40.82、AQ≒68.30、その間の角 45°。余弦定理で
　PQ² = 40.82²＋68.30²−2×40.82×68.30×cos 45° ≒ 1666.3＋4664.9−5576.0×0.7071 ≒ 6331.2−3942.8 = 2388.4
　PQ = 48.87… ≒ **48.9**（m）
　検算: 別の三角形で戻す——B 側から見ると ∠QBP=105°−45°=60°、BP=50×sin 75°/sin 60°≒55.77、BQ=50×sin 30°/sin 45°≒35.36 で、PQ²=55.77²＋35.36²−2×55.77×35.36×cos 60°≒3110.3＋1250.3−1972.0=2388.6、PQ≒48.87 ✓（2つの道で小数第2位まで重なる）。大小の向き——PQ(48.9) は AQ−AP(27.5) より長く AQ＋AP(109.1) より短い ✓
※典型ミス: (2) で sin 105° を「表にない」と止まる、または −sin 75° と符号を付ける（sin は 0°〜180° で負にならない）。(3) で ∠PAQ を 75°＋30°=105° とする（P・Q が AB の反対側にあるときの角。本文は同じ側と指定）。

## L11 空間図形の計量——平面を1枚取り出す

**問1**
(1) 底面の △ABC（∠ABC=90°）で AC²=4²＋4²=32。△ACG（∠ACG=90°）で AG²=AC²＋CG²=32＋16=48。AG = **4√3**
(2) θ=∠GAC は直角三角形 ACG の鋭角で、sin θ = CG/AG = 4/(4√3) = 1/√3 = **√3/3**（≒0.5774）
　表の sin の列で 0.5774 に最も近いのは sin 35°=0.5736（sin 36°=0.5878）だから θ ≒ **35°**
　検算: cos θ=AC/AG=4√2/(4√3)=√6/3 で、sin²θ＋cos²θ=3/9＋6/9=1 ✓。立方体の対角線と底面のなす角は辺の長さによらない（すべての立方体は相似）ので、1辺が 4 でなくても 35° 前後——1辺 1 の立方体で sin θ=1/√3 と同じ ✓
※典型ミス: sin θ=AC/AG（cos との取り違え）→ 0.8165 で約 55°。θ の対辺は「底面に垂直な辺 CG」。

**問2**
　△AFC の3辺を、各面の直角三角形で出す。AF²=AB²＋BF²=4＋1=5、FC²=BF²＋BC²=1＋4=5、CA²=AB²＋BC²=4＋4=8。AF=FC=√5、CA=2√2。
　3辺がそろったので余弦定理で角、正弦に直して面積公式へ。
　cos∠FAC = (AF²＋CA²−FC²)/(2×AF×CA) = (5＋8−5)/(2×√5×2√2) = 8/(4√10) = 2/√10 = √10/5
　sin∠FAC = √(1−10/25) = √(15/25) = √15/5
　△AFC = (1/2)×AF×CA×sin∠FAC = (1/2)×√5×2√2×(√15/5) = √10×√15/5 = √150/5 = 5√6/5 = **√6**
　検算: AF=FC の二等辺三角形だから、F から CA に垂線を下ろすと足は CA の中点。高さ=√(AF²−(CA/2)²)=√(5−2)=√3、面積=(1/2)×2√2×√3=√6 ✓
※典型ミス: 底辺 CA に対する高さを直方体の高さ BF=1 と取り違える（高さは △AFC の乗っている平面の中で測る）。この誤りでは面積 √2 になる。

**問3**
(1) H は底面の正三角形 BCD の中心（例題3 と同じ理由——AB=AC=AD で AH が共通だから、3つの直角三角形が合同で HB=HC=HD）。BC の中点を N とすると BN=2、∠HBN=30°、∠BNH=90° で
　BH = BN/cos 30° = 2÷(√3/2) = 4/√3 = 4√3/3
　直角三角形 ABH で AH² = AB²−BH² = 16−16/3 = 32/3、AH = √(32/3) = 4√2/√3 = **4√6/3**
(2) 底面 △BCD=(1/2)×4×4×sin 60°=4√3。V = (1/3)×4√3×(4√6/3) = 16√18/9 = 16×3√2/9 = **16√2/3**
(3) θ=∠ABH は直角三角形 ABH の鋭角で、cos θ = BH/AB = (4√3/3)/4 = **√3/3**
　検算: 1辺 6 の例題3 との相似比は 4/6=2/3。AH=2√6×(2/3)=4√6/3 ✓、体積は (2/3)³=8/27 倍で 18√2×8/27=16√2/3 ✓。cos θ は辺の長さによらず（正四面体はすべて相似）、例題3 でも BH/AB=2√3/6=√3/3 ✓。sin θ=AH/AB=√6/3 で sin²θ＋cos²θ=6/9＋3/9=1 ✓
※典型ミス: H を BC の中点 N と混同して BH=2、AH=√12=2√3 とする。H は3頂点から等距離の点（中心）で、中点ではない。

**問4**
　地面の △HAB で ∠AHB=180°−30°−45°=105°。sin 105°=sin 75°=0.9659（L05）。AH は ∠HBA=45° の対辺、AB=80 は ∠AHB=105° の対辺だから
　AH = 80×sin 45°/sin 105° = 80×0.7071/0.9659 = 58.56… ≒ 58.57
　鉛直面の直角三角形（∠AHT=90°）で tan 35°=TH/AH、tan 35°=0.7002 だから
　TH = 58.57×0.7002 = 41.01… ≒ **41.0**（m）
　検算: 仰角 35°<45° だから TH<AH ✓（41.0<58.6）。地面の三角形を余弦定理で戻す——BH=80×sin 30°/sin 105°=40/0.9659≒41.41。cos 105°=−cos 75°=−0.2588 だから AB²=58.57²＋41.41²−2×58.57×41.41×(−0.2588)≒3430.4＋1714.8＋1255.4=6400.6 で、80²=6400 と重なる ✓
※典型ミス: sin 105° を表で引けずに止まる（180°−105°=75° に直す）。AH を「∠HAB=30° の対辺」と取り違える（AH の向かいの角は B の角 45°）。

**問5**
　円錐の頂点を O、底面の円の中心を M、底面の円周上の点を P とすると、△OMP は ∠OMP=90° の直角三角形で、母線 OP=6 が斜辺、∠OPM=60° が「母線と底面のなす角」。
　r = MP = OP×cos 60° = 6×(1/2) = **3**
　高さ = OM = OP×sin 60° = 6×(√3/2) = **3√3**
　体積 = (1/3)×π×r²×高さ = (1/3)×π×9×3√3 = **9√3π**
　検算: r²＋高さ²=9＋27=36=6² で三平方の定理が成り立つ ✓。母線と底面のなす角が 60° なら、高さは r の tan 60°=√3 倍——3√3=3×√3 ✓
※典型ミス: r=6×sin 60°（角 60° の隣辺が r。sin と cos の取り違え）。体積の (1/3) を落とす。

**S1**
(1) 3つの面は直角三角形だから三平方の定理で AB=√(1²＋1²)=**√2**、BC=√(1²＋2²)=**√5**、CA=√(2²＋1²)=**√5**
(2) △ABC は3辺がそろったので、余弦定理を cos の形で。
　cos∠BAC = (AB²＋CA²−BC²)/(2×AB×CA) = (2＋5−5)/(2×√2×√5) = 2/(2√10) = 1/√10 = **√10/10**
　sin∠BAC = √(1−1/10) = √(9/10) = 3/√10
　△ABC = (1/2)×AB×CA×sin∠BAC = (1/2)×√2×√5×(3/√10) = (1/2)×√10×3/√10 = **3/2**
(3) S1=△OAB=(1/2)×1×1=1/2、S2=△OBC=(1/2)×1×2=1、S3=△OCA=(1/2)×2×1=1。
　S1²＋S2²＋S3² = 1/4＋1＋1 = **9/4**、S4² = (3/2)² = **9/4**。**2つは等しい**。
　検算: (2) を別の道で——BC=CA の二等辺三角形だから、C から AB に垂線を下ろすと足は AB の中点。高さ=√(CA²−(AB/2)²)=√(5−1/2)=√(9/2)=3/√2、面積=(1/2)×√2×3/√2=3/2 ✓
　（指導メモ: 頂点に3つの直角が集まる三角錐で S1²＋S2²＋S3²=S4² が成り立つことは、四平方の定理と呼ばれることがある。ここでは1つの三角錐で確かめるところまでを求め、一般に成り立つことの証明は、この教材では求めない（OA=a、OB=b、OC=c と文字で置いて (1)〜(3) と同じ計算をたどれば、この単元の道具で示せる）。）
※典型ミス: △ABC を「直角三角形」と思い込んで (1/2)×√2×√5 とする（△ABC に直角はない。直角があるのは3つの側面）。
