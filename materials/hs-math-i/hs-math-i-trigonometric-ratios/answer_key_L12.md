## L12 単元のまとめ——「計量」の道具箱

**問1**
(1) 直角は B にあるから、斜辺は直角の向かいの CA=17。A から見て、対辺は BC=15、隣辺は AB=8。
　sin A = **15/17**、cos A = **8/17**、tan A = **15/8**
　C から見て、対辺は AB=8、隣辺は BC=15。sin C = **8/17**、cos C = **15/17**
　検算: 8²＋15²=64＋225=289=17² で、たしかに直角三角形 ✓。sin²A＋cos²A=(225＋64)/289=1 ✓。A＋C=90° だから sin C=cos A、cos C=sin A（L03）——8/17 と 15/17 で一致 ✓
※典型ミス: 「AB が斜辺」と思い込む（斜辺は直角の向かいの辺——頂点の名前や図の向きでなく、直角の位置で決める）。
(2) sin 150° = sin(180°−30°) = sin 30° = **1/2**
　cos 135° = −cos(180°−135°) = −cos 45° = **−√2/2**
　tan 120° = −tan(180°−120°) = −tan 60° = **−√3**
　検算: 単位円（r=1）で確かめる——150° の点 P は (−√3/2, 1/2) で y=1/2 ✓、135° の点は (−√2/2, √2/2) で x=−√2/2 ✓、120° の点は (−1/2, √3/2) で y/x=(√3/2)÷(−1/2)=−√3 ✓
※典型ミス: cos 135°=√2/2、tan 120°=√3（符号落ち）。鈍角では点 P が y 軸の左にあるので x 座標が負——cos と tan は負、sin は正。
(3) sin²θ=1−cos²θ=1−9/25=16/25。0°≦θ≦180° では sin θ≧0 だから sin θ = **4/5**
　tan θ = sin θ/cos θ = (4/5)÷(−3/5) = **−4/3**
　cos θ<0 だから θ は鈍角。cos(180°−θ)=−cos θ=3/5=0.6 で、表の cos の列で 0.6 に最も近いのは cos 53°=0.6018（cos 54°=0.5878）だから 180°−θ≒53°、θ ≒ **127°**
　検算: 斜辺 5・対辺 4・隣辺 3 の直角三角形で 4/5・3/5・4/3——符号を除けば一致 ✓。1＋tan²θ=1＋16/9=25/9、1/cos²θ=25/9 ✓
※典型ミス: sin θ=±4/5 と2つ書く（sin θ は 0°〜180° で負にならない——鋭角か鈍角かで分かれるのは cos と tan）。θ≒53° と答える（cos が負なら鈍角側 180°−53°）。

**問2**
(1) 3辺がそろっているので余弦定理を cos の形で。cos A = (b²＋c²−a²)/(2bc) = (4＋9−7)/(2×2×3) = 6/12 = 1/2。0°<A<180° で cos A=1/2 となるのは A = **60°**
(2) S = (1/2)bc sin A = (1/2)×2×3×sin 60° = 3×(√3/2) = **3√3/2**
(3) 正弦定理 a/sin A=2R から 2R = √7/(√3/2) = 2√7/√3、R = √7/√3 = √21/3。R = **√21/3**
(4) 最大の辺は c=3（√7≒2.65、2）だから、最大の角は C。cos C = (a²＋b²−c²)/(2ab) = (7＋4−9)/(2×√7×2) = 2/(4√7) = 1/(2√7) = √7/14>0 で C は鋭角。最大の角が鋭角だから、この三角形は**鋭角三角形**。
　検算: (2) を別の道で——cos C=√7/14 から sin C=√(1−7/196)=√(189/196)=3√21/14、S=(1/2)ab sin C=(1/2)×√7×2×(3√21/14)=3√147/14=3×7√3/14=3√3/2 ✓。(3) を別の辺で——c/sin C=3÷(3√21/14)=14/√21=2√21/3=2R ✓
※典型ミス: (4) で「A=60° だから鋭角三角形」と決める（鈍角があるとすれば最大の辺の向かいなので、最大の角で判定する）。cos C の分母を 2bc と書く（cos C の分母は C をはさむ2辺 a・b の積）。

**問3**
(1) OP=70、OQ=80、その間の角 120°——「2辺とその間の角」なので余弦定理。cos 120°=−1/2 だから
　PQ² = 70²＋80²−2×70×80×cos 120° = 4900＋6400＋5600 = 16900、PQ = **130**（m）
　検算: 3辺から角を戻す——cos∠POQ=(70²＋80²−130²)/(2×70×80)=−5600/11200=−1/2 で 120° ✓。PQ=130 は最大の角 120° の対辺で、70・80 より長い ✓。三角形として 130<70＋80=150 ✓
※典型ミス: cos 120° の符号を落として PQ²=11300−5600=5700、PQ≒75.5 とする。鈍角の余弦は負——引く項が足す項に変わる。
(2) 底面の △ABC で AC²=3²＋4²=25、AC=5。△ACG（∠ACG=90°）で AG²=AC²＋CG²=25＋25=50、AG = **5√2**
　θ=∠GAC で sin θ = CG/AG = 5/(5√2) = √2/2。よって θ = **45°**
　検算: △ACG は AC=CG=5 の直角二等辺三角形だから 45° ✓（tan θ=CG/AC=5/5=1 でも同じ）。表を使うなら sin の列で 0.7071 は 45° の行 ✓
※典型ミス: AG=3＋4＋5 のように辺を足す。θ を「AG と辺 AB のなす角」と読む（底面とのなす角は、AG と、AG が底面に落とす影 AC とのなす角）。

**問4**（解答例。観点を満たしていれば表現は自由）
(1) 解答例: 直角三角形の残り2つの角は必ず鋭角なので、鈍角は直角三角形の内角になれず、「直角三角形の辺の比」では鈍角の三角比を定められない。そこで、原点を中心とする半径 r の円周上の点 P(x, y) をとり、OP と x 軸の正の向きのなす角を θ として、sin θ=y/r、cos θ=x/r、tan θ=y/x（ただし x≠0）と定めた。鋭角のときはこの定め方が直角三角形の辺の比と一致するので、もとの定義を含む形で広げたことになる。
　採点の観点: ①鈍角が直角三角形の中に置けないこと ②座標（円周上の点）を使って定めたこと ③鋭角ではもとの定義と一致すること（①②は必須。③があれば十分）。
※典型ミス: 「180° まで使えるようにするため」と目的だけ書いて、なぜ辺の比では無理かを書かない。
(2) 解答例: 余弦定理 a²=b²＋c²−2bc cos A で A=90° とすると、cos 90°=0 だから a²=b²＋c² となり、三平方の定理そのものになる。三平方の定理は直角三角形だけで成り立つが、余弦定理はどんな三角形でも成り立ち、直角のときに三平方の定理を特別な場合として含む。だから「一般化」と呼ばれる。
　採点の観点: ①余弦定理の式を書き A=90° を入れていること ②cos 90°=0 で三平方の定理の式になること ③余弦定理は直角でない三角形でも成り立つこと（3つとも書けていれば十分）。
※典型ミス: 「余弦定理は三平方の定理から作ったから」で止める（作った経緯ではなく、式として含む関係を書く）。

**S1**
(1) 正弦定理 c/sin C=2R から sin C=c/(2R)。これを面積公式に代入すると
　S = (1/2)ab sin C = (1/2)ab×c/(2R) = **abc/(4R)** ✓
(2) cos A = (b²＋c²−a²)/(2bc) = (25＋64−49)/(2×5×8) = 40/80 = 1/2。よって A = **60°**
(3) S = (1/2)bc sin A = (1/2)×5×8×sin 60° = 20×(√3/2) = **10√3**
　R = a/(2 sin A) = 7/(2×(√3/2)) = 7/√3 = **7√3/3**
　abc/(4R) = 7×5×8/(4×7√3/3) = 280×3/(28√3) = 30/√3 = 10√3 で、S と一致する ✓
　検算: (3) の三角形で最大の辺は c=8 だから最大の角は C。cos C=(49＋25−64)/(2×7×5)=10/70=1/7>0 で鋭角三角形——A=60° が最大の角でないことと合う（C のほうが大きい）✓
　（指導メモ: (1) の式は「3辺と外接円の半径」を結ぶので、3辺が分かれば S（余弦→正弦の道）を出して R=abc/(4S) と逆向きにも使える。数学Ⅰの範囲で導けるが、公式として覚えさせる必要はない。）
※典型ミス: (1) で sin C=2R/c と逆数にする（c/sin C=2R を sin C について解く——分母と分子の位置を確かめる）。
