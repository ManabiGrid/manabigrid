## L01 数える——記数法の歴史と位取りの式

**問1**
漢数字「四千二十」は「千」「十」という位の名前を書くので、百の位が空であることは「百」を書かないことで、一の位が空であることは「十」の後に数字を付けないことで、そのまま表せる（一の位はもともと位の名前を書かず、数字を「十」の後ろにそのまま付ける。「四千二十一」なら最後の「一」が一の位の数字である）。位取り記数法は位の名前を書かず、数字の並ぶ場所で位を表すので、空いた位を飛ばして「42」と書くと別の数になってしまう。だから、空いた位に「ここには何もない」と書き込む記号 0 が必要になる。
（採点の目安: 「漢数字は位の名前を書く」「位取りは場所で表す」「空いた位を示す記号が要る」の 3点があればよい。）

**問2**
(1) 5087=**5×1000＋0×100＋8×10＋7×1**
　検算: 5000＋0＋80＋7=5087 ✓
(2) 100×4＋10×0＋9=**409**
(3) N−(a＋b＋c＋d)=1000a＋100b＋10c＋d−a−b−c−d=999a＋99b＋9c=9(111a＋11b＋c)。111a＋11b＋c は整数だから **9 の倍数**である。
　検算: N=5087 → 各位の和 5＋0＋8＋7=20、5087−20=5067=9×563 ✓

**問3** 十の位は 12−4−5=3 だから、求める数は **435**。
99×4＋9×3＋(4＋3＋5)=396＋27＋12=**435** ✓
※十の位を「12」と書いてしまう誤りに注意。各位の数字は 0〜9 で、和が 12 なのは 3つの数字の合計。

**問4** 2050 の空いた位（百の位と一の位）を飛ばすと「25」、205 の空いた位（十の位）を飛ばすと「25」で、**どちらも同じ「2、5」の並びになって区別できない**。位取り記数法では、空いた位を示す記号（0）がないと、異なる数が同じ形になってしまう。

**問5** 1×3600＋48×60＋20=3600＋2880＋20=**6500**（秒）
検算: 6500÷60=108 余り 20 → 108 分 20 秒、108÷60=1 余り 48 → 1 時間 48 分 ✓

**S1**
(1) 59 分 59 秒に 1 秒を足すと、秒が 60 になって 0 に戻り、分へ 1 繰り上がる。分も 60 になって 0 に戻り、時へ 1 繰り上がる。結果は **1 時間 0 分 0 秒**。10進法の 99＋1=100 で一の位・十の位が続けて 0 に戻り百の位へ繰り上がるのと同じ連鎖で、違いは繰り上がる数が 10 でなく 60 であること。
(2) 7325÷3600=2 余り 125、125÷60=2 余り 5。よって **2 時間 2 分 5 秒**。
　検算: 2×3600＋2×60＋5=7200＋120＋5=7325 ✓
(3) 24.25°: 0.25°=0.25×60′=15′ だから **24°15′**。12°45′: 45′=45/60°=0.75° だから **12.75°**。
　検算: 12.75−12=0.75、0.75×60=45 ✓

## L02 n進法と2進法——10進法との往復

**問1**
(1) 110101₍₂₎=1×32＋1×16＋0×8＋1×4＋0×2＋1×1=32＋16＋4＋1=**53**
(2) 2012₍₃₎=2×27＋0×9＋1×3＋2×1=54＋0＋3＋2=**59**
(3) 1043₍₅₎=1×125＋0×25＋4×5＋3×1=125＋0＋20＋3=**148**
※(3) で重みを 1、5、10、… と 10進法のように取る誤り（典型ミス）に注意。5進法の重みは 1、5、25、125 と 5倍ずつ。

**問2**
(1) 77=2×38＋1、38=2×19＋0、19=2×9＋1、9=2×4＋1、4=2×2＋0、2=2×1＋0、1=2×0＋1。余りを下から読んで **1001101**₍₂₎
　検算: 64＋0＋0＋8＋4＋0＋1=77 ✓
(2) 100=3×33＋1、33=3×11＋0、11=3×3＋2、3=3×1＋0、1=3×0＋1。**10201**₍₃₎
　検算: 81＋0＋2×9＋0＋1=81＋18＋1=100 ✓
(3) 500=7×71＋3、71=7×10＋1、10=7×1＋3、1=7×0＋1。**1313**₍₇₎
　検算: 1×343＋3×49＋1×7＋3=343＋147＋7＋3=500 ✓
※余りを「上から」読んで 1011001₍₂₎ などとする誤り（典型ミス）は、10進法へ戻す検算で見つかる（1011001₍₂₎=89 で 77 に戻らない）。ただし (2) の 10201₍₃₎ のように余りの列が上から読んでも同じ並びになるときは、向きを間違えても検算が通ってしまう。検算で見つかるのは数値の誤りであり、読む向きは例題4 の 200（1300₍₅₎）のように並びが変わる例で確かめる。検算を省かない。

**問3** 1221₍₃₎=1×27＋2×9＋2×3＋1=27＋18＋6＋1=**52**。
52=4×13＋0、13=4×3＋1、3=4×0＋3 より **310**₍₄₎
検算: 3×16＋1×4＋0=48＋4=52 ✓

**問4** 111111₍₂₎=32＋16＋8＋4＋2＋1=**63**（=2⁶−1）。それより 1 大きい 64=2⁶ は **1000000**₍₂₎（7桁）。
検算: 64=1×64＋0＋… ✓。6桁で表せる最大が 63 なので、64 は 7桁になる ✓

**問5** 0 から **63** まで（63=4³−1）、全部で **64** 通り（=4³）。
検算: 最大 333₍₄₎=3×16＋3×4＋3=48＋12＋3=63 ✓

**問6** **できない**。2進法 5桁で表せる最大の数は 11111₍₂₎=31 で、50 は 31 より大きいから。50=2×25＋0、25=2×12＋1、12=2×6＋0、6=2×3＋0、3=2×1＋1、1=2×0＋1 より 50=110010₍₂₎ で、**6桁**が必要。
検算: 32＋16＋2=50 ✓
（指導メモ: 「表せる範囲の外にある」という理由で「できない」と答える型の問題。桁数と範囲 nᵏ−1 の関係が、答えの根拠になる。）

**S1**
(1) 右の位から順に: 1＋0=1、1＋1=10₍₂₎ で 0 を書いて 1 繰り上げ、0＋1＋1=10₍₂₎ で 0 を書いて 1 繰り上げ、1＋0＋1=10₍₂₎ で 0 を書いて 1 繰り上げ、最上位に 1。結果は **10001**₍₂₎。
　検算: 1011₍₂₎=11、110₍₂₎=6、11＋6=17、10001₍₂₎=16＋1=17 ✓
(2) 1111₍₂₎＋1₍₂₎: 一の位 1＋1=10₍₂₎ で 0、繰り上がり 1。次の位も 1＋1=10₍₂₎ で 0、繰り上がり 1。これが 4回続き、最上位に 1 が立って **10000**₍₂₎。
　検算: 15＋1=16=2⁴ ✓。10進法の 9999＋1=10000 と同じ、繰り上がりの連鎖である。
